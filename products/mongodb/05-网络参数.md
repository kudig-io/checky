## 连接地址类型

| 类型 | 说明 |
|---|---|
| 私网连接-专有网络 | 实例默认提供；安全性与性能优于经典网络 |
| 公网连接 | 默认不提供，需手动申请；申请前须将客户端公网 IP 加入白名单 |
| SRV 地址 | DNS SRV 记录服务发现，增删节点无需改连接串；仅云盘版实例支持 |
| 只读连接地址 | 仅在实例存在只读节点时显示，读请求只发往只读节点 |

- 分片集群云盘版仅支持为 Mongos 节点申请公网地址（Shard 需先申请 Shard 私网地址；ConfigServer 仅存量已申请私网地址的实例可申请公网）。
- 释放副本集公网地址时，Primary 与 Secondary 的公网地址均被释放。
- 公网地址申请免费，公网流入与流出流量也免费；MongoDB 层面公网访问无带宽限制。
- 副本集 4.4 及以上版本不支持将经典网络切换为专有网络。

## 连接串格式（副本集）

| 连接类型 | 格式 |
|---|---|
| ConnectionStringURI SRV（推荐） | `mongodb+srv://<username>:<password>@<srv-host>/<database>?[authSource=<authenticationDatabase>][&readPreference=<value>][&readPreferenceTags=<tags>]<other_options>` |
| ConnectionStringURI | `mongodb://<username>:<password>@<host1>:<port1>,...,<hostN>:<portN>/<database>?replicaSet=<replicaSet_value>[&authSource=<authenticationDatabase>][&readPreference=<value>][&readPreferenceTags=<tags>]` |
| ReadOnly ConnectionStringURI | `mongodb://<username>:<password>@<host1>:<port1>,...,<hostN>:<portN>/<database>?readPreference=secondary&readPreferenceTags=role:readonly&replicaSet=<replicaSet_value>[&authSource=<authenticationDatabase>]` |
| 单节点连接地址 | `mongodb://<username>:<password>@<host>:<port>/<database>?[directConnection=true]` |

- 官方示例端口为 3717，域名形如 `dds-xxx.mongodb.rds.aliyuncs.com`；SRV 域名形如 `dds-xxx-srv.mongodb.nosql.aliyuncs.com`。
- SRV 连接串的 TXT 记录指明 `authSource=admin`，会覆盖 `<database>` 的鉴权属性；改鉴权库须手动写 `authSource`。
- SRV 连接的 SSL 选项默认为 `true`，不需要加密时加 `ssl=false`。
- 生产环境建议用 ConnectionStringURI 或 SRV 地址；不建议用单节点连接地址（主备切换会改变节点角色）。
- 低版本 Driver 不支持 SRV/自动发现时，改用 ConnectionStringURI。

## readPreference 参数

| 取值 | 读请求去向 |
|---|---|
| primary | 仅主节点 |
| primaryPreferred | 优先主节点；主故障时发往从节点和只读节点 |
| secondary | 仅从节点和只读节点；两者都故障则读失败（不回落主节点） |
| secondaryPreferred | 优先从节点和只读节点；两者都故障时发往主节点 |

- `readPreferenceTags=role:electable`：优先读从节点。
- `readPreferenceTags=role:readonly`：优先读只读节点。
- readPreferenceTags 与 primary 模式不兼容。

## 只读节点

| 项目 | 规则 |
|---|---|
| 支持范围 | 仅副本集实例和分片集群实例（分片限 Shard 组件） |
| 数量上限 | 副本集最多 5 个；每个 Shard 最多 5 个 |
| 数据同步 | 从延迟最低的主/从节点异步复制（Oplog），正常毫秒级延迟，写压大时可能秒级 |
| 选举 | 不参与主节点选举，也不会被选为主节点 |
| 价格 | 单个只读节点价格等同于副本集或 Shard 中单个节点的价格 |
| 连接 | 有独立连接地址；2 个及以上可用 ReadOnly ConnectionStringURI 负载均衡 |
| 故障 | 只读节点故障时读请求自动切到下一个；全部只读节点故障则该地址连接异常 |

## VPC IP 占用（分片集群）

| 组件 | IP 占用规则 |
|---|---|
| Mongos | 每个节点占用 1 个 VPC IP |
| Shard | 默认不占用；申请 Shard 地址后主从合计占 2 个（DTS 导数据场景常用） |
| ConfigServer | 不占用 |

- 未申请 Shard 地址：总 VPC IP 数 = Mongos 数量 × 1。
- 申请 Shard 地址：总 VPC IP 数 = Mongos × 1 + Shard × 2。
