## 副本集 vs 分片集群对比

| 维度 | 副本集实例 | 分片集群实例 |
|---|---|---|
| 组成 | 1 个 Primary + 1/3/5 个 Secondary + 1 个 Hidden + 0~5 个 ReadOnly | Mongos + Shard + ConfigServer |
| 数据分布 | 单副本集内三副本 | 数据按 Shard 横向分布，每个 Shard 自身为三节点副本集 |
| 扩展方式 | 增删 Secondary/ReadOnly 节点、升配规格、扩存储 | 添加 Mongos、添加 Shard（规格/存储/只读节点数可配） |
| 组件数量上限 | 主备节点数可选三节点等档位（见售卖页） | Mongos 最多 32 个；Shard 最多 32 个 |
| ConfigServer | 无 | 副本集架构（三节点），存储 Shard 元数据 |
| 只读节点 | 最多 5 个 | 每个 Shard 最多 5 个 |
| 审计日志 | 支持 | 支持 |
| SSL 加密 | 支持 | 不支持 |
| 回收站 | 支持 | 文档冲突（2026-11-18 复核仍冲突）：使用限制页称「分片集群实例不支持回收站功能」，回收站页称云盘分片集群支持续费/重建 ⚠️ 待核 |
| 数据恢复 | 按时间点、按备份点恢复至新建实例 | 仅支持按时间点创建实例方式恢复 |

## 副本集节点角色

| 节点 | 功能 | 关键约束 |
|---|---|---|
| Primary（主节点） | 执行并响应读写请求 | 每个副本集实例只能有 1 个 |
| Secondary（从节点） | 经 oplog 同步主节点数据，故障时可选举为新主 | 从节点地址只读；数量可选 1/3/5 |
| Hidden（隐藏节点） | 同步主节点数据，接替故障的从节点或只读节点 | 每个实例只有 1 个；对客户端不可见；不被选举为主，但参与投票 |
| ReadOnly（只读节点） | 从延迟最低的主/从节点同步数据，分担读压力 | 最多 5 个；不参与选举；独立连接地址 |

- 从节点/只读节点故障时系统自动与隐藏节点切换；未自动切换可手动切换，连接地址保持不变。
- 两个及以上只读节点可用 ReadOnly ConnectionStringURI 实现读负载均衡。
- 扩展节点时只增加从节点或只读节点，不增加隐藏节点。

## 分片集群组件

| 组件 | 架构 | 说明 |
|---|---|---|
| Mongos | 单节点架构 | 路由读写操作到对应 Shard；多 Mongos 实现负载均衡与故障转移；默认最多 32 个 |
| Shard | 副本集（主备三节点 + 只读节点） | 存储数据；多 Shard 横向扩展存储与读写并发；默认最多 32 个 |
| ConfigServer | 副本集（三节点） | 存储各 Shard 的元数据 |

- 只读节点需单独购买，单个只读节点价格等同于 Shard 中单个节点的价格。
- VPC IP 占用：每个 Mongos 占 1 个 VPC IP；Shard 默认不占用，申请 Shard 地址后每个 Shard 合计占 2 个；ConfigServer 不占用。
- 未申请 Shard 地址时，总 VPC IP 数 = Mongos 数量 × 1；申请后 = Mongos × 1 + Shard × 2。

## 规格族（通用型 / 独享型 / 专属型）

| 规格族 | 资源隔离 | 承诺最大连接数 | 承诺最大 IOPS | 适用 |
|---|---|---|---|---|
| 通用型 | 独享内存与存储，共享 CPU 和 I/O | 是 | 否 | 价格敏感、性能稳定性要求较低 |
| 独享型（本地盘版） | 独享内存、存储、CPU，共享 I/O | 是 | 否 | 数据库为核心的业务 |
| 独享型（云盘版） | 独享 CPU、内存、存储介质与 I/O | 是 | 是 | 同上，性能长期稳定 |
| 独占物理机 | 完全独享一台物理机全部资源 | 是 | 是 | 高合规/高性能要求 |
| 专属型（MyBase） | 完全独享虚拟或物理主机，开放主机权限 | — | — | 需自主调度资源的客户 |

- 通用型云盘版未全网开放，控制台未见时需提交工单申请。
- 通用型云盘版规格暂不支持云盘加密。

## 选型速查

| 场景 | 推荐 | 依据 |
|---|---|---|
| 开发测试、非核心数据 | 单节点 | 低成本；无 SLA、无高可用 |
| 生产读多写少 | 副本集（三节点）+ 只读节点 | 读写分离、读负载均衡 |
| 高并发读写、数据量大 | 分片集群 | Mongos/Shard 可横向加节点，存储无上限 |
| 需要最高稳定性 | 独享型云盘版/独占物理机 | 承诺最大连接数与最大 IOPS |
| 预算有限 | 通用型 | 共享 CPU 与 I/O，性价比高 |
| 核心系统合规 | 专属型 MyBase | 独享主机 + 主机权限 |
