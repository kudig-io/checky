## 数量上限速查

| 项目 | 上限 | 适用 |
|---|---|---|
| Mongos 节点数 | 默认最多 32 个 | 分片集群 |
| Shard 节点数 | 默认最多 32 个 | 分片集群 |
| 只读节点数 | 副本集最多 5 个；每个 Shard 最多 5 个 | 副本集/分片集群 |
| 隐藏节点数 | 每个副本集固定 1 个 | 副本集 |
| 主节点数 | 每个副本集固定 1 个 | 副本集 |
| 单个集合文件 | ≤ 16 TB（超过则实例不可用） | 全部 |
| Serverless 数据库数 | 最多 20 个 | Serverless |
| Serverless 集合数 | 最多 500 个 | Serverless |
| 3.4 版本集合+索引数 | ≤ 1 万（否则可能物理备份失败） | 3.4 副本集 |
| 每账号每地域可购实例数 | ⚠️ 待核（官方文档未给数字，需在配额中心查询） | 全部 |
| 副本集/分片集群的数据库数、集合数上限 | ⚠️ 待核（官方文档仅给出 Serverless 的 20 库/500 集合） | 副本集/分片集群 |

## 连接数限制

- 最大连接数按「每个节点」计算，Hidden 节点不对外服务。
- 代表值：本地盘 1 核 2 GB（dds.mongo.mid）1000；云盘 2 核 4 GB（通用型）3000；云盘 2 核 8 GB（独享型）5000；独占物理机 100000。
- 官方 FAQ 示例称 1 核 2 GB 三节点副本集的 Primary/Secondary 各 500 连接，与规格表（1000）冲突 ⚠️ 待核。
- 连接数耗尽时新连接被拒绝；可用 `&maxPoolSize=<integer>` 限制客户端连接池。
- 部分规格 2024-05-14 起最大连接数上调，实例与文档不符时重启实例生效。

## 单节点实例限制

| 功能 | 约束 |
|---|---|
| 数据库版本 | 文档冲突：使用限制页称「仅 3.4 和 4.0 支持创建单节点」；单节点架构页称「4.0 和 3.4 已停售，请创建 4.2 及以上」 ⚠️ 待核 |
| 数据备份 | 仅支持快照备份 |
| 数据恢复 | 仅支持按备份点恢复至新建实例；不支持按时间点恢复 |
| 服务可用性 | 不支持主备切换、角色切换、迁移可用区 |
| 数据安全性 | 仅专有网络 + 白名单；不支持审计日志、SSL、TDE |
| 日志管理 | 不支持慢日志、错误日志、运行日志 |
| 迁移同步 | 不支持增量迁移与数据同步（无 Oplog） |
| 私网访问加密 | 不支持开启或关闭 |

- 单节点架构：https://help.aliyun.com/zh/mongodb/product-overview/standalone-instances ｜ 复核：2026-11-16

## 副本集与分片集群限制

| 功能 | 副本集 | 分片集群 |
|---|---|---|
| 数据备份 | 3.4/4.0/4.2 支持物理+逻辑备份；4.4 及以上支持快照备份 | 支持物理备份和逻辑备份 |
| 数据恢复 | 支持按时间点、按备份点恢复 | 仅支持按时间点创建实例恢复 |
| SSL 加密 | 支持 | 不支持 |
| TDE | 仅 4.2 及以下版本支持 | 支持 |
| 审计日志 | 支持 | 支持 |
| 经典网络→VPC | 4.4 及以上版本不支持切换 | — |
| 数据读写 | — | admin 数据库仅可读，不可写入 |
| 回收站 | 支持 | 文档冲突：限制页称不支持，回收站页称云盘版支持续费/重建 ⚠️ 待核 |
| 数据库小版本 | 过期小版本在升级/迁移/变配/恢复时被自动升至最新 | 同左 |

## 其他硬性约束

- 停售/停购：3.4 版本 2023-01-01 停售；Serverless（预设容量）2022-07-11 停止新购；3.2 版本已下线。
- 不支持降低存储空间、变更实例架构、变更存储引擎（需创建新实例替换）。
- 分片集群实例不支持回收站功能（限制页口径，与回收站页冲突见上）。
- Serverless 实例不支持修改实例参数、不支持重启、不支持 SSL/TDE/审计日志。
- API 调用频率限制可在配额中心查看与申请提升。
