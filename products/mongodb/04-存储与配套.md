## 备份方案与恢复能力

| 任务 | 方案 | 适用实例 |
|---|---|---|
| 备份数据库 | 自动备份、手动备份 | 单节点、副本集、分片集群 |
| 高频备份 | 缩短按时间点恢复的回放时长 | 副本集云盘版、分片集群云盘版 |
| 跨地域备份 | 地域级故障容灾 | 副本集云盘版、分片集群云盘版 |
| 恢复至原实例（库表级） | 恢复单个/多个数据库 | 副本集云盘版、分片集群云盘版 |
| 按时间点恢复至新建实例 | 还原到指定时间点 | 副本集、分片集群 |
| 按备份点恢复至新建实例 | 整实例恢复，时效性要求低 | 单节点、副本集 |
| 按 Key 闪回 | 小部分数据回档 | MongoDB 5.0 及以上云盘版副本集/分片集群 |
| 恢复至自建数据库 | 逻辑备份文件恢复 | 4.2 及以下本地盘副本集/分片集群 |

- 备份对性能影响：本地盘版仅在 Hidden 节点备份；云盘版仅在 Secondary 或 Hidden 节点备份，不影响 Primary。
- 已下载的备份文件不支持直接恢复至云数据库实例，需先恢复到自建库再经 DTS 迁移。
- 备份保留天数决定可恢复的最早时间；更早数据需开启长期保留备份。
- 备份系统将备份文件存储至 OSS，默认保存 7 天内的备份文件。

## 扩容与变配规则

| 变更项 | 规则 |
|---|---|
| 存储空间 | 不支持降低；只能升配，目标值须 ≥ 当前值 |
| 副本集存储口径 | 变更后每个独立节点的存储空间均为新值（不是各节点之和等于新值） |
| 副本集可变项 | 主备节点数、只读节点数、规格、存储空间 |
| 分片集群添加 Mongos | 支持配置规格与数量；默认最多 32 个（已有 3 个时最多再加 29 个） |
| 分片集群添加 Shard | 支持配置规格、数量、存储、只读节点数；默认最多 32 个 |
| 新增 Shard 约束 | 新 Shard 的规格、存储、只读节点数须 ≥ 已有 Shard 的最高配置 |
| 降存储的替代方案 | 创建新实例替换原实例 |
| 生效时间 | 变更配置可设置在业务低峰期生效 |
| 存储引擎/实例架构 | 不支持变更；需通过新实例完成变配 |
| 回收站 | 单节点、Serverless、共享存储版、本地盘分片集群、开通 TDE 的实例释放后不支持恢复 |
