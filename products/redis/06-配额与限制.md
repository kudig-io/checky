# Redis · 配额与限制

> 产品：Redis ｜ 口径：公共云 ｜ 复核：2026-11-16

## DB 数

| 项目 | 数值 |
|---|---|
| 每实例支持 DB 数 | 256 个 |
| 数据总量限制 | 所有 DB 存储的数据总量受限于实例内存大小 |
| 单 DB 内存 | 按使用情况自动分配，上限为实例内存（如 DB0 占满全部内存） |

**来源**：
- 使用限制：https://help.aliyun.com/zh/redis/product-overview/limits ｜ 复核：2026-11-16

## 账号配额与规则

| 项目 | 数值/规则 |
|---|---|
| 单实例最多账号数 | 20 个（控制台文档与 FAQ 两处一致） |
| 默认账号（6.0 以下版本） | 自动创建 1 个，账号名为实例 ID；不可删除、替换、改权限 |
| 默认账号（6.0 及以上版本） | 自动创建 2 个：实例 ID 和 default |
| 创建账号前提 | 引擎版本为兼容 Redis 4.0 或以上 |
| 账号名规则 | 英文字母开头，小写字母/数字/下划线，长度 ≤35，不得为保留字 |
| 密码规则 | 大小写字母、数字、特殊字符至少 3 种，长度 8~32；特殊字符 `!@#$%^&*()+-=_` |
| 权限类型 | 仅两种：只读、读写（无 MySQL 式高权限账号） |
| 大小写敏感性 | 4.0 实例及 5.0（5.0.8 之前）不敏感；之后版本敏感 |

- API 文档 CreateAccount 曾写「一个实例下最多可创建 18 个账号」，与控制台文档的 20 个不一致；官方最新控制台文档为 20 个，⚠️ 待核（API 文档疑为旧值）。

**来源**：
- 创建与管理账号：https://help.aliyun.com/zh/redis/user-guide/create-and-manage-database-accounts ｜ 复核：2026-11-16
- CreateAccount API（18 个口径）：https://www.alibabacloud.com/help/tc/redis/developer-reference/api-r-kvstore-2015-01-01-dir-account-management-redis/ ｜ 复核：2026-11-16

## 数据类型限制

| 数据类型 | 元素个数 | 单个元素最大值 | 推荐 |
|---|---|---|---|
| List | 无限制 | 512 MB | 元素个数 <8,192，整体 Value ≤1 MB |
| Set | 无限制 | 512 MB | 元素个数 <8,192，整体 Value ≤1 MB |
| Sorted Set | 无限制 | 512 MB | 元素个数 <8,192，整体 Value ≤1 MB |
| Hash | 无限制 | 512 MB | 元素个数 <8,192，整体 Value ≤1 MB |

- 单 Key 总 Value 数量无官方硬性上限（受实例内存约束）；官方仅给出上述推荐值。
- 每实例可创建的 Key 总数上限：官方文档未给出具体数字，⚠️ 待核。

**来源**：
- 使用限制：https://help.aliyun.com/zh/redis/product-overview/limits ｜ 复核：2026-11-16

## 连接与性能类硬限制

| 项目 | 限制 |
|---|---|
| 实例最大连接数（代理模式） | 500,000（2020-03-01 前创建实例 200,000） |
| 单分片最大连接数（直连） | Redis 开源版 10,000；Tair 30,000 |
| 集群代理模式整体带宽 | 16,384 Mbps（经典规格页）/ 20 Gbps（云原生规格页），⚠️ 待核（两页口径不一致） |
| 集群分片数 | 云原生版可自由调整；经典集群版规格固定为 8/16/32/64/128 分片 |
| 单分片带宽 | 开源版 ≤1 GB 分片 384 Mbps、>1 GB 分片 768 Mbps；Tair 768 Mbps |

## 功能性限制与默认行为

| 项目 | 说明 |
|---|---|
| 容量告警 | 产品未提供容量告警，需到云监控配置 |
| 建议监控项 | 实例故障、主备切换、已使用连接百分比、操作失败数、已用容量百分比、写入/读取带宽使用率 |
| 数据过期删除 | 主动删除（后台周期检测）+ 被动删除（访问时删除） |
| 空闲连接 | 服务端不主动回收，由用户管理 |
| 备份开关 | 不允许关闭自动备份；每周至少 1 次，每份自动备份保留 ≥7 天 |
| 单节点架构功能缺失 | 不支持自动/手动备份、离线全量 Key 分析、实例回收站 |
| Maxclients 参数 | 不支持设置，最大连接数由实例规格决定 |
