# Redis · 日志与审计

> 产品：Redis ｜ 口径：公共云 ｜ 复核：2026-11-17

## 日志类型总表

| 类型 | 产生方 | 查看入口 | 默认保留期 | 是否计费 |
|---|---|---|---|---|
| 引擎慢日志·数据节点 | Redis/Tair 引擎 | 控制台 实例 > 日志管理 > 慢日志；API `DescribeSlowLogRecords` | 72 小时（无数量限制） | 否 |
| 引擎慢日志·代理节点 | Proxy 节点 | 同上（`SlowLogRecordType=proxy`；标准架构不提供代理慢日志） | 72 小时（无数量限制） | 否 |
| 运行日志（错误/运维日志） | Redis/Tair 引擎 | 控制台 日志管理 > 运行日志；API `DescribeRunningLogRecords` | 72 小时 | 否 |
| 审计日志（引擎侧，仅写操作） | Redis/Tair 引擎 + 日志服务 SLS | 控制台 日志管理 > 审计日志；API `DescribeAuditRecords` | 保留时长 1~365 天可设（地域级，以最近一次设置为准） | 是（按存储空间与保存时长按量计费） |
| 操作日志·管控事件（ActionTrail） | 操作审计 ActionTrail | 操作审计控制台 > 事件查询 | 默认 90 天 | 操作审计本身免费；投递到 SLS/OSS 按目标产品计费 |

- 慢日志分数据节点慢日志（阈值 `slowlog-log-slower-than` 默认 20000 微秒即 20 毫秒）与代理慢日志（阈值 `rt_threshold_ms` 默认 500 毫秒）。
- 运行日志暂不支持的版本：Redis 开源版 2.8、Redis 倚天版、Tair 内存型（兼容 Redis 6.0）与磁盘型。
- 审计日志基于日志服务 SLS，仅记录写操作（如 SET、DEL、HSET），不记录读操作；开通后对实例性能影响约 5%~15%。

## 关键日志详表

**A. 引擎慢日志（`DescribeSlowLogRecords` 返回字段）**

| 字段 | 类型/示例 | 含义 |
|---|---|---|
| `Command` | 字符串（如 `KEYS *`） | 慢查询语句 |
| `ElapsedTime` | 整数（如 248） | 执行时长，单位微秒 |
| `ExecuteTime` | 时间（`YYYY-MM-DDTHH:mm:ssZ`，UTC） | 执行开始时间 |
| `IPAddress` | IP 地址 | 客户端 IP 地址 |
| `NodeId` | 节点 ID（如 `r-xxx-db-0`） | 产生慢日志的节点 |
| `AccountName` / `Account` | 字符串 | 账号名称 / 账号 ID |
| `DBName` | 数字（如 0） | 数据库（DB）编号 |
| `SlowLogRecordType` | `db`（默认）/ `proxy` | 慢日志类型：数据节点 / 代理节点 |

**B. 审计日志（控制台过滤条件与 `DescribeAuditRecords` 查询维度）**

| 字段 | 类型/示例 | 含义 |
|---|---|---|
| 时间段 | 时间选择器 | 查询指定时间范围内的写操作记录 |
| 命令（关键字） | 字符串（如 AUTH、`"userId:1"`） | 执行的写命令，需输入完整信息；含冒号关键词用英文双引号包裹 |
| 客户端 IP | IP 地址 | 连接实例的客户端 IP（仅记录客户端出口公网 IP） |
| 账号 | 字符串 | 连接实例的账号，默认账号显示为 null |
| DB | 数字 | 指定 DB 中产生的日志 |
| 类别 | `redis_audit_log` / `redis_proxy_audit_log` | 数据分片审计日志 / 代理服务器审计日志（仅集群代理模式或读写分离可见） |
| 节点 | 节点 ID | 按数据节点或代理节点过滤（API 维度） |

**C. 运行日志（`DescribeRunningLogRecords` 查询维度）**

| 字段 | 类型/示例 | 含义 |
|---|---|---|
| 时间段 | 时间选择器（72 小时内） | 查询的时间范围 |
| 节点类型 | `proxy` / `db` / `cs` | 按节点类型过滤（API 维度） |
| 节点 | 节点 ID | 集群架构可指定节点查询（控制台） |
| 主备角色 | 主/备 | 按节点主备角色过滤（API 维度） |
| 关键词 | 字符串 | 按日志内容关键词搜索 |

**D. 操作审计管控事件（ActionTrail 管控事件结构）**

| 字段 | 含义 |
|---|---|
| `eventTime` | 事件发生时间（UTC 格式） |
| `eventName` | 事件名称；`eventType` 为 ApiCall 时即 API 名称（如 `CreateInstance`、`FlushInstance`） |
| `eventType` | 事件类型：ApiCall / ConsoleOperation / ConsoleSignin / ConsoleSignout / AliyunServiceEvent |
| `eventRW` | 读写类型：Read / Write |
| `sourceIpAddress` | 事件发起的源 IP 地址 |
| `userIdentity` | 请求者身份（type 含 root-account / ram-user / assumed-role 等） |
| `errorCode` | 云服务处理 API 请求发生错误时记录的错误码 |
| `resourceName` | 事件相关资源名称（资源唯一标识） |

## 投递与加工

| 通道 | 去向与参数 | 关键限制 / 额度 | 计费要点 |
|---|---|---|---|
| 审计日志托管存储（SLS） | Project 命名 `nosql-<账号UID>-<地域>`；Logstore `redis_audit_log_standard`；类别 `redis_audit_log`（数据分片）/ `redis_proxy_audit_log`（代理） | 控制台审计日志页仅展示 2000 条，更多需登录日志服务控制台查询分析 | 按存储空间与保存时长计费（保存时长 1~365 天，地域级设置）；关闭后仍存至日志过期 |
| 审计日志下载 | 控制台「下载图表 / 下载图表数据」，格式 `.csv` | 下载前可按关键字、类别、账号、客户端 IP、时间段筛选 | 页面下载无额外标注费用 |
| 审计日志报表订阅 | 邮件、钉钉等 WebHook 机器人（可多选） | 频率可设；报表时间支持相对时间/整点时间/自定义（预设默认相对 15 分钟）；可开启添加水印、使用 SQL 增强 | 报表图片可加邮箱或 WebHook 水印 |
| 审计日志实时查询与分析 | 日志服务 SLS 控制台（查询/在线分析/导出） | RAM 用户需 `AliyunLogFullAccess` 或自定义 `log:*` @ `acs:log:*:*:project/nosql-*` | 审计日志存储按产品侧计费；查询分析在 SLS 控制台完成 |
| 操作审计事件投递 | 创建跟踪 → SLS LogStore 或 OSS Bucket | 单账号跟踪每地域 5 个；1 个跟踪最多配置 1 个 OSS Bucket；操作后 10 分钟内可查 | 操作审计免费；投递目标按各自定价单独付费 |
| 跨账号投递 | 多账号跟踪（资源目录成员事件统一投递） | 多账号跟踪所有地域共 1 个；平台事件跟踪所有地域共 1 个 | 同上 |
| 慢日志 / 运行日志投递 | 官方未提供投递通道，仅控制台与 API 查询（保留 72 小时） | 📋 待补（官方未发布慢日志/运行日志投递文档，结构保留待回填） | 否 |

- 审计日志不支持追溯开通前的历史数据；关闭后日志按原保留时长存至过期，期间仍计费。
- 事件投递与多账号跟踪属操作审计通用机制，Redis 侧留痕范围见下节。

## 审计与合规

| 项 | 官方口径 |
|---|---|
| 接入方式 | 云数据库 Tair（兼容 Redis）已接入操作审计（ActionTrail），记录用户通过 OpenAPI、控制台等方式操作产生的管控事件 |
| 管控事件范围 | 实例/分片/账号/备份/白名单/网络等，如 `CreateInstance`、`CreateTairInstance`、`AddShardingNode`、`FlushInstance`、`SwitchInstanceHA`、`ModifySecurityIps`；部分事件含义官方标注后续完善 |
| 数据面覆盖 | 操作审计仅覆盖管控事件；命令级读写不在其中，写操作审计由引擎审计日志覆盖（仅记录写操作，不含读操作） |
| 查询与留痕保留 | 默认为每个阿里云账号记录最近 90 天操作事件；操作后 10 分钟内可在控制台查询 |
| 长期保存 | 超过 90 天需创建跟踪，将事件投递到 SLS 或 OSS（等保 2.0 要求 180 天留存的场景） |
| 配额 | 单账号跟踪每地域 5 个；多账号跟踪所有地域 1 个；平台事件跟踪所有地域 1 个；1 个跟踪最多 1 个 OSS Bucket；`LookupEvents` 每秒最多 2 次 |
| 引擎审计日志 | 记录写操作（SET/DEL/HSET 等），保留时长 1~365 天可设；开通性能影响约 5%~15%；按存储空间与保存时长计费 |
| RAM 权限 | RAM 用户开通审计日志需日志服务管理权限（`AliyunLogFullAccess` 或自定义 `log:*` @ `nosql-*`） |

- 引擎审计日志中的 `aurora` 账号、DB 节点主机 IP、`127.0.0.1` 写入 IP 属系统内部操作记录，非外部访问。
- 操作审计与引擎审计日志互补：前者回答「谁在控制台/OpenAPI 改了什么配置」，后者回答「谁在数据面写了哪些 Key」。
