# Redis · 计费与生命周期

> 产品：Redis ｜ 口径：公共云 ｜ 复核：2026-11-16

## 计费方式

| 计费方式 | 优势 | 规则 |
|---|---|---|
| 按量付费 | 灵活 | 随时创建与释放，释放后不再收费；计费周期 1 小时，不足 1 小时按 1 小时收费 |
| 按量付费 + 资源包 | 灵活、低价 | 计费规则同按量付费，费用由预购资源包自动抵扣，不足部分按量结算 |
| 包年包月 | 低价 | 预付费，创建时支付；计费周期为订单购买周期（UTC+8），包年 = 365 天、包月 = 30 天 |

- 按量付费出账时间通常在周期结束后 1 小时内，最长不超过 3 小时；账单生成后自动扣款。
- 同一周期内变更规格，按该周期内最高规格计费。
- 按开通的实例容量规格收费，而非实际使用的缓存容量（开通 2 GB 只存 256 MB 仍按 2 GB 计费）。
- 创建实例后支持转换计费方式；升级大版本不产生费用。

## 计费项

| 计费项 | 是否必须 | 规则 |
|---|---|---|
| 实例规格费用 | 是 | 按实例规格与购买时长计费；**包含磁盘费用**（磁盘用于系统运行：日志、备份临时文件、AOF 文件），磁盘费用不可调整 |
| 备份费用 | 超额度才收费 | 免费额度 = 实例规格默认内存大小（磁盘型以磁盘存储空间为准）；超出部分约 0.0075 元/GB/天（各地域略有浮动） |
| 审计日志 | 非必须 | 开通后按存储空间按小时出账；华东 1（杭州）0.008 元/GB/小时（100 GB ≈ 0.8 元/小时） |
| 带宽升级 | 非必须 | 按升级带宽大小与使用时间按小时出账；杭州 0.014 元/MB/小时（+10 MB/s ≈ 0.14 元/小时） |
| 流量费用 | 否 | 默认带宽内不收费；VPC 内流量免费；公网流量不收费；带宽瓶颈可买带宽包 |

- 审计日志与带宽升级的其他地域单价：中国香港/新加坡/欧洲美洲/中东等 0.018 元/GB/小时、0.017 元/MB/小时；马来西亚/印尼/菲律宾/泰国/日本/韩国/沙特 0.0122 元/GB/小时、0.017 元/MB/小时（详见计费项页完整表）。

- 计费项：https://help.aliyun.com/zh/redis/product-overview/billable-items ｜ 复核：2026-11-16

## 包年包月到期与按量欠费时间线

### 包年包月实例

| 到期后时长 | 状态与规则 |
|---|---|
| 第 1~15 天 | 实例状态「被禁用」，回收站显示「已锁定」，无法访问；停止计费（审计日志若已开通仍按量计费）；续费后以续费时间重新起算 |
| 第 15~22 天 | 到期 15 天未续费，实例列表删除、回收站显示「已释放」，数据继续保留一周；可在回收站重建恢复 |
| 第 23 天 | 实例彻底销毁，数据不再保留且无法找回 |

### 按量付费实例

| 欠费后时长 | 状态与规则 |
|---|---|
| 第 1~15 天 | 实例「被禁用」无法访问，暂停计费；充值结清欠款后恢复并重新计费 |
| 延停权益额度内 | 实例不停服，期间正常计费；额度按历史消费等每月自动计算，不是欠费总额上限 |
| 第 15~22 天 | 实例「已释放」，数据继续保留 8 天，可在回收站重建恢复 |
| 第 23 天 | 实例彻底销毁，数据不再保留且无法找回 |

- 续费提醒时点：到期前 7 天、3 天、1 天、到期当天及释放前 1 天（站内信、短信、邮件）。
- 包年包月过期后实例规格、带宽升级停止计费；到期 15 天后自动释放。
- 回收站支持「续费解锁」恢复已锁定实例，也支持「立即销毁」彻底删除。

## 资源包与预付费

- 按量付费实例推荐搭配资源包；按量付费的经典版 Tair / 经典版 Redis 开源版实例规格费优先从资源包抵扣，不足部分按量结算。
- 资源包详情见产品计费目录下的「资源包」页。

## 生命周期管理要点

| 事件 | 影响 |
|---|---|
| 升级大版本 | 切换阶段 60 秒以内只读 + 秒级连接闪断；实例 ID、连接地址、数据、白名单、账号密码不变；不收费 |
| 释放实例（按量） | 释放后不再收费 |
| 到期/欠服停服 | 按上表时间线；停服前有提醒 |
| 数据销毁 | 第 23 天彻底销毁，不可恢复 |
