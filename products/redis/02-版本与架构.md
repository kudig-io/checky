## 版本线

### Redis 开源版大版本

| 大版本 | 状态 | 说明 |
|---|---|---|
| 7.0 | 在售可选 | 可选择 7.0、6.0、5.0，完全兼容社区大版本并向下兼容 |
| 6.0 | 在售可选 | 同上 |
| 5.0 | 在售可选 | 同上；Redis 开源版 2.8 实例仅支持升级到 5.0 |
| 4.0 | 存量 | 小版本发布日志仍维护 4.0；存量 4.0 的布隆过滤器 API 未正式开放，升级大版本后不再支持 BF.ADD 等 |
| 2.8 | 仅存量升级 | 2.8 实例仅支持升级到 5.0；不支持降低大版本 |

- 经典版实例最高支持升级到 5.0；升级到 6.0 需先转换为云原生版。
- 大版本升级切换阶段产生 60 秒以内只读状态和秒级连接闪断；升级本身不产生费用。

## 架构形态对比

| 架构 | 副本 | 可调分片 | 只读节点 | 连接模式 | SLA 适用 |
|---|---|---|---|---|---|
| 标准版-单副本 | 单节点 | 否 | 不支持 | 单地址 | 不适用 |
| 标准架构（高可用） | 1 主 + 1~9 备（云原生）；1 主 1 备（经典） | 否 | 支持（1~9 个） | 单地址 + Proxy | 适用 |
| 集群版-单副本 | 每分片单节点 | 8/16/32/64/128 分片（经典规格固定） | 不支持 | 代理/直连 | 不适用 |
| 集群架构 | 每分片 1 主 + 1~4 备 | 云原生支持自由调整分片数 | 代理模式支持（每分片 1~4） | 代理（推荐）/直连，二选一 | 适用 |
| 读写分离 | 主 + 只读（星型复制） | 同底层架构 | 标准 1~9、集群每分片 1~4 | 仅 Proxy | 适用 |

- 读写分离前提：部署模式为云原生、Redis 开源版或 Tair 内存型/持久内存型、规格 1 GB 及以上、实例类型为高可用。
- 经典版读写分离（链式复制，1/3/5 只读节点）已停售。
- 云原生集群实例不支持直连模式切换为代理模式（需新建实例 + DTS 迁移）；经典版集群默认代理模式，直连需手动开通。

## 选型速查

| 场景 | 推荐 | 依据 |
|---|---|---|
| 纯缓存、数据可丢、极致性价比 | 标准版-单副本 / 集群版-单副本 | 价格优势；官方明示不建议生产使用、SLA 不适用 |
| 10 万 QPS 以下、协议兼容要求高 | 标准架构（高可用） | 官方建议阈值 |
| 读多写少、热点 Key | 开启读写分离 | 读 QPS 最高提升 9 倍，无需改代码 |
| 大容量（>64 GB）或超高吞吐 | 集群架构 | 最大 16 TB，吞吐随分片线性扩展 |
| 高性能 + 企业级数据结构 | Tair 内存型 | 约同规格开源版 3 倍性能 |
| 大容量低成本温冷数据 | Tair 磁盘型 | 成本最低 15%、性能约 60% |
| 强持久化、RPO 要求高 | Tair 持久内存型 | 每个操作均保证持久化 |
| 突发弹性、按量付费 | Tair Serverless KV | 自动扩缩容、按实际用量计费 |
| 多 Key/跨 slot 操作多的业务 | 慎用集群架构 | 需所有 KEY 同 slot，有命令限制 |
