## 连接方式与网络选型

| 客户端位置 | 建议网络类型 | 说明 |
|---|---|---|
| ECS 或 ACK | 专有网络 VPC | 同一 VPC 默认网络互通，直接设置白名单即可 |
| 本地客户端 | 公网 | 需先设置 IP 白名单，再申请公网连接地址 |
| 自建 IDC | 高速通道物理专线 | 本地数据中心与云端实例云上云下互通 |

- 实例默认仅提供 VPC 连接地址；通过公网连接需手动申请公网连接地址。
- 非同一 VPC：同地域可调整 ECS 或实例的 VPC 至同一 VPC；跨账号、跨地域可用 VPC 对等连接。
- 集群架构或读写分离实例默认提供 Proxy（代理）节点的连接地址；直连地址连接方式同开源 Redis Cluster。

## IP 白名单与安全组

| 项目 | 限制 |
|---|---|
| 默认状态 | 系统默认禁止所有 IP 地址访问实例 |
| 组内白名单 IP 数 | 最多 1000 个（以英文逗号分隔、不可重复）；支持单 IP 与 CIDR 段（前缀长度 1~32） |
| 白名单分组名 | 2~32 个字符，小写字母/数字/下划线，小写字母开头 |
| 实例可绑定安全组数 | 每个实例最多 10 个 |
| 安全组方式前提 | 实例大版本需为 Redis 4.0（最新小版本）及以上 |
| 安全组不支持的架构 | 云原生版集群架构、云原生版读写分离架构 |
| 默认分组 | default、hdm_security_ips 等系统默认分组不可删除 |
| 0.0.0.0/0 | 表示允许所有 IP 访问，官方警告高安全风险 |
| 白名单生效范围 | 仅作用于新建立的连接；已建立的长连接在断开前仍可通信 |

## 私网带宽规则

- 规格表带宽为内网带宽，与网络连接类型无关；上行、下行带宽独立计算（如 768 Mbps 规格上下行各 768 Mbps）。
- 单分片带宽上限（Redis 开源版）：分片内存 ≤1 GB → 384 Mbps（48 MB/s）；分片内存 >1 GB → 768 Mbps（96 MB/s）。
- Tair（企业版）单分片最大带宽 768 Mbps（96 MB/s）。
- 集群架构总带宽 = 所有分片带宽之和；代理连接地址模式存在整体上限：
  - 经典版集群规格页：带宽上限 16,384 Mbps（2,048 MB/s），达到后增加分片不再提升。
  - 云原生版规格页：集群代理模式与读写分离架构带宽上限 20 Gbps（2.5 GB/s），集群直连模式无整体带宽限制。
  - 两页数字口径不一致（16,384 Mbps ≈ 16 Gbps vs 20 Gbps），⚠️ 待核（疑为经典版/云原生版口径差异）。
- 外网带宽取决于内网带宽与客户端网络，官方建议使用内网连接。
- 可手动增加实例带宽（按小时出账，见 07 计费）。

## 连接数限制

| 模式 | 规则 | 上限 |
|---|---|---|
| 标准架构 | 实例规格表的「最大连接数」即实例最大连接数 | 规格值 10,000~50,000（云原生） |
| 集群代理模式 | 与分片数无关，取决于 Proxy 节点数：min(Proxy 节点数 × 12 万, 50 万) | 500,000（2020-03-01 前创建的实例为 200,000） |
| 集群直连模式 | 单分片最大连接数 × 分片数；Redis 开源版单分片 10,000，Tair 单分片 30,000 | 随分片线性扩展，无 50 万上限 |
| 每秒新建连接数 | 代理模式每秒可新增连接数上限 10,000（示例口径）；直连地址绕过代理后单个数据分片每秒新建连接上限 2,000（如 4 分片 = 8,000/秒） | 见左列 |

- 实例运行中连接数增长受每秒新建连接数限制：如上限 10,000/秒、当前 12,000，则下一秒最大 22,000。
- 服务端不主动回收空闲连接，由用户管理。

## 流量计费口径

- 实例默认带宽内不收费；使用 VPC 时，ECS 等服务与实例之间的数据传输免费。
- 申请公网地址后产生的公网流量同样不收费；带宽成为瓶颈时可额外购买带宽包升级。
- 该口径与「按量付费含流量费」的常见理解不同，以官方 FAQ 原文为准。
