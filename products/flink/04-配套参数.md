## 连接器总览

官方口径：提供 30+ 开箱即用连接器，支持注册自定义连接器。表类型分源表（数据入口）、维表（JOIN 补充）、结果表（出口）。

| 分类 | 连接器 |
|---|---|
| 关系型数据库 | MySQL SQL、RDS MySQL（后续不再支持，建议改用 MySQL 连接器）、PolarDB PostgreSQL（Oracle 兼容 1.0，退役中）、SelectDB、OceanBase（公测中）、Postgres CDC（公测中） |
| NoSQL 数据库 | 云数据库 HBase、MongoDB、表格存储 Tablestore、Lindorm、Milvus（公测中） |
| 消息队列 | Kafka SQL、Upsert Kafka、云消息队列 RocketMQ、数据总线 DataHub |
| 数据仓库 | StarRocks、Hologres、AnalyticDB MySQL 3.0、AnalyticDB PostgreSQL、ClickHouse、Iceberg |
| 数据湖 | Paimon、MaxCompute、Hudi（退役中） |
| 日志/对象存储 | 日志服务 SLS、对象存储 OSS |
| 键值/时序数据库 | Tair（Redis 开源版）、Tair（企业版）、InfluxDB（退役中）、Elasticsearch |
| 通用/调试 | JDBC、社区版 CDC、Faker、Datagen、Blackhole、Print |

## SQL 引擎版本（VVR）

| 项 | 官方口径 |
|---|---|
| 引擎 | Ververica Runtime（VVR），基于 Apache Flink 增强 |
| 版本号格式 | Major1.Major2.Minor；大版本 = Apache Flink X/Y 位变更，小版本 = Z 位兼容修复 |
| 兼容承诺 | 不承诺大版本间兼容；承诺同大版本小版本兼容（SQL 语法、类库接口、引擎框架），不含业务逻辑/数据处理 |
| LTS 规则 | 每个大版本最终小版本为 LTS（如 VVR 6.x 的 6.0.7）；全网仅保留 2 个 LTS 版本运行，推出新 LTS 后最旧的停止服务 |
| 控制台选版建议 | 选带「推荐」「稳定」标签的版本 |
| 文档示例版本 | vvr-8.0.9-flink-1.17（Python 快速入门示例） |
| 当前在售完整版本清单 | 见官方「功能发布记录」页引擎表（2026-11-18 复核：现行 VVR 11.1~11.9、8.0.11、6.0.7 LTS，含各版 GA/EOS 日期，EOS 已过版本不再提供） |

## 作业运维参数

| 参数/能力 | 官方口径 |
|---|---|
| 资源配置生效 | 修改后需重启作业 |
| 专家模式前置 | 仅 SQL 作业；改 SQL 或资源后需重新生成资源计划图 |
| 动态参数更新 | 支持动态配置调整（部分参数无需重启） |
| 多 SSG 模式 | 开启后每个算子独立 Slot，可单独调 CPU/Heap/Off-Heap/并发数 |
| Chain 策略 | ALWAYS（默认）/ HEAD / NEVER |
| 检查点与快照 | 系统检查点 + 作业快照全生命周期管理；原生快照（Native Incremental Savepoint） |
| 智能调优 | 支持自动调优与定时调优（Session 集群作业不支持） |
| 诊断 | Flink Advisor 作业智能诊断 |
| 监控采集 | ARMS 每 30 秒采集一次 Flink 指标；云监控免费监控默认存储 30 天 |
