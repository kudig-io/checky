## VPC 绑定规则

| 项 | 官方口径 |
|---|---|
| 默认能力 | 实时计算 Flink 版默认不具备访问公网的能力；默认仅支持访问相同地域、相同 VPC 下的服务 |
| VPC 选择 | 开通工作空间时必须选择对应地域的专有网络（VPC） |
| 可否更改 | 开通时选择了专有网络后，无法再更改；地域和可用区在资源创建成功后也无法更改 |
| 存储类型 | 存储类型可选全托管存储（公测中）或 OSS Bucket；绑定的 OSS 需与工作空间同地域、标准存储 |
| 诊断工具 | 开发控制台内置「网络探测」，按 Endpoint/IP 检测与上下游连通性 |

## 访问数据源的连通方式

| 场景 | 官方方案 |
|---|---|
| 同地域同 VPC 数据源 | 直接连通（推荐，如 Hologres 同 VPC Endpoint） |
| 跨 VPC 数据源 | 三选一：私网连接（PrivateLink）、VPC 对等连接、云企业网（CEN）；或规划期直接购买同 VPC 服务/重建同 VPC 工作空间 |
| 公网数据源 | 通过 NAT 网关实现 VPC 与公网互通（官方推荐优先内网，公网延迟不确定） |
| 白名单 | 在目标服务白名单中添加 Flink 工作空间虚拟交换机的网段；新增交换机需同步加白 |
| 超时调大 | DDL WITH 参数 `connect.timeout` 默认 30 秒，网络超时可调大 |
| 跨可用区 | 虚拟交换机与上下游不在同一可用区，加白后网络仍可连通 |

## 公网与专线

| 项 | 官方口径 |
|---|---|
| 公网访问 | 默认不支持；需自建公网 NAT 网关实现 VPC 与公网连通；公网带宽需在 VPC 控制台 NAT/EIP 监控运维页查看 |
| 域名解析（无自建 DNS） | 域名-IP 映射 ≤50 条：用 Flink 域名管理（VPC 内网 DNS）；>50 条：用云解析 DNS 内网域名解析 |
| 域名解析（有自建 DNS） | VPC 与自建 DNS 连通：云解析 DNS 转发（推荐，出站终端节点 + 白名单放行 53 端口）；或作业模板配 DNS（仅非 JDK 11 引擎） |
| 强制 IPv4 | `env.java.opts: '-Djava.net.preferIPv4Stack=true'`，支持单作业与工作空间全局两种生效范围 |
| 专线/VPN 接入 | 官方《网络连接选型》：混合云经高速通道（专线）或 VPN 网关接入，跨 VPC 用对等连接/转发路由器/私网连接（2026-11-18 复核） |
