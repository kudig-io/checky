## 资源配额（工作空间/项目空间）

| 配额 | 限制 | 提升方式 |
|---|---|---|
| 包年包月一次开通计算资源 | ≤ 1000 CU；>1000 CU 需工单开通 | 提交工单 |
| 按量付费工作空间配额上限（2023.12 新版本后新购） | 创建时默认 1000 CU，最大 9999999 CU | 控制台「编辑配额上限」 |
| 按量付费工作空间配额上限（2023.12 前购买） | 默认 9999999 CU | 控制台「编辑配额上限」 |
| 混合计费弹性资源配额 | 最大 1000 CU；最小不得小于已使用的弹性资源 CU 数 | 控制台调整 |
| 资源变配最小变化量 | 1 CU（不能小于已分配/已使用资源） | — |
| 单工作空间项目空间数 | 最多 5000 个 | — |
| 单项目空间文件夹数 | 最多 100 个，深度 ≤5 层 | — |
| 单文件夹文件数 | 最大 10000（含目录） | — |
| 按量配额约束 | 工作空间配额上限 ≥ 所有项目空间配额上限总和 | — |

## 部署与网络限制

| 限制项 | 规则 |
|---|---|
| 公网访问 | 默认不支持访问公网（需 NAT 网关等自建方案） |
| VPC | 开通时选定，创建后不可更改；默认仅同地域同 VPC 可访问 |
| 跨可用区部署 | 仅部分地域 Intel X86 架构 + 包年包月工作空间支持 |
| 地域/可用区 | 创建成功后不可更改；杭州可用区 H、张家口暂不支持新购仅扩容 |
| 浏览器 | 控制台推荐 Chrome 内核浏览器 |
| 计费模式转换 | 按量 ⇄ 包年包月可互转；ARM 架构不支持包年包月转按量；已启用跨可用区的工作空间暂不支持转按量 |

## 作业与性能限制

| 限制项 | 规则 |
|---|---|
| 单作业 CU 上限 | 官方使用限制页未公布（2026-11-18 复核，仅单次开通 ≤1000 CU）；受工作空间/项目空间配额与队列资源约束 |
| 单作业并行度硬上限（流作业） | 官方使用限制页未公布（2026-11-18 复核）；批处理自动并行度 max 默认 128 |
| 单作业资源下限 | 每个 JM/TM 至少 0.5 Core + 2 GiB |
| TM/JM 单实例上限 | CPU 最大 16 Core、内存最大 64 GiB（超出需工单） |
| 1 CU 处理能力 | 简单 40000~55000 条/秒；复杂 5000~10000 条/秒（压测口径） |
| 窗口函数作业 | 官方建议至少购买 4 CU |
| Session 集群作业 | 不支持监控告警/数据曲线、不支持配置告警、不支持自动调优；官方标注请勿生产使用 |
| 系统检查点 | 不配置间隔即关闭；超时默认 10 分钟 |
| State TTL | 默认 36 小时（作业过期时间默认 1.5 天） |
