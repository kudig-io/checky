## 内外网地址与端口

| 项目 | 规则 |
|---|---|
| 默认端口 | 3306，允许手动修改 |
| 内网连接地址 | 通过 VPC 内网访问，延迟低、稳定性高，系统自动生成 |
| 外网连接地址 | 需手动申请；申请后才显示；RDS MySQL 不支持调整公网带宽 |
| 地址修改 | 修改连接地址/端口立即生效、不需重启实例；连接地址前缀全网唯一 |
| 地址格式 | 前缀以小写字母开头、字母或数字结尾，至少 8 字符；连接地址总长（前缀+后缀）≤63 字符 |
| 主备切换 | 切换成功后实例地址不变，原主实例转为备实例 |
| 白名单 | 连接前需将客户端 IP 加入 IP 白名单 |

- 基础系列与高可用系列提供「实例连接地址」（内网+外网）与「数据库代理连接地址」（基础系列不支持代理）。
- 修改地址时若已启用 SSL 加密，必须先关闭 SSL（关闭会重启实例）。

## VPC 连接与网络能力

- 内网地址用于同一 VPC 下的 ECS 等资源访问 RDS；跨 VPC 需通过切换 VPC 或其他网络打通方案。
- RDS 未设置固定网络访问带宽限制，实际网络性能取决于主机网络带宽上限；内网访问享受高达万兆的共享带宽资源。
- 官方口径提供公网出流量免费策略（公网入/出流量本身不作为 RDS 计费项，计费项见 07-计费）。
- 实例只能添加与自身网络类型相同的安全组（VPC 实例只能加 VPC 安全组）；每实例最多加入 10 个安全组。
- 若 RDS 与云服务器不在同一安全组，云服务器不能访问 RDS。

## 地址类型（按系列）

| 系列 | 地址类型 |
|---|---|
| 基础系列、高可用系列 | 实例连接地址（内网/外网）；开通数据库代理后有代理连接地址 |
| 集群系列 | 集群读写地址（每实例仅 1 个，指主节点）、集群只读地址（每实例最多 1 个，指备节点，支持负载均衡）、节点直连地址、数据库代理连接地址 |

- 集群系列代理连接地址可设为读写或只读；2024-06-25 起新建集群系列实例默认开通通用型数据库代理。
- 集群只读地址移除备节点时，被移除节点的连接会出现 30~120 秒闪断；至少保留 1 个备节点、至少 1 个节点权重大于 0。
- 调整节点权重只对新建连接生效，已建立连接不受影响。

## 主从延迟相关事实

| 事实 | 数值/机制 |
|---|---|
| 复制方式 | 默认参数模板为半同步；异步/高性能参数模板为异步；半同步在备节点不可用或网络异常时退化为异步 |
| 备节点故障时主节点 FTWRL 只读 | 一般不超过 5 秒 |
| 集群系列备节点延迟阈值 | 超过 7200 秒（2 小时）自动重搭修复 |
| 集群系列备节点恢复目标 | 99% 场景下故障到恢复不超过 10 分钟 |
| 只读实例延迟 | 支持设置「只读实例延时复制」；只读实例同步延迟有专门的排查文档 |
| 延迟对读写分离的影响 | 代理支持设置只读实例延迟阈值，延迟超阈值时不再向该实例分配读请求 |
| 延迟触发的费用 | DDL 导致备库延迟过长时系统可能自动触发备库重搭，增加云盘实例备份存储费用 |
| 主从延迟量化承诺 | 官方未给出统一的「主从延迟 ≤ X 秒」SLA 数值，⚠️ 待核 |
