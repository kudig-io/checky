# RDS MySQL · 计费与生命周期

> 产品：云数据库 RDS MySQL 版 ｜ 口径：公共云 ｜ 复核：2026-11-16

## 计费方式

| 方式 | 规则 |
|---|---|
| 包年包月（预付费） | 新建实例时支付；购买时长越长折扣越多；变更配置产生补差价或退款；到期不续费则 CPU、内存、云盘等资源自动释放，数据丢失 |
| 按量付费（后付费） | 创建后每小时按使用量自动扣费；账号余额需 ≥100 元才可购买；用完可立即释放 |
| Serverless | 按 RCU 动态匹配资源、实时计费；1 个 RCU 性能约等于内存 2 GB 的基础系列 RDS 实例 |
| 计费互转 | 包年包月↔按量付费可互转；仅 RDS MySQL 支持按量付费↔Serverless；包年包月转 Serverless 需先转按量付费 |

## 基础计费项

| 计费资源 | 说明 | 计费方式 |
|---|---|---|
| 实例规格（CPU 和内存） | 按规格收费，含主实例与只读实例 | 包年包月 / 按量付费 / 资源包 / 节省计划 |
| RCU | Serverless 实例计算资源 | Serverless 实时计费 |
| 存储空间 | 主备实例、只读实例、灾备实例的存储空间，单价与存储类型相关 | 包年包月 / 按量付费 |
| IO 性能突发 | 仅高性能云盘支持，按突发量收费 | 按量付费 |
| 数据归档 | 仅高性能云盘支持，按云盘 OSS 归档数据量收费 | 按量付费 |
| 备份存储 | 超出免费额度的备份使用量；每小时费用 =（备份使用量 − 免费额度）× 单价 | 按量付费 |
| 跨地域备份 | 存储（BackupStorageSize / DdrOssStorageSize）+ 网络流量（NetworkOutDuplicationSize），归属 DBS | 按量付费 |

- 除基础计费项外还有可选增值服务（SQL 审计、秒级监控、独享代理等）。
- 公网出流量不作为 RDS 独立计费项（可信云页载明提供公网出流量免费策略）。

## 资源包与节省计划

| 产品 | 抵扣范围 | 关键规则 |
|---|---|---|
| 计算包 | 按量付费主实例/只读实例计算资源、数据库代理计算资源 | 可叠加；先到期先抵扣；不支持续费、退订、升降级 |
| 存储包 | 按量付费实例存储空间（不含高性能云盘）、备份空间（不含高性能云盘）、SQL 审计使用量 | 可叠加；先到期先抵扣；不支持续费、退订、升降级 |
| RDS 节省计划 | 抵扣 RDS 全部按量付费项：实例规格、数据存储、备份存储、异地容灾（限高性能本地盘）、SQL 审计、秒级监控、独享代理 | 覆盖 RDS MySQL / PostgreSQL / SQL Server |
| 备份存储包 | 抵扣包年包月/按量付费实例超出免费额度的备份空间（不含高性能云盘和 SSD 云盘） | 存储包优先于节省计划 |

- 资源包支持地域：中国内地部分地域（杭州、上海、青岛、北京、张家口、呼和浩特、乌兰察布、深圳、河源、广州、成都）。

## 欠费停服与释放规则（按量付费）

| 阶段 | 规则 |
|---|---|
| 账号欠费 | 该账号下所有 RDS 按量付费实例进入「锁定中」；**不影响包年包月实例**；欠费期间无法手动释放实例 |
| 延期免停额度内（7 天） | 实例仍可正常访问，延停期间正常计费，每天收到一次短信提醒；充值后立即恢复 |
| 超出 7 天延停额度 | 暂停实例服务并停止计费；同时释放实例，实例进入回收站保留 8 天 |
| 回收站 8 天内 | 可对实例进行重建恢复，将原实例数据恢复到新实例（部分实例不进回收站） |
| 释放后第 9 天起 | 实例备份不再保留，实例从回收站删除，数据彻底删除无法恢复（跨地域备份保留期内、或已设「已删除实例备份保留策略」的除外） |
| 欠费期间自动备份 | 延停 7 天内自动备份继续执行；超 7 天停服后自动备份立即终止 |

## 包年包月到期与生命周期

| 事项 | 规则 |
|---|---|
| 到期未续费 | 实例到期后无法正常运行；在指定时间内未续费，CPU、内存、云盘等资源自动释放，数据丢失 |
| 只读实例联动 | 主实例到期锁定期间，未到期的只读实例可继续访问（状态显示「运行中（主实例锁定）」） |
| 主实例释放联动 | 主实例被释放后，包年包月只读实例自动退款并释放，按量付费只读实例直接释放 |
| 释放后备份 | 可设置「实例释放后保留备份文件」（保留最后一个/全部保留）；已删除实例备份可下载恢复 |
| 备份长期保留 | 数据备份保留最长可设 730 天（超过为归档备份，单价较低）；可勾选本地盘「实例释放前长期保留」 |
