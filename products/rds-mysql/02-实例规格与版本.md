## MySQL 版本线与生命周期

| 大版本 | 社区发布时间 | RDS 发布时间 | 社区生命周期结束 | RDS 停止支持 |
|---|---|---|---|---|
| MySQL 8.4 | 2023-07-18 | 2026-03 | 预计 2032-04 | 未标注（/） |
| MySQL 8.0 | 2018-04-19 | 2019-05 | 2026-04-21 | 未标注（/） |
| MySQL 5.7 | 2015-10-21 | 2016-11 | 2023-10-21 | 预计 2028-10-21 |

- 当前可升级路径：5.5→5.6→5.7→8.0→8.4，不支持跨大版本直接升级（如 5.6 不能直升 8.0）。
- MySQL 8.4 是 LTS 版本，也是 RDS MySQL 支持的最高大版本，无法继续向上升级。
- 升级均为大版本升级的配套说明：不支持从控制台直接降级，降级需新购低版本实例 + DTS 迁移。
- 官方《大版本生命周期说明》注明表中部分时间为预计时间、将在结束前修正，且「版本新购等问题请关注并以对应公告为准」（2026-11-18 复核该页现行表）。

## 版本与功能的停售状态

| 对象 | 停售/停止支持节点 | 说明 |
|---|---|---|
| MySQL 5.7 | RDS 停止支持预计 2028-10-21（生命周期说明页 2026-11-18 复核） | 社区 2023-10 起停止维护；官方建议升级 8.0 |
| X-Engine 存储引擎 | 2024-11-01 起无法新购/续订；2025-04-30 起存量实例官方不再提供支持 | 建议存量实例转 InnoDB 或迁移 PolarDB MySQL |
| SSD 云盘 | 分批下线中 | 部分 RDS 实例不再提供 SSD 云盘售卖，建议用 ESSD |
| 三节点企业系列 | 2023-03-27 起停止新购 | 建议改购集群系列或 PolarDB-X 2.0 标准版 |
| TokuDB 引擎 | 2019-08-01 起不再支持 | 已转换为 InnoDB |
| 参数模板新建 | 支持 MySQL 5.6、5.7、8.0 | 前提条件页面同时列出 8.4/8.0/5.7/5.6 可用模板功能 |

## 系列与规格族矩阵

| 维度 | 分类 | 要点 |
|---|---|---|
| 产品系列 | 基础系列 | 单节点，计算存储分离，无备节点，不支持只读实例/灾备/主备切换 |
| 产品系列 | 高可用系列 | 一主一备，备节点不可读，可跨 2 可用区，支持只读实例与数据库代理 |
| 产品系列 | 集群系列 | 一主多备（2~9 节点），备节点可读，支持 MGR，支持 5.7/8.0/8.4 |
| 产品系列 | 三节点企业系列 | 一主一备一日志，已停止新购 |
| 规格族 | 通用型（n 系代码） | 多实例共享物理资源，官方注明「无法保证最大 IOPS 和最大 IO 带宽」 |
| 规格族 | 独享型（x 系代码） | 有明确的实例规格最大 IOPS 与 IO 带宽值 |
| 架构代际 | 标准版（原 X86） | 规格代码 mysql.n*/x* |
| 架构代际 | 倚天版（原 ARM） | 倚天芯片，规格上限 64 核，支持基础/高可用/集群系列倚天版 |
| 计费形态 | Serverless | 规格码 mysql.n2.serverless.1c（基础）/ mysql.n2.serverless.2c（高可用），按 RCU 计量 |

## 选型速查

| 场景 | 建议 |
|---|---|
| 开发测试、个人学习 | 基础系列（官方：售价低至高可用系列一半） |
| 生产环境、大多数业务 | 高可用系列（官方：适合 80% 以上用户场景） |
| 大量读请求、读写分离 | 高可用系列 + 只读实例（最多 10 个）+ 数据库代理；或集群系列备节点直接可读 |
| 数据强一致、金融级 | 集群系列 3 节点以上启用 MGR（RPO=0）；三节点企业系列已停新购 |
| I/O 密集/高并发写 | 高性能本地盘（仅高可用系列）或独享型云盘规格 |
| 成本敏感 + 波动负载 | Serverless（按 RCU 实时计费） |
| 存储性价比 | 优先高性能云盘（可开 BPE/IO 突发/数据归档） |

- 通用型无法保证最大 IOPS 和 IO 带宽，官方对 IOPS 敏感业务建议选高可用系列独享型。
- 官方规格页注明：规格列表可能含已下线规格、各地域可售规格以实际购买页为准；倚天版与标准版的差异见「产品类型」文档（2026-11-18 复核标准版主实例规格列表页说明）。
