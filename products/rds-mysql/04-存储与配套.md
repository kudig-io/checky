## 存储类型对比

| 对比项 | 高性能本地盘 | 高性能云盘 | ESSD 云盘 |
|---|---|---|---|
| I/O 延迟 | 10~50 微秒 | 100~200 微秒 | 100~200 微秒 |
| IOPS 决定因素 | 由实例规格决定 | 磁盘规格 + 实例规格共同决定 | 磁盘规格 + 实例规格共同决定 |
| 扩容 | 需拷贝数据，可能几小时，有闪断 | 在线升级，秒级扩容，无影响 | 在线升级，秒级扩容，无影响 |
| 备份方式 | Xtrabackup 物理备份 | ESSD 云盘快照备份 | ESSD 云盘快照备份 |
| 备份/克隆速度 | 小时级（与磁盘大小相关） | 秒级 | 秒级 |
| 数据持久性 | 硬件故障有概率损坏数据，靠备库保护；高可用系列本地盘 SLA 可达 99.995% | 99.9999999%，支持单节点基础版 | 99.9999999%，支持单节点基础版 |
| 支持系列 | 仅高可用系列（含三节点企业系列本地盘） | 基础/高可用/集群系列 | 基础/高可用/集群系列 |

- 高性能云盘在兼容 ESSD 特性基础上提供四种功能：IO 性能突发、Buffer Pool Extension（BPE）、数据归档（成本较 ESSD PL1 下降 80%）、存储压缩。
- ESSD 分 PL0/PL1/PL2/PL3：PL1 约为 PL0 的 5 倍 IOPS、2 倍吞吐；PL2 约为 PL1 的 2 倍；PL3 最高较 PL1 提升 20 倍 IOPS、11 倍吞吐；单盘随机读写能力高达 100 万。
- SSD 云盘分批下线中，官方建议使用 ESSD 云盘。
- 官方选购建议：优先高性能云盘，按需开启 BPE/IO 突发/数据归档；明确要高 PL 等级再选 ESSD。

## 存储扩容

- 云盘（ESSD/高性能云盘）：在线升级、秒级扩容、无影响；部分满足条件的实例支持缩容。
- 高性能本地盘：需拷贝数据，可能需要几个小时，扩容过程有闪断。
- 存储空间达到阈值时可自动扩容（存储/性能自动扩容功能）。
- 存储空间已满时实例会被自动锁定，锁定期间影响使用。
- 变更存储类型：支持 SSD 云盘升级为 ESSD 云盘；「变更高性能本地盘至云盘」在 MySQL 8.4 功能概览全列 ❌（各系列/存储类型均不支持）。
- ⚠️ 待核：本地盘最大存储容量口径不一（2026-11-18 复核：使用限制页 8,000 GB；存储类型页与现行规格表 24,000 GB，规格表另注新加坡/香港地域 16,000 GB），详见 03-实例参数。

## 备份体系

| 项目 | 规则 |
|---|---|
| 数据备份（全量） | 默认开启且无法关闭；最少保留 7 天；频率最低每周 2 次（云盘开高频快照后最高每 15 分钟 1 次） |
| 日志备份（增量） | 默认开启、可关闭；最少保留 7 天；保留天数可设 7~730 天，且必须 ≤ 数据备份天数；5.7 基础系列固定 7 天 |
| PITR | 数据备份 + 日志备份可恢复备份保留期内第一个全量备份开始的任意时间点 |
| 备份组成 | 备份使用量 = 数据备份 + 日志备份；存放于备份空间，不占用实例存储空间 |
| 归档备份 | 保留超过 730 天（2 年）的数据备份为归档备份，收较低归档单价 |
| 免费额度 | 高性能云盘 200%×存储空间（开存储压缩 400%）；高性能本地盘 50%（开压缩 100%）；仅抵扣 730 天内常规备份 |
| 超额计费 | 每小时备份费用 =（备份使用量 − 免费额度）× 备份单价；杭州示例单价 0.00025 元/GB/小时 |
| 表数量限制 | 备份的表超过 60 万张无法备份；库表恢复要求不超过 5 万张 |
| 备份类型 | 逻辑备份（mysqldump）、物理备份（XtraBackup）、快照备份（ESSD） |

## 恢复方式

| 方式 | 说明 |
|---|---|
| 全量恢复（到新实例） | 按备份集恢复整个实例；只读实例不支持 |
| 任意时间点恢复（PITR） | 依赖日志备份，可恢复至保留期内任意时间点 |
| 库表恢复 | 按备份集或时间点恢复指定库/表；常规模式：高性能本地盘可恢复到原实例或新实例，云盘仅支持恢复到原实例；极速模式仅高性能本地盘且仅恢复到原实例，通过性能型沙箱实例实现，比常规快 50%~95% |
| 恢复范围 | 取决于日志备份与数据备份保留时长，二者最大均可设置为 730 天 |
| 只读实例 | 不支持备份集/时间点恢复（实例级与库表级均不支持） |
| 高频备份 | 物理/快照高频备份可缩短数据丢失窗口，满足苛刻 RPO 场景 |

## 只读实例

| 项目 | 规则 |
|---|---|
| 创建上限 | 最多 10 个 |
| 前提 | 主实例版本 8.4/8.0/5.7/5.6；计费为包年包月或按量付费（Serverless 不支持）；实例系列为高可用系列 |
| 数量关系 | 备实例固定 1~2 个（高可用系列 1 个）；灾备实例为不同地域一主一备 |
| 与主实例关系 | 同地域（可不同可用区）；存储类型必须一致；存储空间不能低于主实例；建议规格不小于主实例 |
| 账号/数据库 | 由主实例同步，只读实例不能创建/删除账号或数据库 |
| 备份 | 不支持自动备份策略与手动备份，仅可设本地日志保留策略 |
| 生命周期 | 主实例释放后，包年包月只读实例自动退款并释放，按量付费只读实例直接释放 |

- 创建只读实例时从备实例复制数据，主实例更新会立即自动同步到所有只读实例；支持设置「只读实例延时复制」。
- 只读实例持续提供服务（设置读权重后），备实例与灾备实例在主实例正常运行时不提供服务。

## 读写分离（数据库代理）

| 系列 | 使用条件 |
|---|---|
| 基础系列 | 不支持 |
| 高可用系列 | 需先创建只读实例，再开通数据库代理 |
| 集群系列 | 可直接开通数据库代理并使用（备节点本身可读） |

- 代理地址读写请求自动分流：写请求发主实例，非事务 SELECT 发只读实例或主实例。
- 只发往主实例的语句包括：INSERT/UPDATE/DELETE/SELECT FOR UPDATE、所有 DDL、事务内请求、RR 及以上隔离级别的非只读事务、存储过程、Multi Statements、临时表请求、SELECT last_insert_id()、用户变量、KILL、LOCK/FLUSH（含 FTWRL）、SAVEPOINT 等。
- 发往所有实例的语句：系统变量更改、USE、SHOW PROCESSLIST、NAMED PREPARE、COM_CHANGE_USER/COM_QUIT 等。
- 代理地址支持读写/只读两种读写属性，可配置节点读权重与延迟阈值；官方建议一个主实例至少创建 2 个只读实例。
- 2024-06-25 起新建集群系列主实例默认开通通用型数据库代理（通用型代理免费）；可变配为独享型代理。
- 集群系列相比高可用系列加只读实例，官方称最高可节省 40% 成本。
