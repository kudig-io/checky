## 规格与性能硬限制

| 资源 | 限制 |
|---|---|
| 存储空间 | 高性能本地盘最大 8,000 GB（使用限制页口径）；SSD 云盘最大 6,000 GB；ESSD 云盘最大 64,000 GB。⚠️ 待核（2026-11-18 复核）：存储类型页与现行规格表均为 24,000 GB（规格表另注新加坡/香港 16,000 GB），与使用限制页 8,000 GB 冲突 |
| 临时表空间 | 高性能本地盘最大 300 GB（超出会导致频繁高可用切换、宕机）；云盘无限制 |
| 连接数 | ⚠️ 待核（2026-11-18 复核口径仍冲突）：使用限制页写最大 100,000（并注明以主实例规格列表为准）；规格表默认值最高 208000，参数页称 max_connections 可设 1~208000 |
| IOPS | 高性能本地盘最大 144,000（使用限制页）；存储类型页称本地盘 IOPS 最高可达 15 万 |
| 内存 | 高性能本地盘最大 720 GB；云盘最大 768 GB |
| JSON 字段 | 单字段最大 4 GB |
| 单表大小 | 最大 16 TB（受操作系统文件尺寸限制） |
| 表数量 | 超过 60 万张无法备份；库表恢复要求 ≤5 万张；本地盘大版本升级要求 ≤100 万张 |

## 命名限制

| 限制项 | 规则 |
|---|---|
| 实例名 | 2~255 字符；大小写字母、中文、数字、下划线或短横线；以字母或中文开头 |
| 账号名 | MySQL 8.4/8.0/5.7 为 2~32 字符，5.6 为 2~16 字符；小写字母、数字或下划线；以小写字母开头、字母或数字结尾；不得与已有账号重复、不得用 SQL 关键字 |
| 数据库名 | ≤64 字符；小写字母、数字、下划线或短横线；以小写字母开头、字母或数字结尾；不得重复、不得用 SQL 关键字 |
| 参数模板名 | 8~64 字符；英文、数字、小数点或下划线，字母开头，不含中文 |
| 连接地址前缀 | ≥8 字符；总长 ≤63 字符；小写字母开头、字母或数字结尾 |

## 安全限制

| 限制项 | 规则 |
|---|---|
| 密码 | 8~32 字符；大写、小写、数字、特殊字符（`!@#$%^&*()_+-=`）至少三种 |
| 默认端口 | 3306，可手动修改 |
| 云盘加密 | 只能在创建实例时开启，且不能关闭 |
| 安全组 | 每实例最多加入 10 个；只能添加与实例网络类型相同的安全组 |
| IP 白名单 | 每实例最多 50 个白名单分组；每分组最多 1000 个 IP 地址或 IP 段 |
| 高权限账号 | 每实例仅 1 个；只能通过控制台或 API 创建管理 |
| 普通账号 | 不能创建/管理其他账号，不能断开其他账号连接；默认仅有连接当前库权限 |
| root/sa 权限 | RDS 不提供 |
| XA_RECOVER_ADMIN | 仅 8.0、8.4 支持；控制台创建的账号需手动 GRANT，其他方式创建的账号无法获得 |

## 实例操作限制

| 限制项 | 规则 |
|---|---|
| 存储引擎 | 仅支持 InnoDB；X-Engine 已停止新购；不支持 TokuDB（2019-08-01 起）、MyISAM（自动转 InnoDB）、Memory 引擎 |
| 日志 | 日志默认开启且不支持关闭；binlog_format 固定为 ROW 不支持修改；GTID 默认开启不支持关闭 |
| 主备复制 | 提供主备复制架构（基础系列除外）；高可用系列备实例不可读，集群系列备节点可读 |
| 实例重启 | 必须通过控制台或 OpenAPI 操作 |
| 存储空间 | 存储空间已满实例自动锁定 |
| 物理备份/恢复 | 仅限通过控制台或 API 进行（逻辑备份/恢复可用命令行或图形界面） |
| 大版本升级 | 不支持控制台直接降级；不支持跨大版本；本地盘/云盘升级造成 15 秒业务中断；已开 TDE 需走 DTS |
| 系列互转 | 基础系列可升级高可用/集群系列，升级后不可直接降级；高可用系列可升级集群系列；「高可用系列升级三节点企业系列」功能概览标 ❌ |
