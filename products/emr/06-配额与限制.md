## 集群与节点组配额

| 项目 | 限制 | 备注/提升方式 |
|---|---|---|
| 账号可创建集群数量上限 | ⚠️ 待核 | 官方 EMR 文档未公开数值，需在配额中心或提工单确认 |
| 部署集内节点数 | 单节点组最多 20 台 ECS | 仅 Master/Core 类型节点组可加入部署集；创建后不可更改 |
| 附加安全组 | 创建集群时每节点组 ≤2 个；新增节点组时 ≤4 个 ⚠️ 待核 | 两处口径冲突 |
| Task 节点最小实例规格 | 4 vCPU 8 GiB | 通用型最小 ecs.g7.xlarge（4 vCPU 16 GiB）；其他机型最小 ecs.u1-c1m2.xlarge（4 vCPU 8 GiB） |
| Task 备选实例规格数 | 最多 10 个（同 vCPU 内存） | 仅按量付费/抢占式 Task 节点组 |
| 跨可用区节点组 | 仅支持 Task 类型 | 新增其他可用区节点组时 |
| 新增节点组类型 | Core、Task、Gateway、Master-Extend | Master 节点组不支持手动新建；Gateway 仅 EMR-5.10.1+ DataLake/DataFlow、EMR-5.17.1+ Custom |
| Serverless Spark 任务并发 | 单个 Spark 集群默认 200 | 更高并发提工单 |
| Serverless Spark 免费试用 | 每账号 1 次，1000 CU·h，3 个月有效 | 需此前未开通过工作空间、未购买过相关商品 |

## 扩缩容与配置变更限制

| 项目 | 限制 |
|---|---|
| 扩容 | 不支持扩容 Master 节点组，只能扩 Core 与 Task；新节点配置默认与已有节点一致 |
| Task 缩容 | 版本 5.x > 5.6.0、3.x > 3.2.0；集群运行中；Task 节点组为按量付费或抢占式实例 |
| Gateway 缩容 | 版本 5.x > 5.10.1；集群运行中；Gateway 节点组为按量付费 |
| 磁盘 | 不支持磁盘容量缩容；Master 节点不支持增加磁盘数量（只能调大单块磁盘或扩容 Core） |
| 配置升级 | 仅升不降；大数据型与本地 SSD 型实例不支持升级；按量/抢占式 Task 节点组不支持配置升级 |
| 组件版本 | 不支持单组件版本升级，组件版本不支持升级；需高版本请重新购买集群 |
| 高可用转换 | 不支持非 HA 集群转 HA 集群 |
| 计费方式转换 | 支持按量付费转包年包月；**不支持包年包月转按量付费** |
| 服务卸载 | 创建集群时安装后的服务不支持卸载 |
| 弹性伸缩 | 仅抢占式或按量付费的 Task 节点组可用；集群含 Trino、Presto、StarRocks、Impala、ClickHouse 时不支持切换到托管弹性伸缩规则 |
| 弹性伸缩频率 | 托管弹性伸缩（集群级）：指标收集 5 s、监测 5~10 s，EMR-3.43.0+/5.9.0+；自定义弹性伸缩（节点组级）：指标收集 30 s、监测 30 s，EMR-3.42.0+/5.8.0+ |
| 旧版 Hadoop 集群弹性伸缩 | 需新建专用伸缩组，该节点组不支持手动扩缩容；每次仅一个伸缩组开启；按时间与按负载规则二选一 |

## 账号与任务级限制

| 项目 | 限制 |
|---|---|
| 按量付费开通余额 | 账户可用余额（含现金、代金券、优惠券）不得少于 100 元人民币，否则集群创建失败 |
| 弹性伸缩节点组付费类型 | 仅当 Task 节点组付费类型为按量付费或抢占式实例时允许配置弹性伸缩规则 |
| 抢占式实例 | 仅 Task 节点组支持抢占式实例 |
| 旧版 Hadoop 弹性伸缩组 | 该类型弹性伸缩组不支持直接执行扩容/缩容操作 |
| Serverless Spark 网络连接 | 仅支持指定可用区的交换机（按地域列白名单，如杭州 H/I/J、上海 L/F/G 等） |
| 组件 Web UI | 默认不对外开放端口，需按访问方式开放对应端口 |

## 高危操作（禁止）

| 禁止操作 | 可能结果 |
|---|---|
| 删除/修改 `etc/hosts` 下 hosts 文件 | 集群关联不到节点服务，服务异常 |
| 在 ECS 控制台直接改组件配置文件参数 | 服务重启后修改被覆盖（应在 EMR 控制台改） |
| 通过 ECS 控制台/API 重新部署 ECS 实例 | 影响 EMR 服务 |
| 通过 ECS 控制台/API 给 EMR 节点挂载/卸载磁盘 | 磁盘不可用 / 数据丢失 |
| 通过 ECS 控制台/API 直接删除 Core 节点 | 数据丢失，节点上作业失败 |
| 通过 ECS 控制台/API 直接删除 Master 节点 | HA：NameNode HA、ResourceManager、HBase HMaster 无法切换，只能重购集群；非 HA：集群不可用且无法迁移 |
| 通过 ECS 控制台/API 直接删除 Task 节点 | 该节点上作业失败 |
| 停止 Master 上内置 MySQL 服务 | Hive MetaStore、Oozie、Ranger 无法访问数据库 |
| 修改内置 MySQL root 密码 | Hue、Ranger 等组件失败 |
| 通过 ECS 控制台/API 改安全组、VPC、交换机 | 节点间网络异常、组件不可用 |
| 通过 ECS 控制台/API 转换计费方式 | 无法转回原计费方式（应走 EMR 控制台按量转包年包月） |
| 删除管控 Agent 目录 | 影响集群正常运行 |
