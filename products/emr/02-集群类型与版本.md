## 业务场景（集群类型）

四类预定义业务场景 + 自定义集群；API `ClusterType` 取值 DATALAKE / OLAP / DATAFLOW / DATASERVING / CUSTOM / HADOOP（旧版数据湖，不推荐）。

| 集群类型 | 支持组件（要点） | 核心能力 | 适用场景 |
|---|---|---|---|
| 数据湖 DataLake | Spark、Hive、Tez、Trino、Kyuubi、Presto；HDFS、OSS-HDFS、Celeborn、JindoCache；Flume、Sqoop；Hudi、Iceberg、Paimon；Yarn、Zookeeper；OpenLDAP、Ranger、DLF-Auth、Knox | 统一存储、多计算引擎兼容、多数据湖格式 | 离线 ETL（数据仓库）、交互式查询（即席分析） |
| 数据分析 OLAP | StarRocks、ClickHouse、Doris；Zookeeper | 亚秒级查询、列式存储优化、联邦查询 | 复杂聚合分析（用户画像、人群圈选、商业智能） |
| 实时数据流 DataFlow | Flink；HDFS、OSS-HDFS；Paimon；Yarn、Zookeeper；OpenLDAP、Knox | 流批一体、低延迟、状态一致性 | 实时 ETL（流式湖仓） |
| 数据服务 DataServing | Phoenix；HBase；HDFS、OSS-HDFS、JindoCache；Zookeeper；OpenLDAP、Ranger、Knox | 毫秒级点查、SQL 接口、读写分离 | 高并发查询服务（用户行为分析、精准营销） |
| 自定义 Custom | 上述组件自由组合 | 全组件灵活组合、支持混合负载 | 离线/实时 ETL、聚合分析、高并发查询混合场景 |

- 2022-12-19 17:00（UTC+8）以后首次创建 EMR 集群的账号，不能再选择 Data Science（机器学习）、旧版数据湖 Hadoop、Presto、Zookeeper 集群类型。
- 混合负载场景官方建议：离线、实时、分析业务独立部署多类型集群组合，避免互相影响。

## 发行版本体系

| 规则 | 官方口径 |
|---|---|
| 版本号格式 | EMR-a.b.c：a=技术架构/核心生态重大演进，b=组件更新，c=兼容性 Bug 修复 |
| 当前系列 | EMR 5.x（基于 Hadoop 3.x 和 Hive 3.x 构建）、EMR 3.x（基于 Hadoop 2.x 和 Hive 2.x 构建） |
| 组件版本 | 集群内组件版本通常与开源版本一致；每个版本预装固定组件版本，不建议更改，且不支持升级 |
| 多版本组件 | 创建集群时每个组件只有一个版本；如需 Spark2 与 Spark3 并存，需创建后自行安装并自担兼容性风险 |
| 表格中 `-` | 表示该版本未集成此组件 |

## EMR Serverless Spark 形态

| 模式 | 说明 | 计费 |
|---|---|---|
| Serverless 按需 | 任务提交时秒级拉起资源，运算结束即释放 | 按 CU 用量按量付费 |
| Spark 集群（常驻） | 集群启动后持续运行，任务直接提交，免等资源拉起 | 启动后按 Master + Worker 占用资源持续计费，与是否有任务无关 |
| 免费试用 | 新用户 1000 CU·h 计算资源抵扣额度，自领取起 3 个月有效 | 每账号限一次，仅抵扣 CU 按量费用 |

- 单个 Spark 集群默认任务并发上限 200，更高并发需提工单。
- 提交不频繁且对启动时间不敏感的场景，官方建议直接用 Serverless 按需模式，避免集群空闲持续计费。

**来源**：
- 使用 Spark 集群（并发上限 200、持续计费）：https://help.aliyun.com/zh/emr/emr-serverless-spark/user-guide/use-spark-clusters ｜ 复核：2026-11-16
- 新用户免费试用（1000 CU·h / 3 个月）：https://help.aliyun.com/zh/emr/emr-serverless-spark/product-overview/free-trial ｜ 复核：2026-11-16

## 选型速查

| 需求 | 推荐 |
|---|---|
| 离线 ETL / 数据仓库 / 即席查询 | 数据湖 DataLake 集群（EMR on ECS） |
| 多维分析、BI 报表、高并发点查 | 数据分析 OLAP 集群，或 EMR Serverless StarRocks |
| 实时流式 ETL、流式湖仓 | 实时数据流 DataFlow 集群（Flink + Paimon） |
| 高并发点查、HBase 类场景 | 数据服务 DataServing 集群 |
| 多引擎混合、小规模 | 自定义 Custom 集群（官方建议大规模时拆分为多类型集群组合） |
| 短查询、频繁批任务 | EMR Serverless Spark 的 Spark 常驻集群 |
| 低频、突发批处理 | EMR Serverless Spark 按需模式 |
| Kubernetes 之上构建 | EMR on ACK |
