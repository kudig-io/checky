# EMR · 节点规格

> 产品：EMR ｜ 口径：公共云 ｜ 复核：2026-11-16

## ECS 规格族映射（实例类型）

| 实例类型 | vCPU:内存 | 特性 | 提供节点 |
|---|---|---|---|
| 通用型（g 系列） | 1:4 | 默认选型 | Master/Core/Task |
| 计算型（c 系列） | 1:2 | 更多计算资源，适合 CPU 密集任务 | Master/Core/Task |
| 内存型（r 系列） | 1:8 | 更多内存，适合内存密集任务 | Master/Core/Task |
| 本地 SSD（i 系列） | 1:4 | 本地 SSD 盘，高随机 IOPS 与吞吐，存在数据丢失风险 | **主节点不提供** |
| 大数据型（d 系列） | 1:4 | 本地 SATA 盘，存储性价比高，TB 级数据量推荐 | Core/Task |
| 共享型 | 共享 CPU | 大计算量下稳定性不足，仅入门学习，不推荐企业客户 | **仅任务节点提供** |

- 具体在售规格族与参数以 ECS「实例规格族」文档为准。

## 节点数上下限

| 项目 | 数量口径 |
|---|---|
| Master 节点组 | 默认 1 台；开启高可用（DeployMode=HA）时为 3 台，可有多台 Master 实例 |
| Core 节点组 | 默认 2 台，可按需调整 |
| Task 节点组 | 默认不开启；可随时新增和减少，不影响现有集群 |
| 扩容范围 | 只能扩容 Core 与 Task 节点组，**不支持扩容 Master 节点组** |
| 部署集内节点 | 单节点组最多 20 台 ECS 加入部署集（仅 Master/Core 类型节点组支持） |
| Task 节点最小规格 | 4 vCPU 8 GiB；通用型最小 ecs.g7.xlarge（4 vCPU 16 GiB），其他机型最小 ecs.u1-c1m2.xlarge（4 vCPU 8 GiB） |
| Task 备选实例规格 | 按量付费/抢占式 Task 节点组最多选择 10 个同 vCPU 内存的备选规格 |
| StarRocks/ClickHouse 拓扑 | Core 节点数量必须等于 Replica × Shard |
| 跨可用区节点组 | 新增其他可用区的节点组时仅支持 Task 类型 |

## 规格推荐（官方口径）

### 存算一体（HDFS）— 数据湖/实时数据流/自定义场景

| 节点 | 推荐规格 |
|---|---|
| Master | 常规用通用型、磁盘选云盘；小型集群（≤8 台实例）8 核 32 GiB；中大型集群 ≥16 核 64 GiB；HDFS 文件数 ≥1000 万时规格须满足 NameNode 内存需求 |
| Core | 默认通用型；CPU 密集（如 AI 推理训练）用计算型；内存密集（如离线报表）用内存型；HDFS 存储 >10 TB/节点 用大数据型（本地盘，需自维护）；节点内存 > YARN 单 Container 内存峰值 |
| Task | 峰谷场景：固定 Core 按低谷计算需求配置；弹性 Task 规格 ≥ Core 规格以应对峰值 |

### 存算分离（OSS-HDFS/OSS）

| 节点 | 推荐规格 |
|---|---|
| Master | 同上（通用型、云盘；小型 8 核 32 GiB，中大型 ≥16 核 64 GiB） |
| Core | 功能与 Task 相似、不存储数据；Core 不支持弹性伸缩，官方推荐仅用 Task、不配置 Core |
| Task | 按 YARN 任务 CPU/内存比例选型：默认通用型、CPU 密集计算型、内存密集内存型 |

### 数据分析（OLAP）场景

| 节点 | 推荐规格 |
|---|---|
| Master | 部署 StarRocks FE / Doris FE / Zookeeper；小型 ≤8 台 8 核 32 GiB，中大型 ≥16 核 64 GiB |
| Core | 存储量 ≤10 TB/节点按计算需求选通用/计算/内存型；>10 TB/节点 用大数据型 |
| Task | 仅 StarRocks Compute Node 支持部署在 Task；存算分离（仅 StarRocks 3.x 支持）无 Core，Task 一般 ≥16 核 64 GiB |

## 扩容 / 缩容 / 升配参数

| 操作 | 关键参数与限制 |
|---|---|
| 扩容 | 只能扩 Core/Task；新节点配置默认与已有节点一致；付费类型继承节点组（按量集群可新增按量/抢占式节点组，包年包月集群可新增包年包月/按量/抢占式节点组）；包年包月扩容可设自动续费（到期前 7 天续费，默认续期 1 个月）；扩容不重启存量节点进程 |
| 缩容（Task） | 集群版本 5.x > 5.6.0、3.x > 3.2.0；集群状态运行中；Task 节点组付费类型为按量付费或抢占式实例 |
| 缩容（Gateway） | 集群版本 5.x > 5.10.1；集群状态运行中；Gateway 节点组付费类型为按量付费 |
| 缩容（Core） | 走「手工缩容节点组」流程；本地 HDFS 扩容 Core 后如数据不均衡需执行 HDFS Balancer |
| 配置升级（升配） | 仅支持升配不支持降配；大数据型和本地 SSD 型 ECS 实例不支持升级配置；按量/抢占式 Task 节点组不支持配置升级 |
| 磁盘扩容 | 支持数据盘扩容；**磁盘容量不支持缩容** |
| 弹性伸缩 | 托管弹性伸缩（EMR-3.43.0+ / 5.9.0+，集群级智能选节点组，指标收集 5 s、监测 5~10 s，不支持自定义指标）；自定义弹性伸缩（EMR-3.42.0+ / 5.8.0+，节点组级，指标收集 30 s、监测 30 s，支持自定义指标）；两者均仅支持抢占式或按量付费的 Task 节点组 |
