## 集群网络（VPC 与交换机）

| 参数 | 官方口径 |
|---|---|
| 网络类型 | 创建集群时选择 VPC 与交换机（同一 VPC 内可为不同节点组指定交换机）；节点组创建后交换机不可更改 |
| 交换机可用 IP | 可用 IP 数 = 2^(32-掩码位) − 5（保留网络地址、网关、广播及阿里云保留地址） |
| 网段与可用 IP（网络文档口径） | /24 约 251 个、/20 约 4091 个（按 2^(32-掩码位) − 5 计算） |
| 网段与可用 IP（创建集群页口径） | /24 约 250 个、/20 约 4090 个、/17 约 32764 个（两页均为官方原文，取整口径不一致，按入口分别引用；2026-11-18 已逐字复核创建集群页） |
| 规划要求 | 交换机可用 IP 数须大于集群计划部署的节点总数，否则弹性扩容可能失败 |
| 网段变更 | 交换机网段创建后不支持修改；需扩大 IP 范围时要新建交换机并重建集群 |
| 弹性节点 IP | Task 节点扩缩容时底层 ECS 重建，IP 由 VPC/交换机网段动态分配，不保证与之前相同或不重复 |
| 跨产品互通 | 建议 EMR 与 VPC、SLB、数据库等服务同地域部署；与其他云服务需规划网络互通路径 |

## 安全组

| 参数 | 官方口径 |
|---|---|
| 默认安全组 | 创建集群时可选择已有安全组，或到 ECS 控制台新建 |
| 企业安全组 | **禁止使用 ECS 上创建的企业安全组** |
| 附加安全组（创建集群时） | 每个节点组最多关联 2 个附加安全组 |
| 附加安全组（新增节点组时） | 每个节点组最多关联 4 个附加安全组（「管理节点组 > 新增节点组」页原文，与创建集群页 2 个为不同入口，两处均已逐字复核，非数值冲突） |
| 规则原则 | 最小权限：只开放必要端口，入站仅允许可信 IP/网段；SSH 等管理端口严格管控 |
| Kerberos | 使用 Kerberos 认证的网络连接建议开放 88 端口的 UDP 协议 |
| 授权对象 | 禁止填写 0.0.0.0/0，应填目标交换机网段或客户端内网 IP |
| 变更限制 | 禁止在 ECS 控制台/API 修改 EMR 节点的安全组、VPC 和交换机（会导致节点间网络异常、组件不可用） |

## 组件端口与访问方式

集群内 Hadoop、Spark、Flink 等开源组件的 Web 界面端口默认**未对外开放**，官方提供四种访问方式：

| 访问方式 | 需开放端口 | 限制条件 |
|---|---|---|
| 原生 UI 地址（内网） | 逐一开放组件服务端口（示例：YARN UI 8088/8088） | 客户端须与集群节点同一内网；外部用户无法访问 |
| Knox 代理地址（内网/外网） | 仅需 Knox 8443 | 集群类型需支持添加 KNOX 服务；支持服务有限：YARN、HDFS、SPARK2、SPARK3、FLINK、HBASE、IMPALA、TRINO、PRESTO、TEZ、RANGER |
| SSH 本地端口转发 | 每个组件一个端口 | 需保持 SSH 连接，对带宽与连接稳定性有要求 |
| SSH 动态端口转发 | 只开一个端口即可访问多个组件 | 同上；适合网络受限环境 |

- 端口配置入口：集群详情 → 访问链接与端口；安全组入方向手动添加规则，授权对象填客户端内网 IP。
- 网络连接类场景的端口示例：Hive Metastore 9083；Kerberos 认证建议放通 UDP 88。

- 查看开源组件 Web 界面（四种方式、Knox 8443、支持服务列表）：https://help.aliyun.com/zh/emr/emr-on-ecs/user-guide/access-web-uis-of-open-source-components/ ｜ 复核：2026-11-16

## 公网访问

| 项 | 官方口径 |
|---|---|
| 挂载公网（创建时） | 默认不开启；**仅 DataLake 集群支持节点组级别挂载公网** |
| 创建后获取公网 | 未开启时可在 ECS 上申请开通公网 IP（EIP） |
| 外网访问控制 | 需要外网访问能力时，官方建议使用 NAT 网关或弹性 IP 实现 |
| 费用 | 挂载公网可能产生额外带宽与流量费用，按 ECS 公网带宽计费口径另计 |
