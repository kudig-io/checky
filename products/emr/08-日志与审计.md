# EMR · 日志与审计

> 产品：EMR ｜ 口径：公共云 ｜ 复核：2026-11-17

## 日志类型总表

| 类型 | 产生方 | 查看入口 | 默认保留期 | 是否计费 |
|---|---|---|---|---|
| 组件/服务日志（hdfs、yarn、hive、spark、flink 等 20 类服务） | EMR 开源组件，经「日志管理」投递日志服务 SLS | EMR 控制台 > 集群 > 日志管理；SLS 控制台 | 📋 待补（官方未标注 Logstore 默认保存时长；可在 SLS 控制台设置日志保存时间） | EMR 侧不收费；SLS 按存储、读取流量、请求数、加工与投递计费 |
| 服务运行日志采集（平台侧采集，供健康检查与售后技术支持） | EMR 平台（ilogtail 采集组件运行日志） | 集群基础信息 > 软件信息 > 服务运行日志收集状态；节点 `/usr/local/ilogtail/user_log_config.json` | 📋 待补（官方未标注保留期） | 官方未标注；关闭采集后健康检查与技术支持受限（仅 DataLake、Hadoop 集群支持健康检查） |
| 作业日志（YARN Application / 数据开发运行记录） | YARN、EMR 数据开发与 Workflow | YARN UI（Knox 代理）应用详情；数据开发 > 工作流实例 > 运行记录 | 📋 待补（OSS 目录未标注保留期，需自配生命周期） | 写入用户 OSS Bucket，按 [OSS](../oss/) 存储计费 |
| 操作事件（事件中心：健康事件 / 操作事件 / 费用事件） | EMR 集群系统事件，自动同步到云监控 | EMR 控制台 > 事件；云监控控制台 > 事件中心（产品选 E-MapReduce） | 操作事件仅展示 3 天内的严重与警告事件（全部页签可查全部事件）；总保留期官方未标注 | 官方未标注 |
| Workflow 审计日志（EMR Workbench 安全中心） | 工作空间成员对项目、工作流、任务、文件的操作 | EMR Workbench > Workflow > 安全中心 > 审计日志 | 📋 待补（官方未标注保留期） | 官方未标注；默认关闭，需手动开启 |
| 审计管控事件（操作审计 ActionTrail） | 操作审计（OpenAPI / 控制台操作） | 操作审计控制台 > 事件查询 | 默认 90 天 | 操作审计本身免费；投递 SLS/OSS 按目标产品计费 |

- 支持日志投递的服务共 20 类：hdfs、yarn、yarn_application、hive、spark、jindodata、tez、flink、hbase、zookeeper、kafka、presto、kudu、impala、flume、starrocks、clickhouse、kyuubi、rss、host（主机）。
- 日志管理仅适用于数据湖（DataLake）、实时数据流（DataFlow）、数据分析（OLAP）、数据服务（DataServing）和数据湖（Hadoop）场景的集群。
- 服务运行日志采集创建集群时默认开启；采集内容仅含集群服务组件运行日志。

## 关键日志详表

**A. 组件日志（SLS 字段，EMR 日志管理投递）**

| 字段 | 说明 |
|---|---|
| `__source__` | 节点的内网 IP 地址 |
| `__tag__:_main_cluster_id_` | EMR 集群 ID |
| `__tag__:_role_` | 节点名称（如 core-1-1） |
| `__topic__` | 日志主题，用于分类日志内容 |
| `content` | 日志原始内容，通常是完整的日志记录 |
| `level` | 日志级别（INFO、WARN、ERROR、DEBUG 等） |
| `message` | 解析后的主要日志信息 |
| `time` | 日志生成时间 |

- 其余字段：`__tag__:__hostname__`（节点 Hostname）、`__tag__:__path__`（日志存储路径）、`__tag__:_ecs_id_`（ECS 实例 ID）、`__tag__:_aliyun_user_id_`（阿里云账号 UID）、`thread`（日志产生的线程）。

**B. 作业日志（YARN 应用运行记录字段）**

| 字段 | 含义 |
|---|---|
| ID | YARN Application ID |
| User | 提交作业的用户 |
| Application Type | 应用类型（如 SPARK、FLINK） |
| State | 应用运行状态 |
| FinalStatus | 应用最终状态（SUCCEEDED / FAILED / KILLED） |
| 运行实例 ID / 开始时间 / 结束时间 / 状态 | 数据开发「运行记录」页签列（可查看详情、提交日志与 YARN 容器列表） |

**C. 审计管控事件（ActionTrail 管控事件结构）**

| 字段 | 含义 |
|---|---|
| `eventTime` | 事件发生时间（UTC 格式） |
| `eventName` | 事件名称（如 AddClusterService、CreateCluster、CloneFlow） |
| `eventSource` | 事件来源 |
| `eventType` | 事件类型（ApiCall / ConsoleOperation / ConsoleSignin 等） |
| `eventRW` | 读写类型（Read / Write） |
| `sourceIpAddress` | 事件发起的源 IP 地址 |
| `userIdentity` | 请求者身份信息（root-account / RAM 用户等） |
| `errorCode` | 云服务处理 API 请求发生错误时记录的错误码 |

## 投递与加工

| 通道 | 去向与参数 | 关键限制 / 配置 | 计费要点 |
|---|---|---|---|
| 组件日志投递 SLS | 自定义 Project；系统在该 Project 下生成专属 Logstore `emr_<服务名>_log`（如 `emr_host_log`） | Project 一经选择不可变更；勾选需投递的服务；RAM 用户需 `AliyunLogFullAccess`；停用前勿删除该 Project/Logstore | EMR 不针对该功能收费；SLS 按 Logstore 计费模式（按使用功能 / 按写入数据量）收费 |
| 日志查询与分析 | EMR 控制台「日志管理」下拉选服务；指定时间段与查询语句实时查询 | 可按字段过滤、统计分布；无专属仪表盘，可自定义 SLS 仪表盘 | 查询、索引按 SLS 计费规则 |
| 关闭日志投递 | EMR 控制台「关闭日志投递」 | 关闭后 Project 不会自动删除，需到 SLS 控制台删除以免持续计费 | 关闭前产生的日志按 SLS 存储继续计费 |
| 服务运行日志采集开关 | 创建集群时「允许采集服务运行日志」；创建后在基础信息 > 软件信息 > 服务运行日志收集状态切换 | 校验：`/usr/local/ilogtail/user_log_config.json` 中无 `namenode-log` 即已关闭 | 官方未标注 |
| 作业日志落 OSS | 数据开发运行记录对应 `oss://<bucket>/emr/spark/<集群ID>/jobs/<作业执行ID>/` 目录 | 需自建 Bucket 并规划生命周期清理 | 按 [OSS](../oss/) 存储计费 |
| 审计事件投递（创建跟踪） | 操作审计创建跟踪 → SLS LogStore 或 OSS Bucket | 用于 90 天以上长期留存（等保 2.0 要求 180 天的场景） | 操作审计免费；投递目标按各自定价计费 |
| 平台操作审计（Inner-ActionTrail） | 联合 SLS 采集 E-MapReduce 平台操作事件到指定 Logstore | 需提交工单/向销售经理申请白名单；只支持创建 1 个跟踪；全部事件投递到 1 个 Logstore | 官方未标注（SLS 侧按 SLS 计费） |

## 审计与合规

| 项 | 官方口径 |
|---|---|
| 接入方式 | E-MapReduce 已与操作审计（ActionTrail）集成，可在操作审计中查询用户通过 OpenAPI、控制台操作 E-MapReduce 产生的管控事件 |
| 事件范围 | 事件表含 AddClusterService（为指定集群添加主版本支持的服务）、AddScalingConfigItemV2（创建弹性伸缩配置项）、AuthorizeSecurityGroup（创建入方向安全组规则）、CancelOrder（取消订单）、CloneFlow（克隆工作流）等；官方注明部分事件含义后续逐步完善 |
| 查询与留痕保留 | 操作审计默认为每个账号保存最近 90 天管控事件，支持在线查询与下载 |
| 长期保存 | 超过 90 天需创建跟踪，将事件投递到 SLS 或 OSS（等保 2.0 要求 180 天留存的场景） |
| 平台操作审计 | Inner-ActionTrail 支持采集 E-MapReduce 平台操作事件；需白名单申请；只支持 1 个跟踪、1 个 Logstore |
| Workflow 审计日志 | EMR Workbench Workflow 安全中心审计日志默认关闭，仅工作空间管理员可查看；记录成员对项目、工作流、任务、文件的操作 |
| 事件中心操作事件 | 仅展示 3 天内级别为严重和警告的操作事件，可忽略（忽略后不再提示）；全部页签可查全部事件 |
| 计费 | 操作审计本身免费；投递到 SLS/OSS 按目标产品计费 |
