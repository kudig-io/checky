# EMR · 计费与生命周期

> 产品：EMR ｜ 口径：公共云 ｜ 复核：2026-11-16

## 计费构成

| 计费项 | 说明 |
|---|---|
| E-MapReduce 服务费用 | 集群多维度管理服务：页面展示与控制、OpenAPI/SDK、弹性伸缩、监控报警、运维工具、服务端自动化运维 |
| ECS 产品费用 | 按集群付费类型决定 ECS 计费方式；创建集群时系统按所选配置自动购买并创建 ECS 实例 |
| 公网费用 | 挂载公网时可能产生额外带宽与流量费用 |
| 关联产品费用 | OSS、数据湖构建 DLF 按各自计费文档另计；EMR Workflow 单独计费 |

- 重要：EMR 服务费用**不支持通过关闭节点停止计费**；ECS 实例未释放会持续产生实例规格计费，需释放全部 ECS 实例才结束计费，释放后数据不可恢复。

## 计费方式与结算规则

| 计费方式 | 结算规则 | 适用场景 |
|---|---|---|
| 包年包月（Subscription） | 预付费；计费周期为订单购买周期，起点为开通/续费时间（精确到秒），终点为到期日次日 00:00:00 | 可预估周期、业务稳定、长期使用 |
| 按量付费（PayAsYouGo） | 后付费；每小时整点结算一次（UTC+8），周期内按秒计费 | 前期研发测试、临时与突发资源 |
| 混合 | 包年包月集群内可新建按量付费或抢占式节点组；弹性伸缩产生的节点按量付费结算 | 包年包月打底 + 按量弹性 |

- 预付费时长可选 1/2/3/6/9 个月、1/2/3 年；控制台默认续费时长 6 个月且默认开启自动续费（到期前 7 天续费）；API 口径默认续费时长 1 个月 ⚠️ 待核（两处口径不同）。
- 计费方式转换：支持按量付费转包年包月；不支持包年包月转按量付费。
- 集群创建后可开启释放保护，防止按量付费集群被意外释放。
- 包年包月到期未续费：系统于到期时间点起停止服务。

## 欠费、到期与释放

| 阶段 | 官方规则 |
|---|---|
| 欠费判定 | 账户资金无法支付上一小时费用即进入欠费；多个集群互不影响 |
| 按量付费欠费 0~24 小时 | 可继续使用集群且继续扣费；余额 <0 时短信/邮件提醒；可参与延期免停权益 |
| 按量付费欠费 24 小时后 | 集群暂停服务且停止扣费；除扩容、升级节点配置等涉费操作外其他运维可用；ECS 实例会释放，任务提交受影响 |
| 欠费 15 天内 | 支持导出服务配置、查看集群信息与操作历史 |
| 欠费 15~60 天 | 无法提交任务 |
| 欠费 60 天后 | 所有运维操作不可用；删除用户业务数据、日志与状态数据、产品配置数据，**删除后不可恢复** |
| 包年包月欠费/到期 | 欠费期间仍可使用已购资源，但不能新购或续费；到期未续费从到期时间点起停止服务；到期后受限操作含服务管理、用户管理、弹性伸缩、扩缩容与升配、APM 展示、引导与脚本操作 |
| 释放保护 | 按量付费集群创建时或创建后可开启，开启后无法直接释放，需先关闭 |
| SLA | EMR 服务可用性 ≥99.9%，赔偿为代金券，最高不超过月度服务费用 50%（详见 01 篇） |
