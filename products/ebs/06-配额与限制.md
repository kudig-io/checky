# EBS · 配额与限制

> 产品：EBS 云盘 ｜ 口径：公共云 ｜ 复核：2026-11-18

配额指单个阿里云账号（主账号）可使用的云资源最大值；提升方式见各表「提升限额」列。

## 云盘数量与实例挂载

| 限制项 | 限制 | 提升限额 |
|---|---|---|
| 单实例系统盘数量 | 1 块 | 无 |
| 单实例数据盘数量 | 由实例规格决定（DescribeInstanceTypes 查询）；创建实例时最多指定 1 系统盘 + 64 数据盘，可在创建后继续挂载 | 无 |
| 单个账号在特定地域和可用区下的云盘容量配额 | 不同类型配额不同，见配额中心「查看或提升块存储配额」 | 可申请提升 |
| 单实例 SSD 本地盘总容量 | 与规格有关，最大 8×7,152 GiB | 无 |
| 本地盘实例挂载新本地盘 | 不允许 | 无 |
| 本地盘实例变更配置 | 仅允许变更带宽 | 无 |

**来源**

- ECS 使用限制与配额：https://help.aliyun.com/zh/ecs/limitations
- 复核：2026-11-16

## 系统盘与挂载点

| 限制项 | 限制 |
|---|---|
| 系统盘容量（Windows Server） | 40~2,048 GiB |
| 系统盘容量（FreeBSD） | 30~2,048 GiB |
| 系统盘容量（其他 Linux） | 20~2,048 GiB |
| 普通云盘作系统盘 | 容量上限 500 GiB（上一代产品，逐步停售） |
| Linux 系统盘挂载点 | /dev/vda |
| Linux 数据盘挂载点 | 1~25 块：/dev/vd[b-z]；>25 块：/dev/vd[aa-zz]（第 26 块为 /dev/vdaa） |

## 快照配额与硬限制

| 限制项 | 限制 | 提升限额 |
|---|---|---|
| 单块云盘手动快照 | 2,000 | 无 |
| 单块云盘自动快照 | 2,000 | 无 |
| 单块云盘归档快照 | 10,000 | 无 |
| 单账号单地域自动快照策略 | 100 | 无 |
| 单块云盘自动快照策略 | 10 | 无 |
| 单块云盘并发创建快照 | ESSD 系列：10；上一代云盘：1 | 无 |
| 单块云盘并发归档快照 | 10 | 无 |
| 不支持快照的类型 | ESSD PL-X、本地盘、弹性临时盘 | 无 |
| 快照一致性组 | 仅 ESSD/AutoPL/Entry，且未开启多重挂载 | 无 |
| 下载/导出快照 | 不支持（可先建自定义镜像再导出） | 无 |

## 多重挂载与其他

| 限制项 | 限制 |
|---|---|
| 多重挂载单盘挂载实例数 | 最多 16 台 |
| 多重挂载云盘 | 仅单独创建时开启、仅数据盘、仅按量付费 ESSD/AutoPL/同城冗余 |
| SCU 单次购买最大容量 | 50 TiB（提升：提交工单） |
| SCU 单地域最大购买数 | 100 |
| SCU 抵扣 | 仅按量付费账单，不支持抵扣抢占式实例中云盘的按量账单 |
| 块存储 API 速率配额 | 2021-07-30 版高阶 API 可申请提升；2014-05-26 版暂不支持提升 |
