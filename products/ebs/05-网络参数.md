# EBS · 网络与挂载参数

> 产品：EBS 云盘 ｜ 口径：公共云 ｜ 复核：2026-11-16

云盘本身没有公网/带宽概念，其「网络相关」事实集中在弹性性能、多实例共享挂载与可用区约束上。

## ESSD AutoPL 弹性性能（性能突发）

| 项 | 数值/规则 |
|---|---|
| 性能组成 | 基准性能 + 预配置性能 + 性能突发（默认开启） |
| 突发 IOPS 上限 | 容量≥4 GiB：min{100 万, 1,000×容量}；容量≤3 GiB 不支持突发 |
| 突发吞吐上限 | max{min{16 KB×IOPS/1,024, 4 GB/s}, 基准+预配置吞吐} |
| 最大 IO 密度 | 1,000 IOPS/GiB |
| 突发免费额度 | 每小时突发 IO 总量 ≤10 万：免费 |
| 突发计费 | 超 10 万部分按小时计费；突发 IO 量折算：仅 IOPS 突发按 Σ突发IOPS×时长；仅吞吐突发按 Σ突发吞吐/16 KB×时长；两者都突发按较大者计费，向上取整到万 |
| 突发费用封顶 | 计量周期内最大突发 IO 密度 >200 IOPS/GiB 时封顶：费用 = min((突发IO−10)万×突发单价, 云盘容量费用×8) |
| 欠费影响 | 预配置/突发按量账单欠费：立即停止该两项服务，**基准性能不受影响**；结清后立即恢复 |

## 共享盘多重挂载

| 项 | 规则 |
|---|---|
| 最大挂载实例数 | 单块云盘最多挂载至 **16 台**实例 |
| 支持云盘类型 | 仅按量付费的 ESSD 云盘、ESSD AutoPL、ESSD 同城冗余；仅数据盘，仅单独创建时开启，存量盘不可开关 |
| 实例要求 | 实例规格族需默认支持 NVMe 协议（DescribeInstanceTypes 的 NvmeSupport 参数） |
| 镜像要求 | 镜像需包含 NVMe 驱动（DescribeImages 的 NvmeSupport 参数） |
| 可用区 | 挂载至**同一可用区**内支持 NVMe 协议的多台实例；地域及可用区与支持的实例规格族售卖范围一致 |
| 性能共享 | 所有 ECS 实例的性能总和不能超过该云盘的性能上限 |
| 功能费用 | 多重挂载功能本身不收费；涉及云盘、ECS 实例等资源正常计费 |
| 禁止操作 | 随实例释放、控制台分区、转换计费方式、重新初始化、变更云盘类型、修改 PL、快照一致性组 |
| 文件系统 | ext3/ext4/xfs/ntfs 等单节点文件系统多实例数据不同步；需集群文件系统（OCFS2、GFS2、Veritas CFS、Oracle ACFS、DBFS 等） |

**来源**

- 云盘多重挂载功能：https://help.aliyun.com/zh/ecs/user-guide/enable-multi-attach
- 复核：2026-11-16

## 盘与实例同可用区约束

| 约束 | 事实 |
|---|---|
| LRS 云盘 | 仅能挂载至与云盘**相同可用区**的实例 |
| 同城冗余云盘 | 可挂载至**同地域任意可用区**的实例 |
| 本地盘 | 数据在实例所在物理机，天然同机同可用区；不支持自行挂载新本地盘 |
| 多重挂载 | 所有目标实例必须在同一可用区 |
| 云盘独立性 | 数据盘可单独创建，与实例生命周期独立；系统盘随实例创建、同生命周期 |

## NVMe 协议挂载

- 多重挂载场景通过 NVMe 协议挂载云盘，NVMe PR（PersistentReservation）命令可精确控制云盘读写权限，用于主备故障转移。
- 云盘可支持 NVMe 协议挂载与多重挂载（ESSD 系）。
