> 产品：EBS 云盘 ｜ 口径：公共云 ｜ 复核：2026-11-18

## 快照原理与类型

| 项 | 事实 |
|---|---|
| 原理 | 以数据块为备份最小单元；第一份标准快照为全量，备份所有数据块；后续标准快照均为增量，仅备份自上次快照后新增或修改的数据块 |
| 存储位置 | 默认存储在对象存储 OSS（用户不可见 Bucket）；OSS 支持同城冗余的地域默认用同城冗余 Bucket，否则本地冗余 Bucket |
| 快照类型 | 默认均为标准快照（Standard Snapshot），可转换为归档快照（Archive Snapshot）；归档不可还原为标准快照 |
| 极速可用 | 快照创建后秒级可用，无需等待 100% 上传 OSS；仅 ESSD 系列云盘（ESSD、AutoPL、Entry、同城冗余）支持 |
| 加密 | 加密云盘的快照自动继承加密属性，复制到其他地域或恢复后仍为加密状态 |
| 下载/导出 | 不支持直接下载或导出快照；可先建自定义镜像再导出镜像 |

## 保留时间与归档规则

| 类型 | 保留时间 |
|---|---|
| 标准快照 | 1~65,536 天，或永久保留 |
| 归档快照·标准层 | 不可修改；标准快照保留 ≥14 天才能归档 |
| 归档快照·归档层 | 60 天~（65,536 天−标准层保留时间），或永久保留 |
| 归档最短保留 | 60 天（1,440 小时）；60 天内提前删除需另付归档快照不足规定时长费 |

## 快照数量上限

| 限制项 | 数值 |
|---|---|
| 单块云盘保留的手动快照 | 2,000 |
| 单块云盘保留的自动快照 | 2,000 |
| 单块云盘保留的归档快照 | 10,000 |
| 单账号单地域自动快照策略 | 100 |
| 单块云盘可设置的自动快照策略 | 10 |
| 单块云盘并发创建快照任务 | ESSD 系列（ESSD/AutoPL/Entry/同城冗余）：10；上一代云盘：1 |
| 单块云盘并发归档任务 | 10 |
| 不支持快照的类型 | ESSD PL-X、本地盘、弹性临时盘 |
| 快照一致性组 | 仅 ESSD 系列（ESSD/AutoPL/Entry）支持，且云盘未开启多重挂载 |

已核（2026-11-18 复核《快照极速可用》原页）：旧版（2023-10-12 11:00 前创建）单块云盘可保留的启用极速可用快照为 10 个；新版与单块云盘支持创建的快照数量一致（无独立上限，见快照概述），且 2023-10-12 起全地域不收取极速可用功能费。

## 跨地域复制快照参数

| 复制类型 | 支持范围 | 首次复制容量 | 费用 |
|---|---|---|---|
| 普通复制（非加密→非加密） | 仅跨地域 | 同一目标地域首次为完整快照容量，后续仅增量 | 快照存储费 + 复制流量费 |
| 加密复制（非加密→加密/加密→加密） | 同地域或跨地域 | 首次为完整云盘容量（非加密首次加密复制）或完整快照容量，后续增量；密钥变更会重新全量 | 存储费（+跨地域流量费）+ KMS 加密费（默认密钥免费） |

复制使用限制：

| 限制 | 说明 |
|---|---|
| 归档快照 | 不支持复制 |
| 保留时间/标签 | 不支持同时复制；控制台复制默认永久保留，API CopySnapshot 可指定保留时间 |
| 回滚 | 复制后的快照 ID 与原快照不同，不能用于回滚云盘 |
| 极速可用 | 复制后的快照不支持极速可用能力 |
| 类型转换 | 标准快照仅支持复制为标准快照 |
| 计费周期 | 从创建时间点所在整点开始计费，至删除时间点所在整点停止 |
