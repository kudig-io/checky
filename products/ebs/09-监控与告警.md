# EBS · 监控与告警

> 产品：EBS 云盘 ｜ 口径：公共云 ｜ 复核：2026-11-17

## 核心监控指标

云盘监控数据有三路来源：ECS 基础监控（宿主机采集，粒度 1 分钟）、操作系统监控（云监控插件采集，15 秒粒度，需安装插件）、块存储数据洞察 CloudLens for EBS（秒级，5 秒粒度）。分钟级/秒级数据也可经 API 查询：`DescribeDiskMonitorData`（Period 60/600/3600 秒，仅使用中云盘，最多查近 30 天）、EBS `DescribeMetricData`（Period 5/10/60/300/600/3600 秒）、`DescribeSnapshotMonitorData`（快照容量，Period 60/600/3600 秒）。

| 指标（官方英文名） | 含义 | 单位 | 统计周期 | 维度 |
|---|---|---|---|---|
| DiskReadIOPS | （ECS）所有磁盘每秒读取次数（实例全部云盘合计，基础监控） | 次/秒 | 1 分钟 | userId、instanceId |
| DiskWriteIOPS | （ECS）所有磁盘每秒写入次数 | 次/秒 | 1 分钟 | userId、instanceId |
| DiskReadBPS | （ECS）所有磁盘每秒读取字节总数 | Byte/s | 1 分钟 | userId、instanceId |
| DiskWriteBPS | （ECS）所有磁盘每秒写入字节总数 | Byte/s | 1 分钟 | userId、instanceId |
| disk_readiops | （Agent）单块云盘每秒的读请求数量 | 次/秒 | 15 秒 | userId、instanceId、device |
| disk_writeiops | （Agent）单块云盘每秒的写请求数量 | 次/秒 | 15 秒 | userId、instanceId、device |
| disk_readbytes | （Agent）单块云盘每秒读取的字节数 | Byte/s | 15 秒 | userId、instanceId、device |
| diskusage_utilization | 磁盘使用率（普通用户已用容量占云盘容量的比例） | % | 15 秒 | userId、instanceId、device |
| fs_inodeutilization | inode 使用率（仅 Linux；inode 耗尽时云盘未满也无法新建文件） | % | 15 秒 | userId、instanceId、device |
| LatencyRead / LatencyWrite | 云盘读时延 / 写时延（DescribeDiskMonitorData 返回字段） | μs | 60 / 600 / 3600 秒 | DiskId |
| disk_iops_percent / disk_bps_percent | 云盘 IOPS / 吞吐量占规格上限的比例（即 IOPS、BPS 水位线，数据洞察指标） | % | 5 / 10 / 60 / 300 / 600 / 3600 秒 | DiskId、DeviceType、DeviceCategory、EcsInstanceId、Azone |
| Size（DescribeSnapshotMonitorData） | 地域内快照总容量随时间的变化 | Byte | 60 / 600 / 3600 秒 | RegionId、Category（Standard / Flash / Archive） |

- 水位线两个指标的单位按云盘分析《指标说明》口径（占云盘 IOPS/吞吐量上限的比例，%）；EBS `DescribeMetricData` 文档本身未标注单位。
- 秒级监控指标值为云盘 5 秒内监控数据的最大值，且有 1~5 分钟延迟；5 分钟/15 分钟范围仅支持查询最大值。
- 云盘分钟级 IOPS、吞吐量、延迟在 ECS 控制台 → 块存储 → 云盘 → 监控 页签查看；秒级在 EBS 控制台 → 数据洞察 → 云盘分析 查看；使用率与 inode 使用率在云监控 → 主机监控 → 云盘 页签查看。

## 官方默认与推荐告警

**A. 官方默认告警（ECS 一键报警）**

| 监控项 | 阈值与触发条件 | 等级 | 覆盖范围 | 性质 |
|---|---|---|---|---|
| 磁盘使用率（同时含 CPU 使用率、内存使用率、网络带宽使用率） | 连续 5 次平均值大于 95 | 官方未标注等级 | 阿里云账号下所有 ECS 实例 | 官方默认（开启一键报警后系统自动创建，可在规则详情下禁用或删除） |

**B. 官方内置事件（无需配置阈值）**

| 事件 | 触发条件 | 事件等级 / 类型 | 上报频率 |
|---|---|---|---|
| 块存储系统事件（`Disk:Stalled:Executing` / `Disk:Stalled:Executed`） | 块存储性能受到严重影响（`eventType` 取值 `Degraded` / `SeverelyDegraded` / `Stalled`） | `CRITICAL` | 事件发生与结束时各发一次通知 |
| 数据盘挂载/卸载完成（`Disk:DiskOperationCompleted`） | 数据盘完成挂载或卸载（`operation` 为 `AttachDisk` / `DetachDisk`） | 成功 `INFO` / 失败 `WARN` | 操作完成时上报 |
| 数据保护（CloudLens 云盘事件） | 云盘长时间没有创建快照备份数据 | `Alert` / `Warn` | 每天上午上报 |
| 云盘有 IO Hang 发生（CloudLens 云盘事件） | 云盘内文件系统因读写 IO 延迟过高导致系统不稳定或宕机 | `SystemException` / `Warn` | 实时上报 |
| 云盘 IOPS 达到云盘上限（CloudLens 云盘事件） | 云盘实时 IOPS 达到其规格上限 | `Notification` / `Warn` | 官方未标注上报频率 |
| 突发 IO（CloudLens 云盘事件） | ESSD AutoPL 云盘发生突发 IO，可能产生突发性能费用 | `Notification` / `Info` | 每隔 1 小时监测过去 1 小时 |

**C. 指标阈值类告警**

- 云盘 IOPS、吞吐量、时延、水位线、磁盘使用率、快照容量等指标的阈值告警：**官方未发布推荐阈值** 📋 待补（官方文档仅提供创建报警规则的操作说明，未给出云盘类指标的推荐阈值；按阈值红线不收经验值）。

## 通知与渠道

| 渠道 / 机制 | 说明 |
|---|---|
| 通知方式 | 基础云监控自定义报警的通知方式包括电话、短信、邮件、钉钉机器人、阿里云 App 通知 |
| 报警联系人组 | 创建报警规则时选择报警联系人组；事件通知按报警联系人中配置的手机号、邮箱等发送 |
| 报警回调（Webhook） | 填写公网可访问的 URL，云监控通过 POST 请求推送报警信息，目前仅支持 HTTP 协议 |
| 事件通知分发 | 云监控事件可分发到消息队列、日志服务、函数计算、Webhook，用于自动化处理；事件量大或时延要求高时官方建议改用 EventBridge 订阅 |
| CloudLens 周期报告 | CloudLens for EBS 应用管理按标签筛选云盘/快照，以邮件或站内信发送报告，周期可选每周 / 每双周 / 每月 |
| ActionTrail 事件告警 | 操作审计支持事件告警：模板规则（账号连续登录失败、Root 账号连续登录、未授权 IP 登录、非工作时间登录等）+ 自定义字段与告警条件 |
| 通道沉默周期 | 报警发生后如果未恢复正常，间隔多久重复发送一次报警通知 |
| 生效时间 | 报警规则只在有效时段内检查监控数据；不指定生效时间则全天生效 |
| 报警黑名单 | 支持报警黑名单策略，对某个监控指标屏蔽报警通知 |
| 告警升级策略 | 官方未发布云盘/块存储告警升级（Escalation）策略 📋 待补 |
