## 节点与集群配额

| 项目 | 数值/机制 |
|---|---|
| 只读节点数（企业版·集群版） | 最多 15 个，最少保留 1 个（最后一个不可删） |
| 只读节点数（标准版） | 最多 7 个 |
| 只读节点数（多主 Limitless） | 最多 15 个全局只读节点；读写节点最多 63 个 |
| 单节点形态 | 单节点产品系列已下线；购买时只读节点数设 0 可得单节点集群 |
| Serverless 只读节点伸缩 | 下限/上限均 0~15 |
| Serverless 单节点资源弹升 | 0~16 PCU |
| 账号下集群总数（每地域默认配额） | 官方文档未见明确默认值 ⚠️ 待核（可在配额中心查看 API 流控类配额） |
| API 流控配额 | 配额中心按 API 维度查看（如 200 次/60 秒），可申请提升 |

## 连接、文件与对象硬限制

| 项目 | 数值 |
|---|---|
| 最大连接数 | 单节点维度；`max_connections` 参数取值 1~200000；默认值随规格（1,000~150,000） |
| 数据库个数 | 上限 1 万个（受文件数量限制） |
| 单表最大数据量 | 64 TB |
| 表数量 | 无个数限制；InnoDB 最多 40 亿张表；建议每 GB 空间最多 512 个表 |
| 表名长度 | 字母/数字 ≤64 字符；汉字 ≤50 字符 |
| 隔离级别 | Serializable 不支持 |
| 超级用户 | 不支持 |
| 文件个数上限（企业版） | 按规格 1,024,000~131,072,000（inode）；文件系统占用内存 800 MB~10,240 MB |
| 文件个数上限（标准版 ESSD） | inode 6,707,200、blktag 8,384,000（各规格） |

- 文件数达上限会报 `ERROR 3017: Too many files ... 2048 files every 10 GB disk size`，需删表或升配。

## 备份与保留限制

| 项目 | 数值 |
|---|---|
| 一级备份保留 | 3~14 天（默认 7 天） |
| 二级备份保留 | 同地域 30~7300 天；跨地域 30~7300 天或 -1 长期保留；默认关闭 |
| 数据备份（ESSD）保留 | 3~730 天 |
| 备份周期 | 每周至少选 2 天（常规备份）；高频 2/24H、3/24H、4/24H |
| 删除集群时备份保留 | 默认 NONE；可选 ALL / LATEST |
| 集群回收站保留 | 最长 7300 天 |
| 回收站欠费释放 | 账号欠费超 14 天自动释放回收站内备份集，不可恢复 |

## 部署与地域限制

- 单集群支持跨可用区、不支持跨地域。
- 不支持多可用区部署的地域：华北 1（青岛）、华北 5（呼和浩特）、西南 1（成都）、韩国、菲律宾、泰国（曼谷）。
- 三可用区（存储热备 + Logger 节点）仅支持新购时选择。
- GDN 中的集群不支持 2 核 4 GB、2 核 8 GB 规格。
- 读写节点（RW）仅 Limitless 系列支持添加；列存/AI/搜索节点需集群版本满足功能限定。
