# PolarDB · 集群与节点规格

> 产品：PolarDB ｜ 口径：公共云 ｜ 复核：2026-11-16

## 节点类型

| 节点类型 | 说明 |
|---|---|
| 主节点（读写节点） | 一个集群只有 1 个，处理读写请求；集群 ID 以 pc 开头、节点 ID 以 pi 开头 |
| 只读行存节点 | 基于行存储处理读请求，OLTP 读性能更高；集群初始含 1 个 |
| 只读列存节点（列存索引 IMCI） | 基于列存储处理读请求，OLAP 复杂查询性能远超行存节点；新增时建议规格高于主节点 |
| AI 节点 | PolarDB for AI 功能节点，删除最后一个 AI 节点会立即清除向量表等关联数据 |
| 搜索节点（PolarSearch） | 兼容 Elasticsearch REST API；删除所有搜索节点会清除关联数据 |
| 热备节点 | 为只读节点开启热备功能后的节点，用于快速主备切换与事务保持 |
| Logger 节点 | 三可用区部署形态中的日志节点（存储热备 + Logger 节点方案） |

- 官方文档未见「仲裁节点」这一 PolarDB 节点类型 ⚠️ 待核（PolarDB 使用 Paxos/Raft 多数派机制，非仲裁节点形态）。
- 读写节点（Limitless 的 RW 节点）仅多主集群系列可添加；标准版与集群版不支持。
- 单节点产品系列已下线；购买时可将只读节点个数设为 0 得到单节点形态集群。

## 规格族命名（子系列）

| 子系列 | 命名特征 | 特点 | 适用 |
|---|---|---|---|
| 通用规格 | `polar.mysql.g*`（如 g4.large） | 同一服务器上不同集群互相复用空闲 CPU，性价比高 | 有降本诉求、高性价比场景 |
| 独享规格 | `polar.mysql.x*`（如 x4.large） | 集群独占分配的计算资源，不与同服务器其他集群共享 | 金融、电商、政务等性能稳定性要求高场景 |
| 通用规格（标准版 ESSD） | 规格码带 `.c` 后缀（如 g4.large.c） | 存储为 ESSD 云盘 | 标准版 |
| Limitless 专用规格码 | 带 `mm`（如 mmg4.large、mmx4.large） | 仅多主集群系列 | Limitless |

- 通用/独享规格中的数字后缀（g2/g4/g8、x4/x8）对应内存配比：g2 = 1:2、g4 = 1:4、g8 = 1:8（如 g4.large = 4 核 16 GB、x8.large = 4 核 32 GB）。
- 通用规格与独享规格可在线变配；只读节点规格可与主节点不一致。

## 选型速查（选型指南口径）

| 维度 | 标准版 | 企业版·集群版 | 企业版·多主（Limitless） |
|---|---|---|---|
| 内核版本 | 5.6/5.7/8.0.1/8.0.2 | 5.6/5.7/8.0.1/8.0.2 | 仅 8.0.1/8.0.2 |
| CPU 架构 | X86 / 倚天 ARM（仅 8.0.1） | X86 | X86 |
| 默认最大连接数（最高规格） | 独享 6.4 万 / 通用 1.6 万 | 独享 15 万 / 通用 3.2 万 | 独享 10 万 / 通用 3.2 万 |
| 最大存储 | 64 TB（PL0 32 TB） | 500 TB | 500 TB |
| 最大 IOPS（单只读节点上限） | 通用云盘多节点总和 5 万（IO 突发至 100 万） | 通用 PSL5 8.4 万 / 独享 PSL5 52.3 万 | 通用 PSL5 12.6 万 / 独享 PSL5 38.4 万 |
| GDN | 不支持 | 支持 | 不支持 |
| 弹性并行查询 ePQ | 单机并行（8.0.1） | 单机并行 8.0.1/8.0.2；多机并行 8.0.2 | 单机并行 8.0.1/8.0.2；多机并行 8.0.2 |
| 应用场景 | 个人学习测试、初创；多节点支持大中型读多写少 | 大中型企业生产库、金融核心库 | SaaS 多租户、游戏、电商高并发读写 |

- 负载偶发/剧烈波动 → Serverless；负载平稳 → 包年包月或按量付费（固定规格）。
- 新建库推荐 MySQL 8.0.1 / 8.0.2；迁移上云建议保持原内核版本。

## 节点增删与规格搭配限制

- 新增只读节点内存不得小于主节点内存的一半。
- 只读节点最小 CPU 规格（按主节点 CPU）：2→2、4→4、8→4、16→8、32→16、64→32、88→64、120→64；Limitless 不受此限制。
- 增加 1 个只读节点预计耗时约 5 分钟；多节点并行处理。
- 删除节点时该节点连接闪断，其他节点不受影响；连接集群地址时应用无需改配置。
- 不支持暂停单个只读节点；集群版需保留至少 1 个只读节点，最后一个不可删除。
- 只读节点价格与主节点一致；增加只读节点不增加存储容量（存算分离）。
