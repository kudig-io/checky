# PolarDB · 计费与生命周期

> 产品：PolarDB ｜ 口径：公共云 ｜ 复核：2026-11-16

## 计费类型

| 类目 | 包年包月（预付费） | 按量付费（后付费） | Serverless（后付费） |
|---|---|---|---|
| 计算节点资源 | 固定规格 | 固定规格 | 动态资源（PCU） |
| 计费周期 | 按购买时长 | 秒级计费，按小时结算 | 秒级计费，按小时结算 |
| 适配资源包 | 存储包 | 存储包、固定规格计算包 | 存储包、Serverless 计算包（固定规格开 Serverless 后亦可用） |
| 转换付费类型 | 可转按量付费（需关闭并退订自动续费；按空间计费的包年包月存储不支持转） | 可转包年包月 | 不支持转换 |

- 适用场景：包年包月=可预估、波动小；按量=不可预估、临时突发；Serverless=个人开发、IoT/边缘等不确定负载。
- 部分计费项仅支持按量付费（后付费）：备份存储、SQL 洞察、冷数据归档等，包年包月集群同样会按量产生这些账单。

## 计费项总览

| 计费项 | Code | 说明 | 支持计费类型 |
|---|---|---|---|
| 计算节点 | master_spec | 主节点+只读节点；与地域、规格、时长相关；Serverless 按每 PCU 每秒计费、按小时出账 | 包年包月 / 按量 / 按量+固定规格计算包 / Serverless / Serverless+计算包 |
| 存储空间 | ESSD：SEStorage；PSL4/5：包年包月 storage_space、按量 master_disk_size | 数据文件、索引、日志、临时文件占用；按数据量与时长 | 包年包月 / 按量 / 按量+存储包 / Serverless |
| 备份存储（超免费额度） | data_backup / level1_backup / level2_backup / log_backup | 超出免费额度部分按量计费；单独计费，包年包月不含 | 按量 / 按量+存储包 |
| SQL 洞察（可选） | sql_explorer | DAS 提供，审计日志容量与时长计费，有免费额度 | 按量 |
| 冷数据归档（可选） | colddata | 冷表转存 OSS，容量与时长计费 | 按量 / 按量+存储包 |
| 全球数据库网络 GDN（可选） | - | 跨地域传输暂不收费，仅收各集群自身费用 | 不涉及 |
| 多可用区（可选） | - | 暂不收费 | 不涉及 |

- 存储计费类型：企业版存储可单独配置按容量计费（按量，按实际用量每小时计费）或按空间计费（包年包月，预指定上限预付）；标准版存储跟随计算节点计费类型。
- Serverless 开启「无活动暂停」后，暂停期间不收计算节点费；存储、备份超额度、SQL 洞察照常收费。
- 账单示例口径（仅供参考非定价）：计算节点 1.77 元/小时、存储 0.00243 元/GB、一级备份 0.003 元/GB/小时、二级备份 0.00021 元/GB、冷数据 0.00021 元/GB。

## 资源包

| 资源包 | 抵扣对象 | 关键规则 |
|---|---|---|
| 存储包 | 存储空间 + 备份存储 + 冷数据归档 | 分「中国内地通用」「中国香港及海外通用」两地域范围，范围内所有集群共享；可叠加、可升级，不支持降级；按容量计费集群搭配最高可享按量 55 折 |
| 固定规格计算包 | 按量付费集群的计算节点费用 | 按「度」消耗：1 个 4 核 16 GB 节点 = 0.04 度/小时；示例集群（1 主 2 只读同规格）= 0.12 度/小时 |
| Serverless 计算包 | Serverless 动态资源（含固定规格集群开 Serverless 后的弹升部分） | 按 CU·H 抵扣；账号下所有地域符合条件集群通用 |

- 超出存储包容量的部分按量付费；存储包容量不足可叠加购买或升级。
- 价格计算器、资源包计算器可用于估价与规格建议。

## 包年包月到期规则

| 时间点 | 状态 | 费用 | 恢复方式 |
|---|---|---|---|
| 到期前 168/72/24 小时 | 正常 | — | 系统电话、短信、邮件提醒 |
| 到期日 | 停机、锁定、无法访问 | 计算节点、存储空间、SQL 洞察不收费；备份超免费额度与冷数据归档仍按标准计费 | 手动续费解除锁定 |
| 到期后第 8 天（停机 7 天后） | 集群释放（释放前 1 天短信/邮件提醒） | — | 视备份策略：长期保留 → 进入集群回收站（收费）；立即删除 → 彻底释放不可恢复 |

## 欠费规则（按量付费与 Serverless）

| 阶段 | 规则 |
|---|---|
| 欠费但在延期免停权益额度内 | 集群不停机，每天短信提醒一次；按各计费项总览正常计费；充值后解除锁定 |
| 超出延期免停额度 | 集群停机、锁定、无法访问；计算节点、存储、SQL 洞察停收费；备份超免费额度与冷数据归档仍计费 |
| 停机后第 8 天 | 集群释放（释放前 1 天提醒）；备份按策略进回收站或彻底删除 |
| 回收站 | 账号欠费超 14 天自动释放回收站内备份集，不可恢复 |
| ESSD 满载锁定 | 云盘预留 3 GB 空间防写满损坏；满载时锁定为只读不写，需扩容或开自动扩展 |

- 释放/退订后仍可能出账：后付费账单延迟出账；或包年包月集群存在按量计费的存储/备份项。
- 包年包月集群无法直接释放，需走退订流程；按量付费「运行中」集群可手动释放。
