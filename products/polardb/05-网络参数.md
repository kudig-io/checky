## 集群地址体系（Endpoint）

| 地址类型 | 数量 | 说明 |
|---|---|---|
| 主地址（Primary Endpoint） | 每集群有且仅有 1 个 | 始终连接主节点，支持读写；主节点故障 Failover 后自动指向新主节点；请求不经过 Proxy |
| 集群地址（Cluster Endpoint，默认） | 每集群 1 个（推荐使用） | 由数据库代理提供服务，支持自动读写分离、负载均衡、一致性协调；可设为只读或可读可写 |
| 自定义地址 | 最多再创建 5 个 | 由数据库代理提供；可配置读写模式与负载均衡策略，用于业务隔离；最少挂载 1 个只读节点 |
| 单节点地址（自定义地址特例） | 仅集群地址读写模式为只读且集群 ≥3 节点时可创建 | 该节点故障时地址可能最多 1 小时不可用，官方警告勿用于生产 |

- 默认集群地址与自定义地址的请求经过 Proxy；主地址不经过。
- 会话 ID < 16,777,215 为主地址连接，否则为集群地址连接。
- 只读模式下集群地址在所有只读节点间均衡分配连接（主节点不参与）；可用业务连接总数 = 所有只读节点连接数之和。

## VPC 与端口

| 项 | 官方口径 |
|---|---|
| 网络类型 | 集群创建时默认生成 1 个私网连接地址（支持修改、不可释放）；公网地址需申请、可释放 |
| VPC/交换机 | 创建集群时选定 VPC 和交换机；集群版支持修改单个连接地址的 VPC 和交换机 |
| 默认端口 | PolarDB MySQL 版默认 3306，可自定义 |
| 可设端口范围 | 3000~5999 |
| 私有域名 | 仅私网连接地址支持绑定私有域名 |
| 白名单/安全组 | 仅白名单内 IP 或安全组内 ECS 可访问集群；所有节点共享同一套账号密码 |
| 外网带宽上限 | 10 Gbit/s |
| 最佳性能 | 同 VPC 私网访问最佳；公网访问无法发挥最佳性能 |

## 数据库代理（Proxy）配置项

| 配置项 | 取值/说明 |
|---|---|
| 读写模式 | 只读 / 可读可写（自动读写分离）；修改后仅对新建连接生效 |
| 服务节点 | 从主节点和所有只读节点中选择加入该地址处理读请求的节点 |
| 负载均衡策略 | 基于连接数（默认）/ 基于活跃请求数 |
| 一致性级别 | 可读可写模式：最终一致性（弱，默认）/ 会话一致性（中）/ 全局一致性（强）；只读模式默认最终一致性且不可改 |
| 新节点自动加入 | Enable（默认 Disable）：新节点是否自动加入本地址 |
| 事务拆分 | 开启/关闭：把事务中部分查询路由到只读节点，降低主库负载 |
| 主库是否接受读 | 开启后主库不接收读请求，减少读请求路由到主库 |
| 连接池 | 会话级连接池 / 事务级连接池 |
| 全局一致性读超时 | 超时后自动降级为非一致性读取，客户端不报错 |
| 并行查询/并行度 | 仅 MySQL 8.0 版本集群在代理配置中支持开启并行查询和设置并行度 |
| 单节点地址挂载 | 只读模式下支持；节点故障地址最多 1 小时不可用，勿用于生产 |

- 修改一致性级别后对该地址所有连接立即生效。
- 权重置 0 后已建立的连接仍会发往该只读节点；移除节点前建议切到「基于活跃请求数负载均衡」。
