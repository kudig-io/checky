## 计费组成

| 集群类型 | 集群管理费用 | 云产品资源费用 | 灵骏节点管理费 | 混合云/边缘节点管理费 |
|---|---|---|---|---|
| ACK 托管集群 Pro 版 | 涉及 | 涉及 | 仅配置灵骏节点池时涉及 | 仅配置混合云/边缘节点时涉及 |
| ACK 托管集群基础版 | 不涉及 | 涉及 | 不涉及 | 不涉及 |
| ACK 专有集群 | 不涉及 | 涉及（Master+Worker 均收费） | 不涉及 | 不涉及 |

- 仅 ACK 托管集群 Pro 版收取集群管理费用，按集群个数和使用时长计费。
- 灵骏节点管理费（2025-08-05 起商业化，按天出账）：按 GPU 卡数阶梯——1~100 卡 10 元/卡/天、100~500 卡 8 元/卡/天、500~1000 卡 6 元/卡/天、1000 卡以上 4 元/卡/天（2026-11-18 复核计费页）。
- 混合云/边缘节点管理费（仅托管 Pro 版节点池中存在对应节点时收取）：0.005 元/vCPU/小时、0.25 元/GPU 卡/小时（单一节点收 GPU 卡费后不再收 vCPU 费）；官方注明邀测期间该节点管理费免费，集群管理费与云产品资源费照常收取（2026-11-18 复核）。
- ACK Edge 集群：Pro 版收集群管理费 0.64 元/小时 + 边缘节点管理费 0.2 元/vCPU/天（支持 500 vCPU 资源包抵扣）；基础版不收集群管理费（2026-11-18 复核计费说明）。
- ACK Serverless：基础版不收集群管理费，Pro 版集群管理费公测免费；仅按 Pod 的 CPU/内存等云产品资源计费（2026-11-18 复核计费说明）。

## 集群管理费（Pro 版）

| 控制面档位 | 单集群管理费（元/小时） |
|---|---|
| Pro 版（ACK Pro 控制面） | 0.64 |
| Pro XL 版（预设控制面） | 9.10 |
| Pro 2XL 版（预设控制面） | 21.80 |
| Pro 4XL 版（预设控制面） | 50.90 |

- ACK Pro 集群包含 ACK 托管集群 Pro 版及预设控制面版本（Pro XL、Pro 2XL、Pro 4XL）。
- 公共云不同地域、金融云、政务云单价可能不同，实际价格以控制台为准。
- 计费周期为小时，按整点对齐（UTC+8）；集群创建的第一个计费周期和释放的最后一个计费周期不计费；账单通常在周期结束后 10~30 分钟内生成。
- 收费状态：运行中（running）、升级中（upgrading）、节点排水中（draining）、节点移除中（removing）、配置变更中（updating）。

## 欠费与退款

| 项目 | 规则 |
|---|---|
| 欠费判定 | 账号可用额度 < 待结算账单 |
| Pro 版欠费影响 | 欠费后 15 天内集群处于不活跃（inactive），无法访问 API Server，按量付费云产品资源可能被停机或释放；欠费超过 15 天集群将被删除 |
| 基础版/专有集群欠费影响 | 集群状态不受影响，但按量付费云产品资源可能被停机或释放；欠费超过 15 天集群将被删除 |
| 集群管理费退款 | 不涉及退款（已按实际使用计费） |
| ACK 资源包退款 | 仅支持未使用的资源包退款，已使用余量不退 |
| 停止计费方式 | 删除集群和关联的云产品资源 |

## 生命周期要点

| 事件 | 规则 |
|---|---|
| 集群创建前置条件 | 实名认证 + 开通 ACK + 账户余额 ≥100 元（按量资源） |
| 集群升级 | 控制面逐级升级、不回退；节点池可跨版本升至控制面版本（灰度）；过期版本会被强制升级（提前至少 1 个月通知） |
| 集群维护窗口 | ACK 仅在维护窗口内执行自动化运维（自动升级、OS CVE 修复） |
| 类型变更 | 仅支持热迁移：基础版→Pro 版、专有集群→Pro 版 |
| 集群删除 | 开启删除保护可防误删；删除集群后关联云产品资源需自行清理（如 Edge 边缘节点池系统组件） |
