## 单集群规模上限（Pro 版）

| 维度 | ACK 托管集群 Pro 版 |
|---|---|
| 单集群最大节点数（Terway） | 默认 5,000 个；ACK Pro 预设控制面最大 100,000 个 |
| 单集群最大节点数（Flannel） | 默认 200 个，最大 1,000 个 |
| 单集群 Pod 总数 | 500,000 个（具体取决于网络插件和可用 Pod 网段配置） |
| 单节点最大 Pod 数（Flannel） | 256（受集群创建时网段规划影响，不支持申请提高） |
| 单节点最大 Pod 数（Terway） | 由节点 ECS 规格提供的弹性网卡（ENI）数量决定 |
| 单集群最大 Serverless Pod 数 | 50,000（Pod 大量关联 Service 时建议 ≤20,000） |
| Namespace 数 | 10,000 个 |
| 参考口径 | Pro 版配 Terway、5000 节点规模下 Pod 上限 50,000，Service 和 Pod 总映射上限 64,000 |

基础版对照：节点 10 个、Pod 300 个、Namespace 100 个（详见 06-配额与限制）。

## 节点规格（ECS）

| 规则 | 内容 |
|---|---|
| 最低节点规格 | 4 核 8 GB 及以上 |
| 小规格弊端 | 网络资源受限；需预留 CPU/内存/磁盘给系统组件；资源碎片化 |
| CPU:内存配比建议 | 按 Pod 需求选 1:2、1:4；Java 类内存密集应用建议 1:8 机型 |
| 大规模建议 | 集群日常规模约 1,000 核可选用裸金属神龙服务器（一台神龙至少 96 核，10~11 台可建一个集群） |
| GPU 约束 | 同一节点池禁止混用 GPU 与非 GPU 实例规格 |
| 持久内存型 | re6p 等混合内存架构实例如需持久化存储，需用非易失性存储卷（NVM Volume） |

## 不支持的 ECS 实例规格

| 不支持的规格族/族群 | 示例 | 说明 |
|---|---|---|
| 突发性能实例 t5 | ecs.t5-lc2m1.nano | 性能不稳定，可能导致集群不稳定 |
| 突发性能实例 t6 | ecs.t6-c4m1.large | 性能不稳定，可能导致集群不稳定 |
| vCPU < 4 的实例规格 | ecs.g6.large | 配置过低；可在配额平台申请低规格白名单 |
| 安全增强计算型 c6t | ecs.c6t.large | 暂不支持 |
| 安全增强通用型 g6t | ecs.g6t.large | 暂不支持 |
| 超级计算集群 SCC 规格族 | ecs.sccg7.32xlarge | 暂不支持 |

Terway 下单节点 Pod 限额计算：
- 共享 ENI 模式（或 +Trunk ENI）：(ENI 数 − 1) × 单 ENI 私有 IP 数 > 11。例：ecs.g6.large（ENI 2、单网卡 IP 6）→ 限额 6，无法使用。
- 独占 ENI 模式：ENI 数 − 1 > 6。例：ecs.g6.xlarge（ENI 3）→ 限额 2，无法使用。

## Master 节点推荐规格（专有集群）

| 节点规模 | Master 节点推荐规格 |
|---|---|
| 1~5 个节点 | 4 核 8 GB（不推荐 2 核 4 GB 及以下） |
| 6~20 个节点 | 4 核 16 GB |
| 21~100 个节点 | 8 核 32 GB |
| 100~200 个节点 | 16 核 64 GB |
| 200~500 个节点（请估爆炸半径风险） | 64 核 128 GB |

版本机制：

| 规则 | 内容 |
|---|---|
| 版本号格式 | x.y.z-aliyun.n（n 为阿里云补丁版本） |
| 集群创建 | 仅支持最近三个次要版本（当前为 1.37、1.36、1.35）；Pro 版开启版本延长支持可创建延长支持期版本；新补丁发布后旧补丁不再开放创建 |
| 集群升级 | 控制面仅逐个次要版本升级，不支持跨多版本、不支持回退；节点池可跨版本直接升级至控制面当前版本（灰度中）；补丁仅支持升到最新补丁 |
| 延长支持 | 自 1.34 起，Pro 版标准支持结束后可再获 12 个月安全维护；1.33 及更早无延长支持 |
| 发布节奏 | 社区新 minor 后通常 2 周内开放创建升级；高危安全补丁通常 24 小时内评估验证后开放 |
| 强制升级 | 过期版本不允许长期存在；执行前至少提前 1 个月短信/邮件/站内信通知；专有集群、1.22+Docker 运行时、Nginx Ingress 组件过低等情况需手动升级 |
| 运行时 | 1.24 起不再支持 Docker 作为内置容器运行时，需迁移 containerd |
