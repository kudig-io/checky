## 访问方式总览

| 方式 | 适用 | 关键参数 |
|---|---|---|
| 公网 | 远程 Docker 客户端推拉 | 实例默认关闭公网访问入口；开启后默认生成一条 `127.0.0.1/32` 公网白名单；需手动添加公网白名单网段（删除全部白名单 = 全网可访问，有被攻击风险） |
| VPC 内网（专有网络访问控制） | 同账号、网段无冲突的 ECS/ACK | 绑定 VPC+交换机；占用 VPC 内 1 个 IP，由云解析 PrivateZone 自动解析内网域名；VPC 级生效，绑定后整个 VPC 可访问；需开通云解析 PrivateZone；配额单独购买（初始可能为 0） |
| VPC 内网（终端节点访问控制 / PrivateLink） | 网段重叠、跨账号、要安全组管控 | 白名单功能；终端节点服务名 `com.aliyuncs.privatelink.{RegionId}.cr`；开启占 1 个专有网络额度；建议至少选 2 个可用区；开启免费，流量按 PrivateLink 计费 |
| 跨地域 / IDC | 本地数据中心或其他云 | 经 VPN 网关、高速通道物理专线、智能接入网关或 CEN 打通 VPC 后配置路由 + 域名解析；需获取实例域名、OSS Bucket、认证服务三个 IP |

## 域名与 Endpoint 清单

| 类型 | 公网 | VPC/内网 |
|---|---|---|
| 企业版实例 | `<实例名>-registry.{RegionId}.cr.aliyuncs.com` | `<实例名>-registry-vpc.{RegionId}.cr.aliyuncs.com` |

| 镜像加速器 | `https://<xxx>.mirror.aliyuncs.com`（每账号一个） | — |
| 认证服务（VPC 内） | — | 官方示例：`https://dockerauth-vpc.cn-hangzhou.aliyuncs.com/auth`（可通过实例 `/v2/` 响应的 `www-authenticate` 头获取） |

- 旧版个人版经典网络域名 `registry-internal.*.aliyuncs.com` 已于 2025-02-10 起下线。

- 自定义域名：需已备案域名（无需备案的地域除外）+ SSL 证书，公网/VPC 各通过云解析添加 CNAME 记录指向默认域名；经济版不支持。

## 回调 Webhook 网络（触发器与事件通知）

| 项 | 参数 |
|---|---|
| 触发器协议端口 | HTTP 默认 80；可选端口：80、21、443、70、210、280、488、591、777、1025~65535 |
| HTTPS 端口 | 仅支持默认 443；只支持标准证书，不支持自签证书 |
| 触发条件 | 表达式触发（正则过滤 Tag）或 Tag 触发（Tag 列表最多选 10 个）；未设置则全部触发 |
| 通知内容 | POST JSON，含 `push_data`（digest/pushed_at/tag）与 `repository`（namespace/name/region 等） |
| 事件通知通道 | 钉钉 Webhook（需加签密钥）、HTTP、HTTPS；底层为 EventBridge |
| 事件通知规则 | 每地域 10 条；按实例/命名空间/仓库 + 正则设定生效范围 |
| 不支持地域 | 华东金融云2、华南金融云1、华东金融云1、华北政务云1、伦敦 |
