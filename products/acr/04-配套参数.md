## 镜像安全扫描

双引擎对比：

| 项 | Trivy 扫描引擎 | 云安全扫描引擎 |
|---|---|---|
| 费用 | 免费（默认） | 800 元/月 |
| 检测范围 | 系统漏洞、应用漏洞 | 系统漏洞、应用漏洞、基线检查、恶意样本 |
| 漏洞库 | 每日更新 | 持续风险发现 |
| 一键修复 | 不支持 | 支持，产出 `_fixd` 后缀镜像 |
| 档位可用性 | 基础版及以上 | 基础版及以上（个人版/经济版无） |

- 云安全引擎扫描额度：每月支持不同 Digest 1 万次以内扫描，相同 Digest 扫描不限次。
- Trivy 引擎限制：建议镜像单层不超过 3 GB，超 3 GB 可能扫描失败（建议改用云安全引擎）。
- 扫描时长：一般 3 分钟内完成一个镜像（取决于镜像大小）。
- 扫描规则：按命名空间或仓库 + 版本正则过滤；支持推送/构建成功后自动触发；通知支持钉钉、HTTP、HTTPS。
- 扫描结果分高危/中危/低危/未评级四级。
- ⚠️ 待核（口径冲突）：个人版镜像安全扫描——产品公告称自 2023-08-20 起取消个人版镜像安全扫描与镜像同步功能，而「创建个人版实例」页仍写个人版支持「安全扫描」，两处官方口径不一致。

## 镜像加速器（Docker Hub 拉取）

| 参数 | 数值/规则 |
|---|---|
| 地址分配 | 每个阿里云账号（或 RAM 用户）一个加速器地址，形如 `https://<xxx>.mirror.aliyuncs.com` |
| 配置方式 | Docker `daemon.json` 的 `registry-mirrors`；Containerd `hosts.toml` |
| 使用范围 | 2024-07-02 起仅限阿里云用户在支持公网访问的阿里云产品上使用，且仅支持拉取限定范围的容器镜像 |
| 访问限制 | 仅支持阿里云 ECS 访问，非阿里云机器访问返回 HTTP 403 |
| 同步状态 | ACR 镜像加速已停止同步最新镜像；不支持浏览镜像 Tag 列表 |
| 其他 | 面向个人开发者，不允许再次封装或商业用途 |

## 版本管理与清理

| 项 | 规则 |
|---|---|
| 保留策略范围 | 实例 / 命名空间 / 仓库三级 |
| 执行方式 | 自动（每周或每月定时）或手动触发 |
| 保留规则 | 必填「保留最近推送的镜像数量」+ 选填正则白名单（默认 `.*` 保留全部） |
| 个人版 | 不支持版本保留策略，只能手动删除版本 |
| OSS 空间释放 | 清理后 OSS 空间仍占用；释放需通过「制品清理」任务，且需提交工单开启；镜像删除后不可恢复，严禁直接在 OSS 控制台操作关联 Bucket |

## 跨实例同步与制品订阅

| 项 | 规则/数字 |
|---|---|
| 同步源实例 | 必须为标准版或高级版；目标实例可为经济/基础/标准/高级 |
| 同步规则数 | 标准版 30、高级版 60 |
| 同步级别 | 按命名空间或按仓库，附版本正则过滤 |
| 存量镜像 | 自动同步只同步规则生效后推送的镜像；存量用手动同步或「OSS 复制 + 镜像导入」 |
| 地域限制 | 公共云不支持同步至金融云/政务云等非公共云地域；多地域实例同步不产生额外 OSS 流量费 |
| 制品订阅规则数 | 基础版 5、标准版 10、高级版 30 |
| 订阅前 N 个版本 | Docker Hub 限额 5 个镜像版本，其他源最多 30 个 |
| 订阅源 | Docker Hub/GCR/Quay 及符合 Registry V2、公开、公网 HTTPS 的自定义源；不支持以 ACR 实例为订阅源 |

## 分发加速（P2P 与按需加载）

| 项 | 官方数字 |
|---|---|
| P2P 加速收益 | 1000 节点规模拉取 1 GB 镜像（带宽 10 Gbps 基准），相比普通拉取减少 95% 以上耗时；新版较旧版提升 30%~50% |
| P2P Agent 规格 | 1 核 1 GB 内存，缓存 4 GB |
| P2P 加速地址 | `<实例名>-registry-vpc.distributed.<RegionId>.cr.aliyuncs.com:65001` |
| P2P 启用方式 | 控制台开启 P2P 模块 + ACK 集群部署套件；标签 `k8s.aliyun.com/image-accelerate-mode=p2p` |
| 按需加载·完整模式 | 加速镜像约为原镜像体积 130%；1 GB 原始镜像生成约 25 秒 |
| 按需加载·仅索引模式 | 加速效果约为完整模式 70%；体积约为原镜像 3%；1 GB 生成约 3 秒 |
| 按需加载实测 | NodeBB 镜像 1.34 GB：普通启动 38 s（拉取 36 s），加速后启动 9 s（拉取 4 s） |
| 档位 | P2P 分发、按需分发：标准版、高级版 |
