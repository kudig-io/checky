## 分发与同步配额

| 配额 | 限制 |
|---|---|
| 分发性能（拉取 QPS） | 个人版不保障；经济版 30、基础版 250、标准版 500、高级版 1000 |
| 同步规则 | 标准版 30、高级版 60；源实例必须为标准版或高级版 |
| 制品订阅规则 | 基础版 5、标准版 10、高级版 30 |
| 单条订阅规则同步版本数 | Docker Hub 限额 5 个镜像版本，其他源最多 30 个 |
| 事件规则 | 每地域 10 条（ACR 与 EventBridge 各 10 条） |
| 触发器 Tag 触发列表 | 最多选 10 个 Tag |
| 跨地域同步 | 公共云不支持同步至金融云/政务云等非公共云地域 |

## 个人版硬限制

| 限制 | 说明 |
|---|---|
| 实例数 | 单账号（主账号或 RAM）限 1 个（2024-09-09 起） |
| 地域 | 创建时选定唯一目标地域，后续仅在该地域使用 |
| SLA / OpenAPI | 均不提供；仅限开发测试，禁止生产使用 |
| 资源目录 | 不支持资源目录类型账号创建 |
| 登录密码 | 仅允许 1 个 RAM 子账号设置镜像仓库登录密码；不支持临时账号密码登录 |
| 并发拉取 | 共享带宽无限流保障，官方建议并发拉取数 < 10，否则触发 `TOOMANYREQUESTS` |
| 扫描/同步 | 2023-08-20 起不再支持发起新的镜像安全扫描、镜像同步任务 |
| 版本清理 | 不支持版本保留策略，只能手动删除 |

## 操作与命名限制

| 限制项 | 规则 |
|---|---|
| 仓库名称 | 2~64 字符；小写英文字母、数字、下划线、短划线、半角句号；下划线不能在首位或末位；不支持正斜线 |
| 仓库层级 | 个人版仅一级仓库名；企业版支持多级（如 `agent/client/prod`） |
| 扫描单层大小 | Trivy 引擎建议单层 ≤ 3 GB，超出可能扫描失败 |
| 自定义域名 | 经济版不支持；需已备案域名（非备案地域除外）+ SSL 证书 |
| 终端节点访问控制 | 按白名单开放，需提工单；开启占 1 个专有网络额度 |
| 个人版域名兼容企业版 | 同地域仅 1 个企业版可开启，且为白名单功能 |
| 制品清理 | 需提交工单开启；镜像删除后不可恢复；严禁直接操作关联 OSS Bucket |
| 企业版实例数 | 官方未公布单账号实例数上限（2026-11-18 复查计费说明、创建实例页与配额 API 均无该口径），⚠️ 待核 |
