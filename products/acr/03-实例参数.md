## 计算与存储参数

| 参数 | 官方口径 |
|---|---|
| vCPU / 内存 | 官方未公布。ACR 企业版为托管服务，实例规格以功能档位（经济/基础/标准/高级）表达，不披露 vCPU/内存数字，⚠️ 待核（购买页如有展示以购买页为准） |
| 实例存储 | 落 OSS Bucket：默认自动创建 `<ACR实例ID>-registry`，或自选已有 Bucket；存储容量按实际用量计费（OSS 价格），官方不设实例存储上限数字 |
| 服务端加密 | 企业版默认基于 AES256 对 OSS Bucket 做服务端加密 |
| 实例启动 | 购买后状态「启动中」，约 2~3 分钟变为「运行中」 |
| 购买时长 | 1、2、3、6 个月和 1~5 年，可设到期自动续费 |

## 事件与通知参数

| 参数 | 数值 |
|---|---|
| 事件规则数 | 每地域 10 个（ACR 与 EventBridge 各可创建 10 条，超过需清理废弃规则） |
| 事件类型 | 同步完成、镜像构建完成、镜像扫描完成、交付链处理完成、加签完成 |
| 事件查询 | EventBridge 按事件 ID 仅支持查询 3 天内事件 |
| 钉钉机器人限流 | 每机器人每分钟最多 20 条群消息，超限被限流 10 分钟 |
| 不支持事件通知的地域 | 华东金融云2、华南金融云1、华东金融云1、华北政务云1、伦敦 |

**来源**：
- 创建事件通知：https://help.aliyun.com/zh/acr/user-guide/create-an-event-notification ｜ 复核：2026-11-16

## 个人版实例参数

| 参数 | 数值 |
|---|---|
| 实例数 | 2024-09-09 起单账号（主账号+RAM）限 1 个 |
| 地域 | 创建时选定唯一目标地域，之后仅在该地域可用 |
| 命名空间 / 仓库 | 3 / 300 |
| 并发拉取 | 共享带宽、无固定出口带宽保障；官方建议并发拉取数控制在 10 以下，否则易触发 `TOOMANYREQUESTS` 限流 |
| 仓库名称 | 2~64 字符，小写英文字母、数字、下划线、短划线、半角句号；下划线不能在首位或末位；不支持正斜线 |
| 仓库层级 | 仅支持一级仓库名称 |
