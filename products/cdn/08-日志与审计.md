> 产品：CDN ｜ 口径：公共云 ｜ 复核：2026-11-17

## 日志类型总表

| 类型 | 产生方 | 查看入口 | 默认保留期 | 是否计费 |
|---|---|---|---|---|
| 访问日志（离线日志） | CDN 节点 | CDN 控制台 > 日志管理 > 离线日志（日志下载页签） | CDN 服务器仅保留 30 天，可下载 30 天内按小时粒度的 .gz 文件；日志文件延迟通常在 24 小时之内 | 下载免费（CDN 生成和提供离线日志下载功能免费）；经函数计算转存 OSS 后按 OSS 存储计费 |
| 访问日志（实时日志，投递 SLS） | CDN + 日志服务 SLS | CDN 控制台 > 日志管理 > 实时日志；SLS 控制台 | 投递至 SLS Logstore，保存时间由 SLS Logstore 配置（CDN 文档未标注默认值）📋 待补 | 按投递成功条数按量后付费（CDN 侧，按天结算，出账延迟 3~4 小时）；SLS 存储与分析费另计 |
| 运营统计（运营报表） | CDN 统计系统 | CDN 控制台 > 统计分析 > 运营报表 | 报表数据 T+1 生成（定制后 T+1 日 6 点左右可查看）；控制台保留期官方未标注 📋 待补 | 官方未标注（文档未提及计费） |
| 操作日志（管控事件） | 操作审计 ActionTrail | 操作审计控制台 > 事件查询 > 关联资源类型输入 CDN | 默认为每个账号保存最近 90 天管控事件；操作后 10 分钟内可查 | 操作审计本身免费 |
| 审计（事件投递留痕） | 操作审计 创建跟踪 | SLS LogStore / OSS Bucket | 超过 90 天需创建跟踪投递，随投递目标保存策略 | 操作审计免费；投递到 SLS/OSS/MaxCompute 按目标产品定价计费 |

- 离线日志与实时日志的区别：实时日志延迟不超过 3 分钟并打通 SLS 分析（4 张预制报表）；离线日志延迟通常 24 小时内，只支持转存 OSS，尚未打通日志分析能力。
- 监控查询、用量查询（实际计费流量）查到的流量数据通常是日志统计流量数据的 1.1 倍。

## 关键日志详表

**A. 离线访问日志字段（文本，按小时生成）**

| 字段 | 类型/示例 | 含义 |
|---|---|---|
| 访问时间 | `[8/Jan/2025:20:16:54 +0800]` | 用户访问请求的结束时间 |
| 请求URL | `http://cdn.aliyun.cn/images/cdn.gif` | 用户请求的 URL 链接 |
| HTTP状态码 | `200`、`403`、`404`、`500` | HTTP 响应状态码（边缘响应） |
| 是否命中CDN节点 | `HIT` / `MISS` | HIT=命中边缘节点缓存；MISS=边缘未命中（上游可能是 L2 节点，也可能是源站） |
| 响应时间 | `246` | 请求响应时间，单位毫秒 |
| 客户端IP | `139.224.XXX.XXX` | 从 `X-Forwarded-For` 左起第一个 IP 提取 |
| 响应字节数 | `978` | 请求返回大小，单位字节 |
| User_Agent | `Mozilla/5.0 ...` | User-Agent 请求头信息 |

**B. 实时日志字段（SLS，共 29 个字段）**

| 字段 | 类型/示例 | 含义 |
|---|---|---|
| `unixtime` | 数值 | 请求结束时间 |
| `uri` | 字符串 | 请求资源（默认建索引） |
| `return_code` | 数值（如 `200`） | 请求响应码（默认建索引） |
| `hit_info` | `HIT` / `MISS` | 命中信息（直播、动态加速除外） |
| `request_time` | 数值（毫秒） | 请求响应时间 |
| `client_ip` | IP 地址 | 用户真实 IP（`X-Forwarded-For` 左起第一个） |
| `response_size` | 数值（字节） | 请求返回大小 |
| `uuid` | 字符串 | 全网唯一请求 ID（traceid） |

- 回源状态码说明：CDN 离线/实时访问日志均不含回源状态码字段；回源状态码经 **监控查询 > 资源监控/实时监控 > 回源HTTPCODE** 报表查看。
- `MISS` 不等于回源：CDN 仅提供边缘节点日志，不包含 L2 节点回源信息，无法从日志直接判断是否回源。
- 少数 ISP 可能为用户分配私有 IP（10.x/172.16.x/192.168.x），日志中出现属正常现象。

## 投递与加工

| 通道 | 去向与参数 | 关键限制 / 额度 | 计费要点 |
|---|---|---|---|
| 离线日志下载 | CDN 控制台 > 日志管理 > 离线日志；API `DescribeCdnDomainLogs`；文件名 `域名_年_月_日_起止时间[扩展字段].gz` | 仅支持下载 30 天内日志；按小时粒度 | CDN 侧免费 |
| 函数计算转存 OSS | 函数计算 3.0 `LogFileCreated` 触发器 + Python 函数，绑定 `AliyunCDNLogDumpRole`；CDN 控制台一键开通自动创建 `AliyunCDNEventNotificationRole` 服务关联角色 | 需 CDN、函数计算、OSS 在同一账号；CDN 仅保留 30 天，须及时转存 | 函数计算按执行次数/vCPU/内存/时长计费；OSS 按存储、请求、外网流出流量计费 |
| 实时日志投递 SLS | 创建 SLS Project/Logstore 并指定区域，授权 `AliyunCDNLogArchiveRole`；API `CreateRealTimeLogDelivery` | 一次最多绑定 5 个域名；一个域名同时仅支持投递单个 LogStore；支持地域含杭州/上海/青岛/北京/深圳/香港/新加坡；域名跨账号迁移须先关闭原账号投递，否则持续投递并计费 | 按投递成功条数按量后付费（天结算，出账延迟 3~4 小时）；SLS 存储/分析费另计 |
| 日志分析与过滤 | SLS 查询分析：4 张预制报表（CDN 基础数据/访问错误/热门资源/用户构成）+ 自定义 SQL/字段过滤（如 499、502 状态码域名排行） | 预制报表通过实时日志功能页「查看报表」进入；自定义分析通过「日志分析」进入 | SLS 存储、索引、查询按 SLS 定价 |
| 运营报表订阅 | 邮件发送至指定邮箱；支持定制 PV/UV、地区运营商、域名排行、热门 Referer/URL、回源热门 URL、Top 客户端 IP | 试运行阶段：一个账号（含 RAM 用户）最多创建 5 个订阅任务；数据 T+1 生成 | 官方未标注 |
| 审计事件投递 | 创建跟踪 → SLS LogStore / OSS Bucket / MaxCompute | 单账号跟踪每地域 5 个；1 个跟踪最多配置 1 个 OSS Bucket | 操作审计免费；投递目标按各自定价单独付费 |

- 采样：官方未发布实时日志采样参数说明 📋 待补。

## 审计与合规

| 项 | 官方口径 |
|---|---|
| 接入方式 | CDN 已接入操作审计（ActionTrail），记录用户通过 OpenAPI、控制台等方式操作 CDN 产生的管控事件 |
| 事件范围 | 域名管理、刷新预热、证书、CC 防护、报表订阅等，如 `AddCdnDomain`、`DeleteCdnDomain`、`StartCdnDomain`、`StopCdnDomain`、`RefreshObjectCaches`、`PreloadObjectCaches`、`SetDomainServerCertificate`、`SetCcConfig`、`UpdateCdnSubTask` 等 |
| 查询路径 | 操作审计控制台 > 事件查询 > 选择地域 > 关联资源类型输入 CDN > 设置时间范围；可查看事件详情与事件记录代码 |
| 长期留痕 | 默认保存最近 90 天管控事件；超过 90 天需创建跟踪，将事件投递到 SLS 或 OSS |
| 时效 | 用户操作后 10 分钟内可通过控制台查询；OSS 存储中访问同样为 10 分钟内 |
| 配额 | 单账号跟踪每地域 5 个；1 个跟踪允许配置 1 个 OSS Bucket；LookupEvents 每秒最多查询 2 次 |
| 下载与投递 | 事件支持下载，或保存到 SLS/OSS 用于行为分析、安全审计、合规追踪 |
| 计费 | 操作审计本身免费；通过跟踪投递到 SLS/OSS/MaxCompute 按各自定价单独付费 |

- CDN 审计事件清单为管控事件；官方文档未列 CDN 数据事件采集能力。
