## 回源协议与端口

| 项 | 规则 |
|---|---|
| 默认状态 | 回源协议功能默认关闭；关闭时按回源端口判断：443 → HTTPS，80 或其他 → HTTP |
| 协议选项 | HTTP（固定）、HTTPS（固定）、跟随（用户访问用什么协议就用什么协议回源） |
| 默认端口 | HTTP 回源默认 80，HTTPS 回源默认 443 |
| 自定义回源端口范围 | HTTP、HTTPS 端口均为 1-65535 |
| 客户端访问端口 | 仅支持标准端口 HTTP 80、HTTPS 443；非标准端口仅用于回源侧 |
| 回源超时 | TCP 层默认 10 秒，HTTP 层默认 30 秒 |
| 回源请求头最大长度 | 不超过 300 Bytes |
| 回源 Content-Type | 源站不响应时，CDN 自动添加 `Content-Type: application/octet-stream` |

- HTTPS 回源要求源站配置证书并有效，否则回源失败；HTTP 回源不校验源站证书。
- 回源协议必须与源站实际监听协议一致。

## 回源 HOST 与回源 SNI

- 默认回源 HOST：回源请求的 Host 头默认为加速域名，可自定义为加速域名、源站域名或自定义域名。
- 回源 SNI：决定 HTTPS 回源 TLS 握手中发送的服务器名称指示，独立配置项。
- 源站为 OSS 时：默认回源 HOST 必须配置为 OSS Bucket 公网域名，否则无法访问源站；建议同时配置回源 SNI 为同一域名，否则可能被 OSS 限流。
- 源站多域名监听时：回源 HOST 与回源 SNI 建议设为相同域名（与源站证书及虚拟主机匹配），不一致可能导致 SSL 握手失败、Bad Request 或 502。

## 源站与回源 IP

| 项 | 规则 |
|---|---|
| 源站类型 | OSS 域名、IP、源站域名、函数计算域名 |
| 源站数量 | 每个加速域名最多 20 个源站，支持主备优先级和权重 |
| 源站地址长度 | 最长 67 个字符 |
| IP 源站 | 不支持内网 IP；支持 IPv4+IPv6 混配，必须至少一个 IPv4；ECS 外网 IP 免审核 |
| IPv6 源站 | 需先开启 IPv6 回源功能，否则配置不生效导致回源失败 |
| 循环回源防护 | 源站域名若已被配置为 CDN 加速域名，返回 `RetErrorSourceCircle` 错误 |

节点 IP 分两类：

| 类型 | 说明 | 特点 | 获取方式 |
|---|---|---|---|
| 回源节点 IP（L2） | 节点回源访问源站用的 IP | 动态分配、不固定、定期变化 | 调用 `DescribeL2VipsByDomain`（需日峰值带宽 ≥1 Gbps 并工单申请权限，单域名查询，不能批量）；人工申请回源 IP 地址段已停止 |
| 边缘节点 IP（L1） | 用户访问 CDN 就近分配的节点 IP | 动态调度、随时变化 | 查询节点 IP 列表 L1 接口；nslookup/dig 结果仅代表瞬时调度 |

- 回源默认连接源站 80（HTTP）/443（HTTPS）端口。
- CDN 回源时透传 `ali-cdn-real-ip` HTTP 头，源站可据此识别合法回源请求（替代 IP 白名单方案）。
- 官方不建议仅依赖 IP 白名单保护源站（回源 IP 动态变化）。

## IPv6

- 开关位置：基本配置 > IPv6 功能。
- 开启后：IPv6 客户端可通过 IPv6 访问 CDN 节点，节点回源也携带 IPv6 客户端 IP 信息。
- 覆盖：大部分节点已支持 IPv6；就近节点不支持时客户端回落 IPv4。
- 限制：部分域名为优化性能默认关闭中国内地以外的 IPv6，有需求需提交工单。

## HTTP/2 与 HTTP/3（QUIC）

| 协议 | 开启条件 | 要点 |
|---|---|---|
| HTTP/2 | 必须先配置 HTTPS 证书且生效 | 关闭 HTTPS 后 HTTP/2 自动失效、开关置灰 |
| HTTP/3（QUIC） | 域名配置页打开 QUIC 协议开关 | 支持 IETF 标准版本 QUIC；七层 QUIC；基于 UDP |

- Chrome 已支持对 CDN 直接发起 HTTP/3 请求；自研 App 需集成 lsquic-client、cronet、ngtcp2、quiche 等网络库。
- QUIC 请求判断标准：是否基于 UDP；计费上 QUIC 请求匹配静态 QUIC 请求数计费，非 QUIC 匹配 HTTPS 请求数计费。
- 静态 QUIC 请求数 = 域名请求次数 + 域名关联的静态资源加载次数，按量后付费、按小时结算（出账延迟 3~4 小时）。

## 带宽/流量统计口径

- 计费口径：按流量、按带宽峰值、月结 95 均指 CDN L1 节点上产生的下行流量带宽。
- 带宽峰值采样：每 5 分钟统计一个带宽值，每日 288 个值取最大值；月结 95 每日同样 288 个计量点。
- 监控/用量流量 vs 日志流量：实际计费流量（含监控查询流量）= 日志统计流量 × 1.1（TCP 系数）。
- 差异来源：TCP/IP 包头（IP 包最大 1500 字节中 40 字节包头，至少占日志流量 2.74%，通常约 3%）+ TCP 重传（互联网通常 3%~10% 数据被丢弃后重传）。
- 行业惯例：在日志 response size 基础上加 7%~15% 得出实际计费流量；阿里云 CDN 取平均值 10%。
- 计费区域按访问用户 IP 判定归属，共 8 个计费大区：CN、NA、EU、AP1、AP2、AP3、MEAA、SA。
