## 域名数量配额

| 项 | 默认值 | 提升条件 |
|---|---|---|
| 每账号加速域名数 | 50 个 | 域名总带宽日均峰值 > 50 Mbps 且业务无风险，可在配额中心申请增加 |
| 泛域名下精确域名数 | 500 个 | 超过后新增精确域名不生效（已匹配的不受影响） |
| 域名停用回收 | 停用状态超过 120 天（含审核未通过）自动删除记录 | 重新添加即恢复 |
| 域名格式 | 总长 ≤ 100 字符；子域名部分 ≤ 64 字符 | 不支持中文、大写、除短划线外符号 |

- 加速域名不允许重复添加；跨账号迁移需走域名归属权验证迁移流程。
- 泛域名与子域名必须在同一账号下。
- 每账号可配置的 HTTPS 证书数量配额：官方 CDN 文档未公布 ⚠️ 待核。

## 刷新与预热配额

| 配额项 | 默认配额 | 恢复周期 | 提升条件 |
|---|---|---|---|
| URL 刷新 | 10000 条/日/账号 | 次日 00:00:00 恢复 | 账号日带宽峰值 > 200 Mbps 可在配额中心申请提升 |
| 目录刷新 | 100 条/日/账号 | 次日 00:00:00 恢复 | 同上 |
| 正则刷新 | 20 条/日/账号（每个账号每日最多可提交 20 条含正则表达式的 URL） | — | — |
| 文件预热 | 1000 条/日/账号，仅支持 URL 预热 | 次日 00:00:00 恢复 | 同上 |

- 刷新与预热功能本身不收取操作费用；由此产生的回源流量/回源请求按源站产品规则计费。
- 控制台目录刷新、正则刷新默认为「标记刷新」（标记过期，回源带 If-Modified-Since/If-None-Match，源站 304 则继续用原缓存）；URL 刷新直接删除缓存。
- 强制无条件清除可用 API 并将 Force 设为 true（URL 刷新不使用 Force）。
- 提交的 URL 含非 ASCII 字符必须先 UTF-8 百分号编码，否则任务可能不生效。
- RAM 用户需授予 `cdn:RefreshObjectCaches`、`cdn:PushObjectCache` 权限。

| EdgeScript 边缘脚本规则 | 默认每域名 2 条 |

## 请求报文长度与状态码限制

| 场景 | 限制 | 超限返回 |
|---|---|---|
| HTTP/2 单个请求头或单个 URL | ≤ 32 KB（`http2_max_field_size`） | 414 |
| HTTP/2 全部请求头 + URL 合计 | ≤ 128 KB（`http2_max_header_size`） | 400 |
| HTTP/1.1 单个请求头或单个 URL | ≤ 64 KB（`large_client_header_buffers` 4×64 KB） | 414 |
| HTTP/1.1 全部请求头 + URL 合计 | ≤ 256 KB | 400 |
| 源站返回的 HTTP 响应头总大小 | ≤ 32 KB | 502 |

- 支持的请求方式：GET、PUT、POST、HEAD、OPTIONS；DELETE/PATCH 需用 ESA。
- 物联网卡终端在中国内地无法访问 CDN 节点（工信部规定）。
- 客户端 SSL 握手不带 SNI 时，CDN 不保证握手成功。

## 内容与安全限制

- 所有接入域名都要经过内容审核；不支持接入的域名类型包括：无法正常访问/无实质信息、私服游戏类、传奇类及纸牌类游戏、盗版软件/小说/视频/漫画站、P2P 类金融网站、彩票类、违规医院药品站、涉黄涉毒涉赌等。
- 泛域名下的精确域名出现违规，整个泛域名会被下线。
- 违规域名情节严重的封禁整个账号下域名服务且永不恢复。
- 域名沙箱：DDoS/CC 攻击或未报备突增导致带宽/QPS 大涨时，系统可将域名切入沙箱（不会 100% 触发）；严重时同账号其他域名一起入沙箱，并限制新域名接入。
- 默认不提供访问控制或安全防护；被盗刷产生的高额账单无法免除/退款。
- CNAME 域名仅可作为调度解析使用，恶意使用会被清退。
