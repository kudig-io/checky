## 业务类型（加速类型）

添加加速域名时需选择业务类型，官方共 3 种：

| 业务类型 | 适用场景 | 关键数字 |
|---|---|---|
| 图片小文件 | 门户、电商、新闻、娱乐游戏类网站的 HTML/CSS/JS/图片分发 | 小文件为主，核心指标为首包时间 |
| 大文件下载 | 游戏安装包、应用更新、ROM 升级、应用包下载 | 平均单文件 ≥ 20 MB |
| 视音频点播 | 影视、在线教育、短视频、音频类网站 | 支持 MP4、FLV 等主流格式 |

- 业务类型只影响调度优化策略（如大文件下载启用分片回源和预加载），选错不会导致加速不可用。
- 业务类型不预设缓存天数：创建域名时选择的类型不会针对特定后缀或路径预设固定缓存时长，缓存行为以控制台配置为准。

## 加速区域

| 加速区域 | 覆盖 | 备案要求 |
|---|---|---|
| 仅中国内地 | 仅中国内地节点 | 必须 ICP 备案，否则无法正常访问 |
| 全球 | 覆盖全球所有节点（含中国内地） | 加速区域含中国内地即必须备案 |
| 全球（不包含中国内地） | 仅内地以外节点（含中国香港、澳门、台湾） | 不含内地，无需因内地节点备案 |

- 「全球（不包含中国内地）」会禁止请求访问中国内地节点，内地用户被调度至邻近境外节点（如中国香港、日本、新加坡）。
- 加速区域为「全球（不包含中国内地）」时可开启全球资源计划：节点资源更丰富，但支持的功能受限。
- 备案针对源站进行，与 CDN 节点 IP 无关；CDN 节点 IP 变化不影响域名备案状态。

## 添加域名流程与归属权验证

| 步骤 | 要点 |
|---|---|
| 1. 添加域名 | 配置加速区域、加速域名、业务类型，其余参数可保持默认 |
| 2. 域名归属权验证 | 推荐 DNS 解析验证：在 DNS 服务商添加 TXT 记录，主机记录 `verification`，记录值为控制台显示值，配置后点击验证 |
| 3. 配置源站 | 源站类型：OSS 域名、IP、源站域名、函数计算域名 |
| 4. 配置 CNAME | 把加速域名解析类型改为 CNAME，指向 CDN 分配的专属地址 |

- `www.example.com` 与 `example.com` 是两个域名，需分别添加为加速域名并各自配置 CNAME。
- 不能把裸域名的 CNAME 直接解析到带 www 域名的 CDN CNAME 地址。
- 泛域名（如 `*.example.com`）与子域名必须在同一账号下；泛域名下精确域名数量上限 500 个。
- 加速域名总长度不超过 100 字符；去掉根域名后的子域名部分不超过 64 字符；仅支持小写字母、数字、短划线。

## 域名配置项总览

控制台「管理」进入域名配置，主要配置域如下：

| 配置域 | 内容 |
|---|---|
| 基本配置 | 加速区域切换、配置源站、条件源站、IPv6 开关 |
| 缓存配置 | 缓存过期时间、状态码过期时间、缓存键、共享缓存、CORS、忽略参数 |
| HTTPS 配置 | HTTPS 证书、协议重定向、HSTS、HTTP/2、TLS 版本与加密套件、OCSP Stapling |
| 回源配置 | 回源协议、默认回源 HOST、回源 SNI、回源 HTTP 请求头、回源超时、Range 回源 |
| 访问控制 | Referer 黑/白名单、URL 鉴权、远程鉴权、IP 黑/白名单、UA 黑/白名单 |
| 流量限制 | 用量封顶（带宽/流量/HTTPS 请求数）、单请求限速 |
| 其他 | QUIC 协议开关、规则引擎、边缘脚本 EdgeScript、刷新预热 |

- 配置变更或新增缓存规则仅对新缓存的资源生效；要立即全网生效必须手动刷新/预热。
- 多域名共用源站：共享缓存可开启；HTTPS 需为每个加速域名单独配置证书；回源 HOST 建议设为实际源站域名。
