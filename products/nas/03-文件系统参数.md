## 吞吐与 IOPS（含海外地域上限）

通用型 NAS 吞吐随容量线性增长：容量型初始读写 150 MB/s、每 GiB 增 0.15 MB/s；高级型 300 MB/s、每 GiB 增 0.3 MB/s；性能型 600 MB/s、每 GiB 增 0.6 MB/s。读上限：容量型 10 GB/s、高级型/性能型 20 GB/s；写上限均 5 GB/s。最大 IOPS：容量型 1.5 万、高级型 3 万、性能型 3 万。极速型：标准型读+写 1.2 GB/s、高级型读+写 4 GB/s，最大 IOPS 20 万（按配置容量）。

## NFS 协议限制（v3 / v4.0；不支持 v4.1）

| 限制项 | 说明 |
|---|---|
| 支持版本 | 仅 NFS v3 和 NFS v4.0；**不支持 NFS v4.1** |
| 版本选择 | 挂载时参数决定；一般 v3 性能优于 v4.0；多节点同时改同一文件需 v4.0 文件锁 |
| 极速型 | 仅支持 NFS v3 |
| 不支持的功能 | Delegation（委托） |
| 不支持的属性 | FATTR4_MIMETYPE、FATTR4_QUOTA_AVAIL_HARD/SOFT、FATTR4_QUOTA_USED、FATTR4_TIME_BACKUP、FATTR4_TIME_CREATE、FATTR4_ARCHIVE |
| 不支持的操作 | OP_DELEGPURGE、OP_DELEGRETURN、NFS4_OP_OPENATTR（客户端报 NFS4ERR_ATTRNOTSUPP） |
| UID/GID | v4.0 挂载且 Linux 内核 < 3.0 时全部显示 nobody；此时不要执行 chown/chgrp |

## SMB 协议限制

| 限制项 | 数值/说明 |
|---|---|
| 协议版本 | 支持 SMB 2.1 及以上 |
| 单文件/目录活跃句柄 | 最多 8192 个（全节点全用户合计） |
| 文件系统级活跃句柄 | 最多 65536 个 |
| 不支持功能 | 扩展属性、基于 Lease 的客户端缓存、稀疏文件、文件压缩、交换数据流、LDAP 身份认证、SMB Direct、Multichannel、Directory Leasing、Persistent File Handle |
