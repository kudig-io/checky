## 挂载点模型

| 项 | 规则 |
|---|---|
| 挂载点形态 | 文件系统在网络环境中的连接点，以域名形式出现 |
| 挂载点数量 | 单文件系统最多 2 个（通用型；极速型 2024-01-19 前创建的为 1 个，之后创建的为 2 个） |
| 网络类型匹配 | 挂载点网络类型必须与计算节点一致：VPC 计算节点只能挂 VPC 挂载点，经典网络计算节点只能挂经典网络挂载点 |
| 共享 | 一个网络环境 1 个挂载点即可供数百计算节点共用 |
| 权限组绑定 | 一个挂载点必须且只能绑定 1 个权限组 |

## 访问方式矩阵

| 场景 | 是否直接支持 | 实现方式 |
|---|---|---|
| 同账号 + 同地域 + 同 VPC | 是 | 直接挂载 |
| 同地域跨 VPC | 否 | PrivateLink 或云企业网（CEN 经转发路由器，VPC 互通后路由自动学习）打通后挂载 |
| 跨账号跨地域 | 否 | 云企业网跨账号跨地域挂载（先跨账号 VPC 授权再连转发路由器；传输性能较差） |
| 经典网络 | 有限支持 | 经典网络不支持 ECS 跨账号挂载 NAS |
| 本地 IDC / 非阿里云主机 | 否 | VPN 网关或 NAT 网关打通 VPC 内网后挂载 |
| 公网访问 | 否 | NAS 不提供公网 IP，必须内网挂载 |

- 拥有一个网络环境是计算节点访问 NAS 的前提条件；官方建议使用 VPC，支持比经典网络更完善。
- 文件系统与待挂载 ECS 建议同地域；不同地域不能直接连通。
- 挂载前提（官方原文）：NAS 只支持与挂载点**同一 VPC** 的计算节点挂载，且挂载点所绑权限组规则的授权地址必须包含计算节点的 VPC IP；跨 VPC、跨地域、跨账号须经 PrivateLink 或云企业网打通。
- 批量挂载命令支持经典网络与同地域跨 VPC，**不支持跨地域挂载（即使 VPC 已打通）**。

## 公网访问限制

| 项 | 事实 |
|---|---|
| 外网/本地 IP 直挂 | 不支持；NAS 必须通过内网挂载 |
| 官方口径（FAQ 原文） | 「NAS 是否支持外网/本地 IP 挂载？」→ **不支持**；外部要挂载 NAS 必须先打通 NAS 所在 VPC 的内网 |
| 公网 IP | NAS 不提供公网 IP 服务 |
| 外部访问唯一路径 | 打通 NAS 所在 VPC 内网（VPN 网关 / NAT 网关 / 专线等） |
| 本地电脑 / 非阿里云主机 | Linux 可经 VPN 网关或 NAT 网关接入；macOS 需先挂载 SMB 再经 Kerberos 访问 |
| NAT 网关端口映射 | NFS 需映射 111、2049 端口；SMB 需将公网 4456 映射到私网 445 |
| 暴露公网的风险 | 官方社区文档提示：NAT 网关 DNAT 映射 SMB 挂载点到公网有安全风险，推荐 VPN 或专线方案 |

## 可用区与网络性能

| 项 | 规则 |
|---|---|
| 性能最优拓扑 | 计算节点与挂载点同交换机，且该交换机与文件系统同可用区 |
| 跨可用区 | 通用型 NAS 支持跨可用区挂载；极速型 NAS 推荐同可用区挂载 |
| 极速型时延（跨 AZ） | 跨 AZ 读写延迟 3~5 ms（同 AZ 2 ms） |
| 双活/多 AZ | NAS 不支持双活和多 AZ 场景 |

## 网络限制

| 限制项 | 说明 |
|---|---|
| 经典网络 | 不支持 ECS 实例跨账号挂载 NAS 文件系统 |
| 经典网络挂载点新建 | 自 2022-11-21 起，通用型 NAS 不支持新建经典网络类型挂载点；此前创建的存量经典挂载点仍可正常挂载访问 |
| 经典挂载点与 ECS 类型 | 经典网络挂载点必须使用经典网络 ECS 挂载，不支持专有网络 ECS，且权限组授权地址须包含 ECS 内网 IP |
| 经典网络挂载点 IP 变更 | 因内核限制可能出现挂载点 IP 变更导致文件系统不可访问；NAS 提前 30 天通知，须在推送日起 30 天内重新挂载 |
| TCP Options | 通用型 NAS 高性能网络链路不支持用户自定义 TCP Options，自定义可能导致挂载失败 |
| 传输链路 | 通用型使用阿里云新一代高性能网络传输链路 |
