| 每账号单地域权限组数 | 20 个 |
| 单权限组规则数 | 300 条 |
| 每账号单地域生命周期策略数 | 20 个 |
| 单文件系统标签数 | 20 个（标签键不可重复，地域间不互通） |

## 硬限制（产品规格）

| 限制项 | 数值 |
|---|---|
| 单文件系统容量上限 | 通用容量型 10 PiB；通用高级型 1 PiB；通用性能型 1 PiB；极速型 256 TiB |
| 单文件系统最大文件数 | 通用型 10 亿；极速型 5 亿 |
| 最大目录层级 | 1000 级 |
| 单文件容量上限 | 32 TiB |
| 单文件硬链接数 | 511 个 |
| 快照数（极速型高级型） | 手动 128 + 自动 128 |
| 目录配额 | 单文件系统 500 个目录、最大深度 8 层 |
| 存储类型互转 | 不同存储类型的文件系统不能相互转换 |
| 协议类型 | 创建后不可更改 |

## 操作系统与客户端限制

| 限制项 | 说明 |
|---|---|
| 推荐镜像 | 仅对推荐内核镜像充分验证；不在推荐列表的镜像官方不承诺可用性 |
| 问题内核 | 已定位的问题内核版本不升级的，官方不承诺可用性（通过邮件/站内信/短信/公告推送） |
| macOS | 仅支持挂载 SMB 文件系统 |
| AIX | 不支持 |
| Windows + NFS 客户端 | 官方不推荐 |

**来源**

- 使用限制（操作系统）：https://help.aliyun.com/zh/nas/product-overview/limits ｜ 复核：2026-11-16

## 功能支持限制汇总

| 功能 | 限制 |
|---|---|
| 生命周期管理 | 仅通用型；每账号每地域 20 个策略 |
| 目录配额 | 仅通用型 NFS 文件系统；500 目录 / 8 层 |
| 回收站 | 仅通用型 |
| 快照 | 仅极速型高级型；公测期不保障 SLA |
| 接入点 | 仅通用型 NFS；须用 NFS 传输加密挂载 |
| 回收站/生命周期导致计费容量 | 可能大于实际存储容量 |

## AgenticFS 限制（白名单产品）

| 限制项 | 数值 |
|---|---|
| 创建权限 | 仅支持白名单创建（提交工单申请），地域亦为白名单开放 |
| 协议与客户端 | 仅 NFS v3 + Linux；不支持 SMB/Windows/macOS |
| 单 AgenticFS 容量上限 | ⚠️ 待核：限制页 500,000 PiB，选型页 100 PiB（两页冲突） |
| 单 AgenticFS 文件数上限 | ⚠️ 待核：限制页 5,000,000 亿，选型页 50,000 亿（两页冲突） |
| AgenticSpace 数量 | 单文件系统最多 100 万个 |
| 单 AgenticSpace 容量 / 文件数 | 1 PiB / 10 亿；容量配额按 4 GiB 步长扩容，仅一个容量配额 |
| 路径 | 仅单层目录，不支持嵌套、重命名、软链接路径；根目录不支持挂载（仅 OpenAPI 管控） |
| 计算节点 | ECS、ACS（含 Agent Sandbox）等支持 NFSv3 挂载的 Linux 节点 |
