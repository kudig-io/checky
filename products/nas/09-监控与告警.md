# NAS · 监控与告警

> 产品：NAS ｜ 口径：公共云 ｜ 复核：2026-11-17

## 核心监控指标

- NAS 已接入基础云监控（CloudMonitor），Namespace 为 `acs_nas`，基础云监控免费。
- 维度（Dimensions）：`{"userId":"<账号ID>","fileSystemId":"<文件系统ID>"}`；AgenticSpace 粒度另含 `AgenticSpaceId`。
- 报警判断周期口径为 1 分钟（1 周期 = 1 分钟）；控制台图表默认展示 1 小时，自定义日期范围不能超过 30 天。
- 监控数据保留期存在官方口径差异：NAS 文档称「监控数据保留 90 天」，基础云监控限制页称 Period=60 秒存储 31 天（写明冲突，两处均附来源）。

| 指标（英文名） | 含义 | 单位 | 统计周期 | 维度 |
|---|---|---|---|---|
| `AlignedSize` | 通用型 NAS 数据量（不含低频存储） | 字节 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `SecondaryAlignedSize` | 低频存储使用量（开通生命周期管理后） | 字节 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `FileCount` | 文件数（不含目录、不含回收站） | 个 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `ExtremeCapacity` | 极速型 NAS 总存储空间 | 字节 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `ExtremeCapacityUsed` | 极速型 NAS 已使用数据量 | 字节 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `ExtremeInodeUsed` | 极速型 NAS 已使用文件数 | 个 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `IopsRead` | 读 IOPS（每秒平均读取次数） | 次/秒 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `IopsWrite` | 写 IOPS（每秒平均写入次数） | 次/秒 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `ThruputRead` | 读吞吐（每秒平均读字节） | 字节/秒 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `ThruputWrite` | 写吞吐（每秒平均写字节） | 字节/秒 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `LatencyRead` | 读延迟 | ms | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `LatencyWrite` | 写延迟 | ms | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |
| `QpsMeta` | 元数据 QPS（每秒平均元数据请求次数） | 次/秒 | 1 分钟（报警周期口径） | `userId` + `fileSystemId` |

- 读写 IOPS 与元数据 QPS 为整型：一分钟内相关请求数小于 60 时监控值显示为 0。
- 容量监控数据为实时值，不作为账单计量值。
- 通过 API `DescribeMetricList` / `DescribeMetricLast` / `DescribeMetricMetaList` 查询监控数据。

## 官方默认与推荐告警

**A. 官方报警等级与通知机制（NAS 报警规则说明）**

| 报警等级 | 通知机制 | 报警条件 |
|---|---|---|
| 紧急 Critical | 电话 + 短信 + 邮件 + 钉钉机器人 | 连续 N 个周期（每周期 1 分钟）的平均监控指标满足判断条件并与阈值比较；N 值按报警等级区分设置 |
| 警告 Warn | 短信 + 邮件 + 钉钉机器人 | 同上 |
| 普通 Info | 邮件 + 钉钉机器人 | 同上 |

- 所选指标类型不同时报警条件会有差异，以实际界面为准。

**B. 官方文档示例阈值（逐条有官方出处）**

| 场景 | 指标 + 阈值 + 等级 | 出处 |
|---|---|---|
| 简单指标示例 | 通用型文件系统 `LatencyRead` 读延迟：连续 3 个周期（1 周期 = 1 分钟）监控值 ≥ 5 ms → 警告级 | 配置 NAS 报警规则（配置简单指标监控案例） |
| 组合指标示例 | 读延迟 ≥ 5 ms 或 写延迟 ≥ 5 ms 或 低频介质存储容量同比昨天同时间上涨 40%，连续 1 个周期 → 紧急级（通知方式：电话 + 短信 + 邮件 + WebHook） | 配置 NAS 报警规则（配置组合指标监控案例） |
| 企业云监控 PromQL 示例 | `AliyunNas_SecondaryAlignedSize / AliyunNas_AlignedSize > 0.8`（低频介质数据量占通用型 NAS 总数据量超过 80% 触发） | 配置高级告警规则（报警表达式示例） |

**C. 指标阈值类告警**

- 容量（`AlignedSize`/`ExtremeCapacity`）、文件数、吞吐、IOPS、元数据 QPS 等指标的推荐阈值：**官方未发布推荐阈值** 📋 待补（官方文档仅提供报警规则配置方法与上表示例，未给出 NAS 推荐阈值；按阈值红线不收经验值）。

## 通知与渠道

| 渠道/机制 | 说明 |
|---|---|
| 报警等级通知方式 | 紧急：电话 + 短信 + 邮件 + 钉钉机器人；警告：短信 + 邮件 + 钉钉机器人；普通：邮件 + 钉钉机器人（企业云监控口径为 电话/短信/邮件/Webhook 分级） |
| 通道沉默周期 | 取值：5 分钟、15 分钟、30 分钟、60 分钟、3 小时、6 小时、12 小时、24 小时；沉默期内不重复发送，超期未恢复再次发送 |
| 生效时间 | 报警规则仅在生效时间内检查监控数据 |
| 报警联系人组 | 创建报警规则时选择已绑定报警联系人的联系人组 |
| 报警回调 | 公网可访问的 URL，云监控通过 HTTP POST 推送报警信息，目前仅支持 HTTP 协议，可测试回调连通性 |
| 函数计算 | 报警发生时将通知发送至函数计算进行格式处理（需设置地域、服务、函数） |
| 轻量消息队列（原 MNS） | 报警发生时写入指定 Topic（需设置地域和主题） |
| 日志服务 | 报警发生时将报警信息发送至 SLS 的 Project/Logstore |
| 弹性伸缩联动 | 报警发生时触发相应伸缩规则（需设置地域、伸缩组、伸缩规则） |
| 无数据处理 | 取值：不做任何处理（默认）、发送无数据报警、视为正常 |
| 报警标签 | 单条报警规则最多设置 6 组标签（标签名称 + 标签值） |
| 连续周期取值（企业云监控） | 1、3、5、10、15、30、60、70、90、120、180，1 周期 = 1 分钟 |
| 告警升级（Escalation）策略 | 官方未发布 NAS 告警升级策略 📋 待补 |
