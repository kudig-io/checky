## 快照

| 项 | 规则 |
|---|---|
| 支持范围 | 仅极速型 NAS 高级型支持；标准型/通用型/AgenticFS 不支持 |
| 前提 | 文件系统须处于「运行中」状态 |
| 数量上限 | 单文件系统手动快照 128 个 + 自动快照 128 个 |
| 保留时间 | 自定义 1~65536 天；或永久保留（超 128 个自动删最早） |
| 串行限制 | 存在创建中的快照时，不能再次创建 |
| 一致性 | 只备份某一时刻数据；创建期间的增量不同步 |
| 性能影响 | 创建期间 I/O 性能短暂变慢，建议避开业务高峰 |
| 计费状态 | 免费公测中，**公测期间不保障 NAS SLA** |
| 删除 | 手动快照永久保留，直至账户欠费停止服务 15 天后被删除 |

## 生命周期管理

| 项 | 规则 |
|---|---|
| 支持范围 | 仅通用型 NAS（容量型/高级型/性能型） |
| 策略数量 | 每个阿里云账号在一个地域最多 20 个策略 |
| 分层 | 标准存储 → 低频存储（适合每月访问不到 3 次的数据）→ 归档存储（适合每季度访问不到 2 次的数据） |
| 转储方式 | 符合策略自动转储，命名空间不变、可随时访问；不支持直接写入低频/归档 |
| 取回 | 低频可手动取回标准存储，或继续转储归档；归档可手动取回标准存储 |
| 开启条件（产品页口径） | 文件系统中包含每月访问频率低于 2 次的文件时可开启 |

## 回收站

| 项 | 规则 |
|---|---|
| 支持范围 | 仅通用型 NAS |
| 恢复内容 | 被删文件/目录及其 UID、GID、ACL 等元数据 |
| 计费 | 回收站中暂存文件按**原存储类型**计费（容量型文件按容量型、低频/归档按低频/归档） |
| 与计费容量关系 | 开启后计费容量可能大于实际存储容量 |

⚠️ 待核：回收站文件保留时长上限未在本次抓取页核到。

## 备份与跨地域容灾

| 项 | 规则 |
|---|---|
| 备份支持产品 | 通用型 NAS、极速型 NAS（AgenticFS 不支持） |
| 实现方式 | 云备份（HBR）对 NAS 文件系统做策略备份 |
| 跨地域容灾 | 通过云备份的跨地域备份策略实现（官方计费案例三：为文件系统设跨地域备份策略，异地用备份库重建文件系统） |
| NAS 原生跨区域复制 | NAS 本身无原生「跨区域复制」功能，跨地域数据保护走云备份 |

## 目录配额

| 项 | 规则 |
|---|---|
| 支持范围 | 仅通用型 NAS NFS 文件系统支持配额管理；极速型/AgenticFS 见选型表（极速型不支持 NFS 配额，AgenticFS 支持 Space 粒度） |
| 配额目录数 | 单文件系统最多 500 个目录 |
| 最大目录深度 | 8 层（根目录为 0 层） |

## 远程挂载与跨地域访问

| 场景 | 方案 |
|---|---|
| 同账号同地域同 VPC | 直接挂载（默认形态） |
| 同地域跨 VPC | PrivateLink 或云企业网 |
| 跨账号 / 跨地域 | 云企业网（跨地域挂载传输性能较差） |
| 本地 IDC / 非阿里云主机 | VPN 网关或 NAT 网关打通 NAS 所在 VPC 内网后挂载 |
| 公网直挂 | 不支持（NAS 不提供公网 IP，必须内网挂载） |
