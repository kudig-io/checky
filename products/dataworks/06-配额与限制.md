## 调度与开发硬限制

| 限制项 | 数值 |
|---|---|
| 单工作流节点数 | 最多 400 个，建议 ≤100 个 |
| 手动业务流程节点数 | 最多 200 个，建议 ≤100 个 |
| 单任务最大并行实例数 | 1~10,000 或不限制 |
| 手动业务流程最大并行实例数 | 上限 100,000 |
| 超时上限 | 168 小时（7 天），最小 1 分钟 |
| 失败自动重跑 | 1~10 次，间隔 1~30 分钟 |
| 分支节点分支数 | ≤50 |
| 赋值节点传值 | ≤2MB |
| 依赖检查节点检查时长 | ≤1,440 分钟（仅企业版） |
| 调度日历 | 每租户最多 10 个（仅企业版） |
| 数据集挂载 | 每节点最多 5 个 |
| MaxCompute SQL 节点 | 代码 ≤128KB 且 ≤200 条；查询结果 ≤1 万行或 10MB |
| do-while 循环上限 | ⚠️ 待核：节点页写 128 次，原理页写 1,024 次（疑似新旧版口径差异） |
| for-each 循环上限 | 1,024 次 |
| 跨工作空间依赖 | 限同区域（同地域） |
| SUB_PROCESS 子工作流 | 嵌套 ≤5 层、引用总工作流 ≤200（条目摘要） |

## 空间、成员与生命周期限制

| 限制项 | 规则 |
|---|---|
| 同地域版本数 | 同一地域同一时间仅可购买一个非基础版本 |
| 工作空间成员数上限 | 官方文档未公布默认上限 ⚠️ 待核 |
| 工作空间删除 | 删除全部开发成果；数据源/计算资源/节点/资源进回收站，保留 **14 天**，到期永久删除且不支持延长 |
| 回收站保障范围 | 仅数据源、计算资源、节点、资源可恢复；调度任务与数据集成**不在回收保障范围** |
| 回收站名称占用 | 工作空间进入回收站后名称保留最长 14 天，期间不能创建同名工作空间 |
| 删除前置条件 | 空间内或关联 PAI 空间存在运行中任务时禁止删除；需主账号或 AliyunDataWorksFullAccess |
| 按量付费资源组冻结 | 7 天内未被使用（任一场景）则冻结，可手动启动 |
| 资源组到期释放 | 包年包月资源组到期后保留 7 天，未续费则释放 |
