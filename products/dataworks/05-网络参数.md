## 资源组 VPC 打通

| 项目 | 规则/数值 |
|---|---|
| 前置要求 | Serverless 资源组强依赖 VPC：需提前准备 VPC 及交换机；资源组必须与工作空间同地域 |
| 禁用网段 | Serverless 资源组不支持使用 21 网段 VPC（21.0.X.X ~ 21.255.X.X.X 均不可用） |
| 创建后限制 | 创建后不支持更换已绑定交换机（V-Switch）；VPC 可购后增绑 |
| VPC 绑定数量（按量付费） | 数据计算+数据集成合计最多 2 个；数据服务仅 1 个 |
| VPC 绑定数量（包年包月） | ≤10 CU：总共最多 4 个（数据计算 1 个，调度+集成合计 3 个）；>10 CU：总共最多 8 个（数据计算 1 个，调度+集成合计 7 个） |
| 公网访问 | Serverless 资源组**默认不具备公网访问能力**，需为绑定的 VPC 配置公网 NAT 网关 + EIP |
| 服务关联角色 | 首次购买需创建 AliyunServiceRoleForDataWorks（访问 VPC/ENI/安全组） |
| 独享资源组 | 购买后需绑定 1 个 VPC；4c8g 规格最多绑 2 个 VPC、其他规格 3 个（条目摘要）；不支持跨地域使用 |
| 公共资源组 | 不支持网络链路或白名单配置（不支持 VPC 打通与 IP 白名单） |
| 白名单 | 需将资源组交换机网段或 EIP 加入数据源白名单 |

## 数据源连通方案（六种）

| 方案 | 适用场景 | 连通方式要点 |
|---|---|---|
| 方案一：同主账号、同地域 | 阿里云数据源，同账号同地域 | 资源组与数据源绑定同一 VPC；将资源组交换机网段加入数据源白名单 |
| 方案二：同主账号、跨地域 | 阿里云数据源，同账号不同地域 | 云企业网或 VPC 对等连接打通；资源组加「自定义路由」指向数据源交换机网段；数据源加白名单 |
| 方案三：跨主账号 | 数据源与 DataWorks 不同主账号 | 数据源侧跨账号授权 + 云企业网/对等连接打通双方 VPC；资源组加自定义路由；数据源加白名单 |
| 方案四：ECS 自建数据源 | 数据源部署在 ECS | 同账号同地域走同 VPC + ECS 安全组放通（如 3306）；跨账号/跨地域按方案二/三打通 |
| 方案五：IDC 数据源 | 本地 IDC（及第三方云推荐内网方式） | 高速通道物理专线或 VPN 打通 VPC 与 IDC；资源组加指向 IDC 网段的自定义路由；IDC 侧放行交换机网段 |
| 方案六：公网数据源 | 数据源具备公网地址 | Serverless 资源组需为 VPC 配 NAT 网关 + EIP（SNAT）；旧版资源组默认带 EIP 可直连；数据源白名单加 EIP |

- 第三方云（华为云 MRS、AWS RDS 等）：内网优先（VPN/高速通道，参考方案五），公网需 NAT+EIP，跨境建议 VPN 网关或高速通道。
- 不支持与**经典网络**环境的数据交互，官方建议将经典网络数据源迁移至 VPC。
- 资源组与数据源连通是任务运行成功的必要条件之一；连通性测试失败需先核对地址/端口/库名/账号密码与权限。
- 标准模式工作空间需保证开发环境与生产环境的数据源地址均可连通。

## 连通相关补充规则

| 项目 | 规则 |
|---|---|
| 公网流量费归属 | 仅使用独享集成资源组时产生 DataWorks 侧公网流量费（0.8 元/GB，公有云）；Serverless 资源组场景下其他云产品公网流量按云产品规则计费 |
| 公网速度/稳定性 | 官方明示无法保障公网环境下任务的速度和稳定性，建议内网或云企业网同步 |
| 数据源白名单出口 IP | 数据集成、数据服务、元数据采集、数据分析四类模块均需按资源组出口（交换机网段或 EIP）配白名单 |
| PrivateZone | Serverless 资源组不支持直接访问 Host 地址时，可用内网 DNS 解析（PrivateZone）解决 |
| 旧版独享资源组网络 | 数据源在经典网络则无法连通；跨地域/IDC 需高速通道或 VPN + 指向目标 IP 的路由 |
