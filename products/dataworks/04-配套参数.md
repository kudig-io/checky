## 数据集成同步参数（离线同步）

| 参数 | 数值/规则 |
|---|---|
| 任务期望最大并发数 | 通道控制中配置；实际并发可能 ≤ 配置值（未配 splitPk、物理分表数不足、文件数不足、数据倾斜等场景） |
| 限流速率 | 按作业整体速度（MB/s）限流；分片限速 = 作业速率 ÷ 并发数（向上取整），**分片限速下限 1 MB/s**；实际速率上限 = 实际并发 × 分片限速 |
| 不限流 | 按配置并发与硬件环境跑最大传输性能 |
| 分布式模式 | 并发数 ≥8 才能开启；单台机器的独享资源组不建议开启 |
| 脏数据阈值 errorLimit | 留空=不限制；0=不容忍（超 1 条任务失败）；正整数 N=最多容忍 N 条 |
| 实时同步·目标端写入并发 | 默认 3，可配置上限 32 |
| 离线全量初始化·来源端最大 JDBC 连接数 | 默认 15 |
| 同步速度整体上限 | 官方未给出统一 MB/s 硬上限，速度受资源组规格、并发与数据源约束 ⚠️ 待核 |

|---|---|
| 预设模板 | 30 多种表级、字段级和自定义监控模板 |

## OpenAPI 限制

### 版本

| OpenAPI 版本 | 适用 |
|---|---|
| 2024-05-18（新版） | 使用新版数据开发（Data Studio） |
| 2020-05-18（旧版） | 未使用新版数据开发 |

### 按 DataWorks 版本的调用限制

| 版本 | QPS 限制 | 每日调用上限 | 每月免费额度 | 超出后 |
|---|---|---|---|---|
| 基础版 | 所有 API 总 QPS ≤5 | 100 次/日（成功+失败均计入） | 3,100 次/月 | 不支持按量付费，无法继续调用 |
| 标准版 | 所有 API 总 QPS ≤5 | 不限 | 100,000 次/月 | 0.3 元/万次 |
| 专业版 | 所有 API 总 QPS ≤5 | 不限 | 500,000 次/月 | 0.3 元/万次 |
| 企业版 | 读 API 总 QPS ≤50、写 API 总 QPS ≤20 | 不限 | 1,000,000 次/月 | 0.3 元/万次（公有云） |

- 统计口径：每个主账号及其子账号在**每个地域**的累计值。
- OpenAPI 额度耗尽不影响已发布周期任务的实例生成与执行（调度不走 OpenAPI）；仅影响通过 API 发起的运维操作及调用了 OpenAPI 的节点（如 Python/PyODPS 节点）。
- ⚠️ 待核（口径冲突）：计费总览页称 OpenAPI 超额付费「仅企业版支持」，与 OpenAPI 使用指南「标准版、专业版、企业版支持按量」不一致；本表采用 OpenAPI 专页口径。

### 接口级流控（2024-05-18 版本，示例）

| 接口类别 | 配额 |
|---|---|
| 大多数接口 | 1,000 次/秒 |
| ListSchemas | 10 次/秒 |
| ListTables、ListPartitions | 20 次/秒 |
| ListLineages | 15 次/秒 |
| 元数据类读接口（GetCatalog/GetColumn 等） | 10 次/秒 |
| 部分写入类（DeleteMetaCollection、CreateDataset 等） | 5 次/秒 |
