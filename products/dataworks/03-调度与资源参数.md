## 调度周期与时间属性

| 参数 | 数值/规则 |
|---|---|
| 调度周期 | 分钟、小时、日、周、月、年 6 种；cron 表达式按所选时间自动生成，不可手动修改 |
| 分钟调度最小间隔 | 1 分钟 |
| 小时调度实例产出 | 按双闭区间 [起始, 结束] 计算（如 [00:00,03:00] 间隔 1 小时产出 4 个实例） |
| 默认调度时间 | 新建任务默认日调度，定时时间在 00:00~00:30 随机生成 |
| 空跑机制 | 非运行日（周/月/年调度的非勾选日）生成空跑实例，直接置成功、不执行代码、不占资源 |
| 调度时区 | 默认采用工作空间地域时区；6 个海外地域支持切换 UTC+0/UTC+8（地域级、不可逆、需工单） |
| 实例生成方式 | T+1 次日生成（推荐）/ 发布后即时生成；即时生成要求定时时间晚于发布时间超过 10 分钟，否则空跑 |
| 发布变更生效 | 22:00~24:00 的发布变更在第三天生效 |
| 调度类型 | 正常调度 / 暂停调度（转失败、阻塞下游）/ 空跑调度（0 秒置成功、触发下游） |
| 业务日期 | 业务日期 = 定时时间 − 1 天 |

- 每天 00:00 前后为起调高峰期，实例从定时时间到开始运行通常有数分钟延迟，官方建议错峰。

## 超时、重跑与并行

| 参数 | 数值/规则 |
|---|---|
| 超时上限 | 手动可设 1 分钟 ~ 168 小时（7 天）；系统默认 3~7 天（按负载动态调整）；超时强制终止置失败 |
| 超时是否触发重跑 | 否，超时导致的失败不触发自动重跑 |
| 出错自动重跑次数 | 1~10 次 |
| 重跑间隔 | 1~30 分钟 |
| 最大并行实例数（单节点/单任务） | 不限制（默认）或 1~10,000；达上限后新实例排队 |
| 手动业务流程最大并行实例数 | 不限制或自定义，上限 100,000 |
| 优先级档位 | 1、3、5、7、8（数字越大越高）；覆盖规则：运行时指定 > 节点级 > 业务流程级 |
| 延时执行时间 | 仅工作流节点，基于工作流定时时间累加 |

## 依赖与编排上限

| 项目 | 限制 |
|---|---|
| 周期工作流内部节点 | 单工作流最多 400 个节点，建议 ≤100 个（超过建议拆分） |
| 手动业务流程节点 | 最多 200 个节点，建议 ≤100 个 |
| 工作流整体成功判定 | 任一关键节点失败则工作流失败；冻结/暂停上游节点会导致整体失败 |
| SUB_PROCESS 子工作流 | 嵌套层级上限 5 层、引用总工作流数 ≤200（来源为文档索引条目） |
| 跨工作空间依赖 | 限同区域（同地域）；标准模式依赖简单模式可能需提交工单 |
| 分支节点 | 最多挂 50 个分支，未命中分支置空跑 |
| 赋值节点传值上限 | 2MB |
| 依赖检查节点最大检查时长 | ≤1,440 分钟（仅企业版） |

## 资源组总览：通用型（Serverless）与旧版

DataWorks 任务分两类：**调度型任务**（仅触发外部引擎，如 MaxCompute SQL，不消耗 CU）与**计算型任务**（代码在资源组内执行，消耗 CU）。

| 资源组类型 | 计费 | 状态 |
|---|---|---|
| Serverless 资源组（通用型，推荐） | 包年包月 / 按量付费 | 2024-06 起唯一推荐新购类型，统一调度、集成、数据服务 |
| 独享调度/数据集成/数据服务资源组 | 仅包年包月 | 不再推荐；新用户已不可购买旧版资源组 |
| 公共调度/数据服务资源组 | 按量付费 | 正在下线，切勿用于生产 |

## Serverless（通用型）资源组规格与并发

| 参数 | 数值 |
|---|---|
| CU 定义 | 1 CU = 1 核 CPU + 4 GiB 内存 |
| 包年包月最低购买 | 2 CU，最小扩容步长 1 CU；购买规格无上限（受库存影响） |
| 按量付费上限 | 单个按量付费资源组总规格上限 500 CU |
| 调度并发实例数 | 默认 50，最大可调至 200（单资源组） |
| 计算型任务 CU | 最低 0.25 CU、步长 0.25；单任务建议 ≤16 CU（上限 64 CU）；同步任务（除实时同步）单任务最多 16 CU |
| 数据集成·离线同步 | 并发 <4 → 0.5 CU；并发 ≥4 → (并发数 − 4) × 0.07 + 0.5 CU |
| 数据集成·实时同步 | 单表实时 1 CU；MySQL 实时 1 库 2 CU（2 库及以上同）；整库实时最低 2 CU；Kafka 实时 1 CU |
| 数据服务 | 500/1,000/2,000 QPS → 最低 4/8/16 CU，SLA 99.95% |
| 个人开发环境 | CPU 类 2~100 CU；GPU 类 21~60 CU |
| 高可用 | 至少同城双可用区部署，单可用区故障任务自动 failover |

## 旧版独享调度/数据集成资源组规格与并发

独享**调度**资源组（包年包月，不支持跨地域、不支持 yum 命令）：

| 规格 | 最大并发运行实例数 |
|---|---|
| 4 vCPU 8 GiB | 16 |
| 8 vCPU 16 GiB | 32 |
| 12 vCPU 24 GiB | 48 |
| 16 vCPU 32 GiB | 64 |
| 24 vCPU 48 GiB | 96 |

独享**数据集成**资源组（包年包月，保障的是同步线程总数而非同步实例数）：

| 规格 | 离线同步最大并发线程数 |
|---|---|
| 4 vCPU 8 GiB | 8（开启分布式时不能设 8） |
| 8 vCPU 16 GiB | 16 |
| 12 vCPU 24 GiB | 24 |
| 16 vCPU 32 GiB | 32 |
| 24 vCPU 48 GiB | 48 |
