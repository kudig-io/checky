# 大数据开发治理平台 DataWorks（dataworks）

PaaS 级大数据开发与治理平台：以工作空间为隔离单元，覆盖数据集成、数据开发（Data Studio）、调度运维、数据质量、数据地图与数据服务；底层计算由 MaxCompute/Hologres/EMR/Flink 等引擎承担，引擎费用独立计费。

> 口径说明：官方版本为 **基础版/标准版/专业版/企业版** 四档（无「旗舰版」称谓，本目录按官方命名）；资源组已从旧版「独享/公共」演进为 **Serverless 资源组**（1 CU = 1 核 CPU + 4 GiB 内存）。
