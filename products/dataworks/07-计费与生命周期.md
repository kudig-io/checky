# DataWorks · 计费与生命周期

> 产品：DataWorks ｜ 口径：公共云 ｜ 复核：2026-11-16

## 计费组成

DataWorks 费用 = 软件版本费 + 资源组费 + 调度实例数费 + Data Agent 费 + 其他按量费用（数据质量、智能监控等）。

- 工作空间创建本身不产生费用；底层 MaxCompute 等引擎的计算与存储产生独立账单，不由 DataWorks 收取。
- 购买软件版本仅代表获得功能使用权，任务运行消耗的资源需单独计费。

## 调度实例数费用（任务调度费）

- 计费对象：使用 Serverless 或公共调度资源组、**运行成功**的实例（周期/手动/测试/补数据实例；虚拟节点除外）；空跑、未运行、失败、冻结实例不计费。

## 欠费与扣费规则

| 项目 | 规则 |
|---|---|
| 扣费周期 | Serverless 资源组、调度实例、数据质量、智能基线：按天（次日生成明细，月中冻结余额，月初出账）；公共数据服务资源组、公网流量：按小时 |
| 欠费 ≤24 小时 | 延续 24 小时服务，第 12、23 小时发通知；期间充值不停服 |
| 欠费 >24 小时 | 服务停用：无法启动新实例，已运行实例可运行至结束；公共数据服务无法调用已发布 API |
| OpenAPI 欠费 | 账号欠费立即停止 OpenAPI 调用 |
| 延停权益 | 阿里云提供欠费后延期免停额度，按历史消费每月自动计算 |
| 出账方式 | 每天/每小时按用量生成消费明细，月中冻结相应余额，下月初生成最终账单后扣除实际消费金额 |

## 生命周期（到期/续费/释放）

| 事件 | 规则 |
|---|---|
| 版本到期通知 | 到期前第 7、3、1 天分别向主账号手机/邮箱/站内信发送通知 |
| 版本到期处理 | 未续费则到期后立即停止增值版本功能并**降级为基础版**；代码、任务、节点不丢失；重新购买即恢复 |
| 降级影响 | 流程控制节点、Check/HTTP 触发器、代码评审、高级 API 等停用并导致任务失败；智能基线不产生基线实例；迁移助手导出包降为 10 个 |
| 资源组到期 | 到期立即停止服务；保留 **7 天**，7 天内续费可恢复，逾期释放（释放前 1 天通知）；续费后约 30 分钟恢复状态 |
| 按量资源组 | 7 天内未使用自动冻结，可手动启动；不使用不计费 |
| 工作空间删除 | 前置：无运行中任务；删除后数据源/计算资源/节点/资源进回收站保留 14 天，调度任务与数据集成不保障恢复 |
| 彻底停用顺序 | 下线 API → 删卡片报告 → 关基线 → 退订包年包月 → 删工作空间 |
