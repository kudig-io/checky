# NAT 网关 · 网关类型与规格

> 产品：NAT 网关 ｜ 口径：公共云 ｜ 复核：2026-11-18

## 类型对比（产品线 / 网关类型）

| 维度 | 公网 NAT 网关 | VPC NAT 网关 |
|---|---|---|
| API NetworkType | internet | intranet |
| 转换地址 | 弹性公网 IP（EIP） | NAT IP（从 NAT IP 地址段分配） |
| 能力 | SNAT/DNAT，公网出入流量 | 私网地址转换（冲突互访、指定地址访问） |
| EIP 绑定 | 支持（默认最多 20 个，见配额冲突说明） | 不支持绑定 EIP |
| 配额（单网关 NAT IP） | — | 默认 15 个，最大可提升至 50 个 |

- 官方 API `NatType` 当前取值仅 `Enhanced`（增强型）。
- 「标准型」（已核，2026-11-18）：官方类型体系为「公网 NAT 网关（API `NatType=Enhanced` 增强型）」与「VPC NAT 网关」两类，预付费规格为 `Small`/`Middle`/`Large`（ModifyNatGatewaySpec）；官方文档无「标准型」提法（该词为其他云厂商术语）。
- 「小规格」：对应存量按固定规格的 `Small`（小型）规格，仅存量实例存在，已停止新购。

## 容灾类型对比

| 维度 | 跨可用区容灾（默认） | 单可用区容灾 |
|---|---|---|
| 部署方式 | 主备两个可用区各部署一套，备可用区由阿里云选择 | 仅用户指定可用区内部署，设备级冗余 |
| 故障切换 | 可用区故障时自动切换 | 可用区整体故障时不自动切换 |
| 实例费 | 基准价 | 约为跨可用区的 50% |
| CU 费 | 基准价 | 约为跨可用区的 80%（国内地域 0~100 万 CU 0.184 元/个/小时，100 万以上 0.11） |
| 付费限制 | 按量计费 | 仅支持按量计费，不支持包年包月，暂不支持资源包抵扣 |
| SLA | 多可用区 ≥ 99.995% | 单可用区 ≥ 99.95% |

单可用区容灾已在 NAT 网关支持的所有地域开放，官方说明需联系客户经理申请。

## 存量固定规格（小/中/大，停止新购）

包年包月和按固定规格计费的后付费模式已停止新购；存量实例仍有小型、中型、大型规格。

| 规格 | 新建连接速率（CPS） | 并发连接数 | 吞吐量 | PPS |
|---|---|---|---|---|
| 小型 Small | 1 千 | 1 万 | 5 Gbps | 60 万 |
| 中型 Middle | 5 千 | 5 万 | 5 Gbps | 60 万 |
| 大型 Large | 1 万 | 20 万 | 5 Gbps | 60 万 |

- 最大连接数和每秒新建连接数均包含 SNAT 连接和 DNAT 连接。
- API `Spec` 仅在 `InstanceChargeType=PrePaid`（存量包年包月）时有效，`CreateNatGateway` 已将 Spec/PricingCycle/Duration/AutoPay 标为无效参数。

## 选型速查

| 场景 | 建议选择 |
|---|---|
| 多台 ECS 共享公网出口、统一管控 | 公网 NAT 网关 + SNAT 条目（VPC/交换机/ECS/网卡/自定义网段粒度） |
| 单台 ECS 对外提供指定端口服务 | 公网 NAT 网关 + DNAT 端口映射（不暴露全部端口） |
| 网段冲突的 VPC 互访 / 指定私网 IP 访问 IDC | VPC NAT 网关 |
| 业务跨可用区、要求更高可用 | 跨可用区容灾（默认） |
| 成本敏感、业务集中在单可用区 | 单可用区容灾（实例费约 50%、CU 费约 80%） |
| 存量小/中/大规格实例 | 转换为按使用量计费（转换不可回退，SNAT/DNAT/EIP/路由不变） |
| 需要 IPv6 公网转换 | ⚠️ 待核（2026-11-18 复核官方 NAT 网关 llms.txt 索引仍无 IPv6 表述，见 05 篇） |
