# NAT 网关 · 配额与限制

> 产品：NAT 网关 ｜ 口径：公共云 ｜ 复核：2026-11-16

> 官方说明：通用配额调整后，对新创建资源和存量资源均生效。默认值以配额中心/控制台为准。

## 通用配额（官方配额页）

| 配额名称 | 描述 | 默认值 | 调整 |
|---|---|---|---|
| natgw_quota_nat_num_per_vpc | 单个 VPC 内可创建的 NAT 网关数量 | 5 个 | 可提升（配额中心/配额管理页申请） |
| natgw_quota_nat_ip_num_per_vpc_nat | 单个 VPC NAT 网关可创建的 NAT IP 数量 | 15 个 | 可提升 |
| natgw_quota_eip_num_per_nat | 单个公网 NAT 网关支持绑定 EIP 的数量 | 20 个 | 可提升 |
| natgw_quota_dnat_entry_num | 单个 NAT 网关支持创建的 DNAT 条目数量 | 100 个 | 可提升 |
| natgw_quota_snat_entry_num | 单个 NAT 网关支持创建的 SNAT 条目数量 | 40 个 | 可提升 |

API 速率配额（QPS）不在文档列表，需在配额中心「API 速率配额」页查看。

## 配额口径冲突（功能特性页 vs 配额页）

功能特性页给出的默认值/上限与配额页不一致，按「官方最新 > 官方旧版」标注冲突：

| 项 | 配额页 | 功能特性页 | 状态 |
|---|---|---|---|
| 单网关绑定 EIP | 默认 20 个 | 去直通（NAT 普通）模式默认 15、最大 50；直通（多 EIP 网卡可见）模式默认 15、最大 512 | 冲突 ⚠️，以控制台/配额中心实际值为准 |
| 单网关 DNAT 条目 | 默认 100 个 | 默认 40、最大可提升至 3000 | 冲突 ⚠️ |
| 单网关 SNAT 条目 | 默认 40 个 | 默认 40、最大可提升至 2500 | 默认值一致，提升上限仅功能特性页给出 |
| VPC NAT 网关 NAT IP | 默认 15 个 | 默认 15、最大可提升至 50 | 默认值一致 |

## 硬限制

| 类别 | 限制 |
|---|---|
| 部署 | NAT 网关不能脱离 VPC 单独使用；部分可用区未部署，可通过 ListEnhanhcedNatGatewayAvailableZones 查询 |
| 交换机 | 创建后不支持切换所属交换机和私网 IP；只能新建网关 + 改路由 |
| EIP 地域 | EIP 须与 NAT 网关同地域，否则不出现在条目 IP 列表 |
| EIP 模式 | NAT（普通）模式不可切换为多 EIP 网卡可见模式；多 EIP 网卡可见模式不支持 IPv4 网关 |
| IPv4 网关配合 | 与 IPv4 网关结合时 NAT 网关必须为 NAT 模式；已建 MULTI_BINDED 网关无法创建 IPv4 网关 |
| DNAT 端口 | 范围 1~65535；任意端口（IP 映射）独占该 EIP 全部端口；端口段公私网数量须一致 |
| DNAT 互斥 | 任意端口（IP 映射）模式下该 EIP 端口被整体占用，不能再创建与其冲突的其他 DNAT/SNAT 条目 |
| DNAT 能力 | 不支持基于域名的请求分发（不解析应用层） |
| ECS 绑 EIP | ECS 绑定 EIP 后其出方向不经 NAT，SNAT 不生效；ECS 绑 EIP 时 DNAT 条目不生效（需解绑） |
| SNAT 端口 | 默认公网端口段 1025~65535；>1024 的 DNAT 公网端口需开「端口突破」（存量 SNAT 连接闪断） |
| SNAT 协议行为 | 仅支持主动出向，FTP 主动模式不可用（需被动模式） |
| 分片 | 支持 TCP/UDP/ICMP 分片数据包 |
| 删除 | 删除网关只解绑 EIP 不释放 EIP；SNAT/DNAT 删除不可恢复；支持删除保护 |
| 新建网关 | 系统自动添加 `0.0.0.0/0` → NAT 网关路由（仅系统路由表且无该条目时） |

## 性能上限（超限即丢包）

| 指标 | 跨可用区弹性上限 | 单可用区弹性上限 |
|---|---|---|
| CPS | 10 万 | 10 万 |
| 并发连接数 | 200 万 | 200 万 |
| 吞吐量 | 15 Gbps | 20 Gbps |
| PPS | 250 万 | 250 万 |

超过最大指标时业务访问面临丢包风险，更高性能需联系商务申请。存量固定规格（小/中/大）上限见 [02-网关类型与规格](02-网关类型与规格.md)。
