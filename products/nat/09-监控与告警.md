# NAT 网关 · 监控与告警

> 产品：NAT 网关 ｜ 口径：公共云 ｜ 复核：2026-11-17

## 核心监控指标

- NAT 网关已接入基础云监控，官方口径免费；增强型 NAT 网关的指标入口为云监控「指标和事件中心」的 `acs_nat_gateway / enhanced_nat_gateway`。
- RAM 用户查看 NAT 网关监控数据需具备 `AliyunCloudMonitorFullAccess` 权限。
- 统计周期：NAT 官方文档未标注各指标的 Period，下表按云监控常见取值填 60 秒，⚠️ 待核（以指标和事件中心「Min Periods」为准）。
- 维度：实例（单个 NAT 网关实例）；产品类型在云监控中选择「增强型NAT网关」。

| 指标（官方英文名） | 含义 | 单位 | 统计周期 | 维度 |
|---|---|---|---|---|
| `SessionActiveConnection` | 并发连接数：NAT 网关每分钟同时容纳的 TCP 和 UDP 连接数 | 次（count） | 60 秒 | 实例 |
| `SessionNewConnection` | 新建连接速率：NAT 网关每秒新建的 TCP 和 UDP 连接数 | 次/秒（count/s） | 60 秒 | 实例 |
| `SessionNewLimitDropConnection` | 新建丢弃连接速率：每秒因超过新建连接上限被丢弃的连接数 | 次/秒（count/s） | 60 秒 | 实例 |
| `SessionNewConnectionWater` | 连接水位：已建连接数占连接上限的百分比（官方英文口径） | % | 60 秒 | 实例 |
| `SessionNewLimitDropConnectionWater` | 新建连接水位：已建新连接数占新建连接上限的百分比（官方英文口径） | % | 60 秒 | 实例 |
| `BWRateInFromOutside` | 入方向流量速率：公网 → NAT 网关的每秒流量 | bps | 60 秒 | 实例 |
| `BWRateOutToInside` | 入方向流量速率：NAT 网关 → VPC 的每秒流量 | bps | 60 秒 | 实例 |
| `BWRateOutToOutside` | 出方向流量速率：NAT 网关 → 公网的每秒流量 | bps | 60 秒 | 实例 |
| `BWRateInFromInside` | 出方向流量速率：VPC → NAT 网关的每秒流量 | bps | 60 秒 | 实例 |
| `BytesOutToOutside` | 出方向流量：NAT 网关发往公网的总流量 | 字节（bytes） | 60 秒 | 实例 |
| `PPSRateOutToOutside` | 出方向包速率：NAT 网关发往公网的每秒包数 | pps | 60 秒 | 实例 |
| `PacketsOutToOutside` | 出方向包量：NAT 网关发往公网的包总数 | 个（packets） | 60 秒 | 实例 |

- 中文监控项还包括：端口分配失败丢失数、并发丢弃连接速率、吞吐、报文丢弃总速率、区间内 port 分配失败的个数与速率，以及入/出方向的 `Bytes*`/`PPSRate*`/`Packets*` 对称指标；这些指标官方文档未给出英文 MetricName，📋 待补（以指标和事件中心为准）。
- 水位基准（监控文档口径）：单实例默认每秒 10 万新建连接数、每分钟 200 万并发连接数；触发弹性能力变化后相关调整约 10 分钟内生效。
- ECS 粒度流量监控（网关流量监控，需开通网络智能服务 NIS 权限）：入/出方向带宽（bps）、入/出方向包速率（个/秒）、并发连接数（个）、新建连接数（个/秒），展示流量最大的前 100 个 ECS；开启后需等 15 分钟出数，数据延迟 3~5 分钟。
- 绑定 EIP 监控：流出/流入带宽（bps）、流出/流入带宽使用率（%）、流出/流入包速率（pps）、入/出方向限速丢包速率（pps）。

## 通知与渠道

| 渠道/机制 | 说明 |
|---|---|
| 通知方式 | 云监控报警服务支持电话、短信、邮件和 Webhook 地址；安装阿里云 App 可通过 App 接收报警通知 |
| 报警联系人组 | 创建 NAT 阈值报警规则时选择已绑定报警联系人的联系人组 |
| 轻量消息队列（原 MNS） | 报警发生时写入指定 Topic（推送与集成能力） |
| 函数计算 FC | 报警发生时将通知发送至函数计算进行处理 |
| 日志服务 SLS | 报警发生时将报警信息发送至 SLS 日志库 |
| NAT 阈值事件订阅 | 订阅阈值事件可定制报警通知：合并降噪避免报警风暴；未恢复时自动把通知发送给下一个报警联系人组；自定义通知渠道级别与模板；可直接把报警数据推送到 MNS、SLS、函数计算 FC 和 Webhook |
| 通道沉默周期 / 生效时间 | 报警规则配置项：沉默期内不重复发送；仅在生效时间内检查监控数据 |
| 服务状态订阅 | 健康看板「网络与CDN > NAT 网关」提供 RSS 订阅入口 |
