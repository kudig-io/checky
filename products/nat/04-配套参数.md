## 弹性公网 IP（EIP）

| 项 | 规则 |
|---|---|
| 必要性 | 公网 NAT 网关需绑定 EIP 才能正常工作；「稍后配置」创建的实例暂不具备公网能力 |
| 数量 | 单网关默认 20 个（配额页）/ 15 个起（功能特性页，按绑定模式提升至 50 或 512），冲突见 06 篇 |
| 计费 | EIP 有独立计费规则，与 NAT 网关实例费、CU 费分开计 |
| 释放 | 删除 NAT 网关只解除绑定，不释放 EIP；仅解绑不停止任何一方计费；停 EIP 计费需释放 EIP（按量 EIP 可释放，包年包月 EIP 到期自动停服） |
| 新购默认 | 创建网关时新购的 EIP 默认为 BGP（多线）按使用流量计费，可选带宽峰值 |
| 共享带宽 | 多 EIP 时官方建议将每个 EIP 加入同一个共享带宽，避免单 EIP 带宽打满 |
| 私网 IP | NAT 模式下每绑一个 EIP 占用网关所在交换机一个私网 IP，需预留地址 |

## 转发规则（DNAT 条目）

| 映射方式 | 行为 |
|---|---|
| 任意端口（IP 映射） | 访问该 EIP 的所有请求转发到目标 ECS；目标 ECS 也可用该 EIP 主动访问公网；该 EIP 不能再用于其他 DNAT/SNAT 条目 |
| 具体端口（端口映射） | 指定协议 + 公网端口/端口段 → 私网端口/端口段；公私网端口数量须一致（如公网 `10/20` 对私网 `80/90`） |
| 端口段 | 以正斜线 `/` 分隔起止端口，范围 1~65535 |
| 优先级 | 同一网关同时配了 DNAT IP 映射和 SNAT 时，ECS 访问公网优先使用 DNAT IP 映射的 EIP |
| 域名分发 | 不支持；DNAT 不解析应用层（无域名/Host/SNI），七层分发用 ALB 或自建 Nginx |

## 安全组与白名单配合

| 场景 | 配合规则 |
|---|---|
| SNAT 出方向 | 后端 ECS 安全组需放行访问公网的出方向流量；NAT 网关本身不做安全防护，防护仍依赖安全组和网络 ACL |
| DNAT 入方向 | 仅配 DNAT 时 ECS 收到的源 IP 是公网 IP，安全组入方向要用真实公网源 IP 放行 |
| 排查顺序 | 先用同 VPC 内 `telnet <私网IP> <私网端口>` 验证私网可达，再查安全组/防火墙是否放行对应端口 |
| 白名单 | 访问被拒时检查对端访问控制，或将实例绑定的 EIP 加入白名单 |
| ICMP 代回 | 默认开启；经 NAT 的 Ping 有回复不保证后端正常，具体端口映射场景 Ping 探测不可用 |

## 跨 VPC 共用 NAT（SNAT 出口共享）

| 方式 | 说明 |
|---|---|
| VPC 对等连接 | 互连后多个 VPC 共用同一公网 NAT 网关访问公网 |
| 转发路由器 TR | 使用转发路由器实现多个 VPC 共用 NAT 网关 |
| 云企业网 CEN | 官方 what-is 页列出 CEN 为多 VPC 共用 NAT 的互连方式之一 |
| 单 VPC 多 NAT | 同一 VPC 最多 5 个 NAT 网关（可提升）；多 NAT 共存时仅一条 `0.0.0.0/0` 默认路由指向其中一个，SNAT 源网段需覆盖对应交换机网段 |
