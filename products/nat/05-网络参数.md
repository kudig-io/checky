## 带宽与吞吐上限

| 层级 | 上限 | 说明 |
|---|---|---|
| 网关吞吐（跨可用区） | 初始 5 Gbps → 弹性 15 Gbps | 入流量 + 出流量合计 |
| 网关吞吐（单可用区） | 初始 10 Gbps → 弹性 20 Gbps | 单可用区容灾模式 |
| SNAT 出口带宽 | 由绑定的 EIP 带宽决定 | 不受 ECS 自身公网带宽限制（ECS 公网带宽 1 Mbps + EIP 100 Mbps → SNAT 出口可达 100 Mbps） |
| 多 EIP 叠加 | 支持绑定多个 EIP 叠加带宽 | 哈希分流，可能不均匀；建议加入同一共享带宽 |
| 共享带宽 | EIP 可加入共享带宽包 | 避免单 EIP 带宽打满；具体 EIP 带宽档位以 EIP 产品为准 ⚠️ 待核（本次未抓取 EIP 计费页） |
| 与 ECS 直绑对比 | — | 多 ECS 共享同一 EIP 时共享该 EIP 带宽，单台可用带宽随他人流量减少 |

注意：功能特性页「弹性提升至 20 Gbps」为汇总口径；按容灾类型分表（what-is 页）跨可用区为 15 Gbps，两页存在口径差异。

## 公网出入方向流量路径

出方向（ECS → 公网，SNAT）：

1. VPC 路由表 `0.0.0.0/0` 下一跳为 NAT 网关（系统路由表无该条目时，创建该 VPC 第一个公网 NAT 网关自动添加；自定义路由表需手动加）。
2. 网关按 SNAT 条目把私网源 IP 转换为 EIP，记录五元组映射。
3. 经 EIP 发往公网；回包按会话映射表还原私网 IP。
4. 目标网段重叠时按最长前缀匹配转发。

入方向（公网 → ECS，DNAT）：

1. 公网访问目标为网关绑定的 EIP。
2. 网关按 DNAT 规则把 EIP:端口 转换为私网 IP:端口 并转发。
3. ECS 回包按路由送往 NAT 网关，按映射表转回 EIP。

出口优先级：实例固定公网 IP/EIP > DNAT IP 映射（任意端口） > SNAT 条目绑定 EIP。ECS 绑定 EIP 时出方向不经过 NAT 网关。

## 协议与报文参数

| 参数 | 取值 |
|---|---|
| 支持协议 | TCP、UDP、ICMP 分片数据包均支持处理 |
| ICMP 代回 | 默认开启，不支持关闭（按量创建 API 默认 true） |
| SNAT 空闲超时 | TCP 900 秒；UDP 60 秒 |
| 分片 | 支持处理 TCP/UDP/ICMP 分片 |
| 性能影响因素 | 实例包长、连接类型（长/短连接）、网络架构；实际表现可能偏差，建议压测 |
