## 实例基础参数

| 参数 | 取值/规则 |
|---|---|
| 所属网络 | 必须指定 VPC 和交换机，创建时分配交换机内一个空闲私网 IP；不可脱离 VPC 单独使用 |
| 交换机变更 | 不支持切换所属交换机和私网 IP，只能新建网关并改路由 |
| 容灾类型 | CrossAZ 跨可用区（默认）/ SingleAZ 单可用区 |
| 付费模式 | PostPaid 按量付费（默认）；PayBySpec/PayByLcu 按使用量 |
| EIP 绑定模式 | MULTI_BINDED 多 EIP 网卡可见（API 默认）/ NAT EIP 普通模式（兼容 IPv4 网关）；控制台创建默认 NAT 模式 |
| ICMP 代回 | IcmpReplyEnabled 默认 true（开启） |
| 创建耗时 | 异步接口，一般 1~3 分钟，状态 Creating → Available |
| 删除保护 | 支持开启删除保护，删除前需关闭 |

| 指标 | 跨可用区 初始 | 跨可用区 弹性上限 | 单可用区 初始 | 单可用区 弹性上限 |
|---|---|---|---|---|
| 新建连接速率 CPS | 2 万 | 10 万 | 2 万 | 10 万 |
| 并发连接数 | 50 万 | 200 万 | 50 万 | 200 万 |

## DNAT 条目参数

| 参数 | 规则 |
|---|---|
| 条目数 | 默认配额 100 个（natgw_quota_dnat_entry_num）；功能特性页称默认 40、最大可提升至 3000，两处口径冲突，见 06 篇 |
| 映射方式 | 任意端口（IP 映射，占满该 EIP 全部端口）/ 具体端口（端口映射）/ 端口段（`10/20` 写法，公私网端口数量须一致） |
| 端口范围 | 1~65535 |
| 协议 | TCP/UDP/ICMP（任意端口即 IP 映射） |
| 互斥规则 | 任意端口模式下该 EIP 端口被整体占用，不能再建其他 DNAT/SNAT 条目 |
| 与 SNAT 复用 | 同一 EIP 可同时用于 SNAT 与 DNAT 条目；DNAT 具体端口 >1024 时可能与 SNAT 默认端口段冲突，需开启端口突破（会导致部分存量 SNAT 连接闪断） |
| 后端要求 | 后端 ECS 若已绑 EIP，DNAT 条目不生效，需先解绑；NAT 网关与后端 ECS 同地域同 VPC 即可（无需同可用区） |
| 不支持 | 域名分发（不解析应用层报文，需七层分发请用 ALB 或自建反向代理） |

## SNAT 条目参数

| 参数 | 规则 |
|---|---|
| 条目数 | 默认 40 个（natgw_quota_snat_entry_num），最大可提升至 2500 个 |
| 生效粒度 | VPC / 交换机 / ECS / 弹性网卡 / 自定义网段（CIDR） |
| 优先级 | 多条源网段重叠时最长子网掩码匹配，ECS 粒度 /32 最高 |
| EIP 绑定 | 一条 SNAT 可选多个 EIP，哈希分流；开启 EIP 亲和性后同一私网 IP 访问同一目的固定使用相同 EIP |
| 默认端口范围 | SNAT 默认分配公网端口 1025~65535；DNAT 需用 >1024 公网端口时需开「端口突破」 |
| 新建交换机 | NAT 网关不会自动为新建交换机加 SNAT 条目，需手动补配 |
| FTP | 主动模式不支持（仅主动出向），需用被动模式；多 EIP 时需开 EIP 亲和性 |
| 与路由关系 | 路由决定哪些流量进 NAT，SNAT 粒度决定对哪些源 IP 转换；两者范围建议一致 |

## EIP 绑定规则

| 规则 | 说明 |
|---|---|
| 默认配额 | natgw_quota_eip_num_per_vpc_nat 对应「单个公网 NAT 网关支持绑定 EIP 的数量」默认 20 个，可申请提升 |
| 冲突口径 | 功能特性页：去直通（NAT 普通）模式默认 15、最大 50；直通（多 EIP 网卡可见）模式默认 15、最大 512。与配额页 20 冲突，见 06 篇 |
| 普通（NAT）模式上限 | API 说明：EIP 普通模式绑定上限 50 个，且每新增一个 EIP 占用所在交换机一个私网 IP |
| 地域限制 | EIP 必须与 NAT 网关同地域 |
| 私网 IP 占用 | 2022-09-19 起新建公网 NAT 网关绑定 EIP 会占用所在交换机一个私网 IP（存量实例不受影响）；多 EIP 网卡可见模式不占用 |
| 模式切换 | NAT 模式不可切到多 EIP 网卡可见模式（API）；反向可切，EIP ≤5 个可直接 API 切换，>5 个需联系商务；切换有秒级闪断 |
| SNAT+DNAT 复用 | 同一 EIP 可同时用于 SNAT 和 DNAT 条目（任意端口模式除外，该 EIP 被独占） |
| 出口优先级 | 实例固定公网 IP/EIP > DNAT IP 映射 > SNAT 绑定 EIP；ECS 绑定 EIP 时出方向不经 NAT |
