## Endpoint 选择规则

| 维度 | 规则 |
|---|---|
| 协议 | 同时支持 HTTP 和 HTTPS |
| 地域选择 | 必须与 MaxCompute 项目（Project）所在地域一致，否则无法访问目标项目 |
| 阿里云内部客户端（如 ECS） | 推荐 VPC Endpoint，更安全稳定 |
| 阿里云外部（办公电脑） | 使用公网 Endpoint |
| VPC 未开通公网访问 | 仅可使用 VPC Endpoint |
| Tunnel 地址 | 仅配置主 Endpoint，MaxCompute 自动解析出对应网络的 Tunnel Endpoint |
| 云产品互联 | Quick BI 等云产品互联网络访问时选云产品互联 Endpoint |

Endpoint 示例格式（华东 1 杭州）：

| 网络 | 主 Endpoint | Tunnel Endpoint |
|---|---|---|
| 公网 | `https://service.cn-hangzhou.maxcompute.aliyun.com/api` | `https://dt.cn-hangzhou.maxcompute.aliyun.com` |
| VPC | `https://service.cn-hangzhou-vpc.maxcompute.aliyun-inc.com/api` | `https://dt.cn-hangzhou-vpc.maxcompute.aliyun-inc.com` |
| 云产品互联 | `https://service.cn-hangzhou-intranet.maxcompute.aliyun-inc.com/api` | `https://dt.cn-hangzhou-intranet.maxcompute.aliyun-inc.com` |

## VPC 私网连接（PrivateLink）

| 项 | 规则 |
|---|---|
| 原理 | 通过接口终端节点建立 VPC 与 MaxCompute 服务的私有连接，避免公网访问风险 |
| 需建终端节点数 | 2 个：`com.aliyuncs.privatelink.<region>.maxcompute.frontend`（主服务）+ `...maxcompute.tunnel.share`（Tunnel），建议同时开启 |
| 域名访问 | 需在终端节点详情页打开「自定义服务域名」开关 |
| 可用地域 | 杭州、上海、北京、张家口、乌兰察布、深圳、成都、香港、新加坡、吉隆坡、雅加达、东京、首尔、法兰克福、硅谷、弗吉尼亚（共 16 个） |
| 私网 Endpoint 格式 | `http://service-pvl.<region>-vpc.maxcompute.aliyun-inc.com/api`；Tunnel 为 `http://dt-pvl.<region>-vpc.maxcompute.aliyun-inc.com`（部分地域为 `dt.` 无 pvl 前缀） |
| 费用 | 开通时不产生费用；开通后按使用量每小时出账，含实例费和流量处理费，由服务使用方付费 |

**来源**：
- 通过VPC私网连接访问MaxCompute：https://help.aliyun.com/zh/maxcompute/user-guide/vpc-private-link-maxcompute ｜ 复核：2026-11-16

## 公网关闭后的连通方式

| 场景 | 做法 |
|---|---|
| VPC 未开通公网访问 | 客户端只能使用 VPC Endpoint（`service.<region>-vpc.maxcompute.aliyun-inc.com`） |
| odpscmd 配置 | `end_point` 填 VPC Endpoint，`tunnel_endpoint` 填 VPC Tunnel Endpoint；不填 tunnel_endpoint 时控制台自动获取，部分场景可能产生网络费用 |
| 云产品互联 | Quick BI 等用 `service.<region>-intranet.maxcompute.aliyun-inc.com` |
| 跨云专线接入 | 通过专线接入阿里云 VPC 网络，下载不收取公网下载费 |
| 作业访问 VPC 内资源（OSS/RDS 等） | 需创建「网络连接」并设置 `SET odps.session.networklink=<name>`（Spark 用 ENI 参数）；2026-06-30 起 SQL UDF/Spark/MaxFrame 禁止直接访问 OSS 内网地址，必须走网络连接 |
| Spark 访问 VPC 账号限制 | MaxCompute 项目与目标 VPC 必须归属同一主账号 |

## 网络隔离与访问控制

| 项 | 规则 |
|---|---|
| 三网隔离 | 经典网络、VPC 网络、Internet 网络三网隔离，只能访问各自对应的 Endpoint 及 IP |
| 无限制项目 | 未配置 VPC ID 及 IP 白名单的 Project 可被三种网络对应域名访问 |
| 配置 VPC ID | 该 Project 只能被对应的 VPC 访问 |
| 配置 IP 白名单 | 该 Project 只能被对应机器访问；加代理时以最后一跳代理 IP 及 VPC ID 判断 |
| 白名单格式 | 多个 IP 用逗号分隔；支持单独 IP、`-` 连接的 IP 段、带子网掩码的 IP |
| 白名单失效场景 | 开启白名单后，非白名单设备即使 AccessKey 正确也无法通过鉴权 |
| 任务级网络 | 安全容器 overlay 虚拟网络，同一任务节点间用私网 IP 通信；外部网络需求在作业启动时声明、经权限检查后按作业打通 |

## 跨项目访问与权限

| 方式 | 说明 |
|---|---|
| 基于 Package | 一个用户可同时拥有多个项目权限；通过安全授权在一个项目中访问另一项目的对象（基于 Package 跨项目访问资源） |
| 表达式 | 跨项目对象用 `<project_name>.<table_name>` 引用 |
| 外部项目 | `<external_project_name>.<table_name>`，计算资源归属关联的内部项目 |
| 权限对象粒度 | 项目（Project）、资源 Quota、网络连接对象（Networklink）、表、函数、资源、实例；支持对 Tunnel 下载、敏感数据访问、跨项目访问行为单独管控 |
