# MaxCompute · 计费与生命周期

> 产品：MaxCompute（原 ODPS） ｜ 口径：公共云 ｜ 复核：2026-11-16

## 计费项总览

MaxCompute 以项目为单位，对存储、计算和下载操作计费。

| 计费方式 | 说明 |
|---|---|
| 存储费用 | 按数据量阶梯计费；备份超 1 天部分按量计费 |
| 计算（按量付费） | SQL、MapReduce、Spark、Mars、查询加速 SQL、MaxFrame 按量计费 |
| 计算（包年包月） | 提前预订资源，先付费后使用（预留/非预留，非预留已停售） |
| 计算（按时计费） | 基于包年包月规格按时扩缩容，按扩容资源量 × 使用时长，后付费 |
| 计算（AI 计算资源） | GU Quota，按业务周期订购，先付费后使用，SLA 独立约定 |
| 模型计算（Token） | 大模型推理按 Token 量计量，按量付费 |
| 数据传输（公网下载） | 仅对公网下载数据收费；数据导入不收费 |
| 数据传输独享资源 | 公共资源组免费限量；独享资源组包年包月；按时计费按 Slots × 时长 |
| 开放存储（按量） | 第三方引擎经 Storage API 读取 MaxCompute 数据 |
| 跨地域灾备 / 存储容灾 | 按量计费（涉及跨地域复制存储 / 容灾计费规则） |
| Credits 费用 | MaxAgent 等 AI 能力按 Credits 计费 |

## 按量付费计算价格（公共云）

| 计费对象 | 计费公式 | 单价 |
|---|---|---|
| 标准 SQL 作业 | 输入数据量 × SQL 复杂度 × 单价 | 单日计算量 ≤100 TB：0.3 元/GB；>100 TB 部分 0.285 元/GB；>500 TB 部分 0.27 元/GB |
| SpotSQL（闲时版） | 同上 | 一般 0.1 元/GB |
| 外部表 SQL | 逻辑 size 数据量 × SQL 复杂度 × 单价 | 0.03 元/GB |
| 查询加速（MCQA） | 输入数据量 × SQL 复杂度 × 单价 | 0.3 元/GB |
| 标准 MapReduce | 当日总计算时 × 单价；计算时 = 运行小时 × Core 数 | 0.36 元/计算时 |
| Spot MapReduce | 同上 | 0.154 元/计算时 |

- 执行失败的 SQL/MapReduce 作业不计费；MR 排队时间不计费。
- 输入数据量按压缩后计量，受分区过滤与列裁剪影响。
- 按时计费（弹性预留/自动弹性）：0.315 / 0.36 元/CU/小时（公共云），按一级 Quota 小时粒度汇总 CU×时出账。
- 包年包月：标准 150 元/CU/月、多 AZ 高可用 195 元/CU/月。

## 存储分层计费（公共云价格）

| 存储类型 | 存储费（元/GB/天） | 数据访问费（元/GB） | 备注 |
|---|---|---|---|
| 单 AZ · 标准存储 | 0.004 | 不涉及 | 存储量 ≤512 MB 时按 0.01 元/天计费 |
| 单 AZ · 低频存储 | 0.00266 | 0.04 | — |
| 单 AZ · 长期存储 | 0.0011 | 0.522 | — |
| 多 AZ · 标准存储 | 0.0052 | 不涉及 | — |
| 多 AZ · 低频存储 | 0.00346 | 0.04 | — |
| 多 AZ · 长期存储 | 0.00143 | 0.522 | — |
| 备份存储 | 0.004 | 不涉及 | 保留周期 ≤1 天免费 |

计费公式：存储费 = 日存储量平均值 × 单价（日存储量平均值 = 采集存储量之和 ÷ 24）；数据访问费 = 数据访问量 × 单价（仅低频/长期产生）。
低频存储表或分区转为标准或长期存储时，收取低频存储数据访问费。
金融云价格（单 AZ 标准 0.0076、低频 0.00505、长期 0.0021 等）见同一页面。

## 公网下载与免费额度

| 项 | 规则 |
|---|---|
| 公网下载单价 | 一次下载费用 = 下载数据量 × 下载价格；公共云 0.8 元/GB，金融云 1.2 元/GB |
| 不收费方向 | 数据导入 MaxCompute 不计费；跨云专线接入阿里云 VPC 下载不收费 |
| 下载数据量口径 | 一次下载请求的 HTTP Body 大小（ProtoBuffer 编码） |
| 新用户免费额度（个人） | 计算抵扣包 500 CU*H + 100 GB，有效期 3 个月 |
| 新用户免费额度（企业） | 计算抵扣包 5000 CU*H + 100 GB，有效期 3 个月 |
| 存储免费额度 | 8 度（原文如此 ⚠️ 待核）、有效期 3 个月，可抵扣实际存储量 100 GB |
| 领取条件 | 从未开通购买过任何 MaxCompute 产品的账号；支持地域：杭州、上海、北京、深圳、成都 |
| 抵扣范围 | 仅抵扣按量付费标准版/闲时版的计算与单 AZ 标准存储；多 AZ 标准存储费不在抵扣范围，可能欠费 |

## 出账与账单

| 项 | 规则 |
|---|---|
| 存储费出账 | 当前计费周期结束后 3 小时内，最长不超过 6 小时；前一天账单一般次日 06:00 前生成 |
| SQL/MR 等计算出账 | 第二天对执行成功的作业一次性按项目汇总，06:00 前汇总至账号账单 |
| 扣费 | 账单生成后自动从账户余额扣除 |
| 消费告警 | 可对按量任务设置消费监控告警（每日消费总额上限告警） |

## 欠费与停服规则

| 计费方式 | 规则 |
|---|---|
| 包年包月 | 到期后立刻停服。地域已开通按量付费标准版：Quota 冻结，15 天内充值恢复；欠费超 15 天视为放弃 Quota 并删除释放，若按量服务同时注销则删除该地域全部项目且不可恢复，数据立即彻底删除。地域未开通按量付费：所有项目保留 15 天后释放，15 天内充值可恢复且存储照常计费；超 15 天视为放弃，释放前一天短信/邮件提醒，项目释放后数据 30 天内彻底删除 |
| 按量计费 | 可用余额小于上期账单即欠费。延停权益额度内不停服；超出后暂停服务，15 日内补缴恢复（15 天内保留数据存储照常收费）；欠费超 15 天视为放弃所有项目，释放且不可恢复，释放前一天提醒；项目释放后数据立即彻底删除 |
| 停服报错 | `ODPS-0420095: Access Denied - Authorization Failed [4093] ... Access Mode is AllDenied` |

海外/金融地域口径：香港、东京、新加坡、吉隆坡、雅加达、法兰克福、伦敦、硅谷、弗吉尼亚、迪拜、利雅得中，按量付费标准版开通时间在 2024-04-25 之前按「场景措施 2」，及之后按「场景措施 1」。

## 资源释放与生命周期

| 项 | 规则 |
|---|---|
| 表/分区生命周期 | 最后一次更新起指定时间无变动即被自动回收；用于自动清理或保留数据 |
| 表本地备份 | 默认免费保留 1 天；保留 >1 天的备份按 0.004 元/GB/天（公共云）计费 |
| 免费试用到期 | 计算抵扣包用尽或到期后按标准按量计费；存储到期正常收标准存储费 |
| 抵扣包抵扣时机 | 非实时抵扣，需等各计量计费项账单产出后抵扣 |
