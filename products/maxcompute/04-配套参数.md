## 数据集成（DataWorks 离线同步）

| 参数 | 官方规则 |
|---|---|
| 前提条件 | 已配置数据源；已购买独享数据集成资源组；资源组与数据源网络打通 |
| 写入模式 | 目标端（ODPS）清理规则可选「写入前清理已有数据 (Insert Overwrite)」等 |
| 切分键 splitPk | 推荐用表主键；仅支持整型切分；不填则单通道同步 |
| 任务期望最大并发数 | 定义并行读写最大线程数；实际并发可能小于配置值 |
| 同步速率限流 | 限速最小配置 1 MB/s；流量度量值是数据集成本身度量，网卡流量通常是通道流量的 1~2 倍 |
| 脏数据控制 | 不配置默认允许脏数据；配置为 0 表示不允许，出现即任务失败 |
| 分布式处理 | 并发数 ≥8 才能开启分布式模式；单机资源组不建议开 |
| MaxCompute Reader | 暂不支持在源端字段使用函数 |

## 数据传输服务（Tunnel）概述

- MaxCompute 的数据传输服务（DTS）= 普通 Tunnel（批量）+ Stream Tunnel（流式微批），另提供 odpscmd 的 Tunnel 命令。
- 一个地域只有一个共享资源组，对每个租户有并发上限；独享资源组（包年包月）单独购买、独享使用。
- 独享资源组网络限制：只支持云上 VPC 访问、只支持同地域；不支持排队策略，资源不足直接报错。
- 正常传输速度范围 1 MB/s~20 MB/s（受网络影响大）。

## Stream Tunnel（流式通道）限制

| 限制项 | 值 |
|---|---|
| 单 Slot 写入速度 | 10 MB/s |
| 单表并发写入分区数 | 64 个 |
| 单分区最大可用 Slot 数 | 32 个 |
| 并发 Flush 数 | 受 Slot 并发数限制，单次 Flush 占 1 Slot |
| STRING 字段大小 | ≤8 MB（上传数据限制） |

Delta Table Upsert：UpsertSession 生命周期 24 小时；最大写入速度 = 表或分区 Bucket 数 × 10 MB/s；每分区 1 分钟内仅允许 Commit 1 次，超出报 `CommitUpsert QPS Quota exceeded`。

## 冷热分层与长期存储

| 项 | 规则 |
|---|---|
| 存储类型 | 标准存储（默认）、低频存储、长期存储；仅对分区表的分区或非分区表设置，不支持对分区表整体设置 |
| 转换方向 | 标准→低频/长期、低频→长期：支持手动+自动，无 I/O 访问费；低频→标准、长期→低频/标准：仅手动，有 I/O 访问费 |
| 自动规则粒度 | 项目级（默认，作用于非分区表和未单独设规则的分区表）与分区表级（优先级更高）；不能为单个非分区表或单个分区单独设规则 |
| 规则条件 | `DaysAfterLastModificationGreaterThan` / `DaysAfterLastAccessGreaterThan`（多条件为 or 关系） |
| 规则扫描频率 | 平台每天定时扫描两次，转换存在延迟 |
| 访问费临界点 | 一个月全量访问一次低频存储 = 标准存储费用；六个月全量访问一次长期存储 = 标准存储费用 |
| 适用地域 | 杭州、上海、北京、张家口、乌兰察布、深圳、成都、香港、三朵金融云、新加坡、吉隆坡、雅加达、东京、法兰克福、硅谷 |
| 限制 | 低频/长期存储数据不支持 Hologres 直接访问；Hologres 直读不更新 last_access_time |
| 独立权限点 | 开启租户级开关后，读低频/长期数据需 `ReadLowFrequencyStorage` / `ReadLongtermStorage`，SELECT 仅可读标准存储 |

## 数据生命周期（Lifecycle）

- 表（分区）数据从最后一次更新起，经过指定时间无变动即被 MaxCompute 自动回收；该指定时间即生命周期。
- 表本地备份默认免费保留 1 天，可设置保留周期大于 1 天；超过 1 天的备份按存储费计费。
