## 日志类型总表

| 类型 | 产生方 | 查看入口 | 默认保留期 | 是否计费 |
|---|---|---|---|---|
| 流量日志（VPC 流日志，五元组流量条目） | VPC + 日志服务 SLS | 专有网络控制台 > 流日志；SLS 控制台 Logstore / Flowlog 日志中心 | 随 SLS Logstore 保存策略：勾选「流日志分析报表」默认 7 天，未勾选默认 300 天，可修改 | 流日志生成费（每账号每地域每月 5 GB 免费额度，超出按阶梯计费）+ SLS 存储/索引费 |
| 操作日志·管控事件（CreateVpc/CreateVSwitch/AllocateEipAddress 等） | 操作审计 ActionTrail | 操作审计控制台 > 事件查询 | 默认 90 天（仅保留最近 90 天） | 操作审计本身免费；创建跟踪投递 SLS/OSS 后按目标产品计费 |
| 审计事件投递副本（跟踪到 SLS 的 LogStore） | 操作审计 + 日志服务 SLS | SLS 控制台，Logstore 命名 `actiontrail_<跟踪名称>` | LogStore 默认永久保存（可修改） | SLS 按使用功能或写入数据量计费 |
| 配置审计（资源配置变更历史、不合规事件） | 配置审计 Cloud Config | 配置审计控制台（VPC 已接入，默认每隔 10 分钟记录资源配置变更） | 📋 待补（官方未标注保留期） | 官方口径「免费试用」；投递到 SLS/OSS 按目标产品计费 |
| 引擎日志（error/slow/general log） | — | — | — | — |

- VPC 是网络产品，**无数据库类引擎日志**（区别于 RDS 的错误日志/慢日志）；流量侧日志由流日志承担，管控侧由操作审计与配置审计承担。
- 阿里云 VPC 默认不记录网络日志；如需满足等保对网络日志的要求，需开启 VPC 流日志功能。
- 流量镜像为旁路复制流量到分析设备，不产生托管日志文件（镜像流量不支持镜像安全组/网络 ACL 丢弃流量、流日志流量）。

## 关键日志详表

**A. VPC 流日志条目（SLS 字段）**

| 字段 | 类型/取值示例 | 含义 |
|---|---|---|
| `srcaddr` / `srcport` | `10.0.0.1` / `53870` | 源 IP 地址与源端口（五元组之一） |
| `dstaddr` / `dstport` | `10.0.0.2` / `80` | 目的 IP 地址与目的端口（五元组之一） |
| `protocol` | `6`（TCP）、`1`（ICMP）、`17`（UDP） | IANA 协议编号（五元组之一） |
| `direction` | `in` / `out` | 流量方向：流入 / 流出弹性网卡 |
| `action` | `ACCEPT` / `REJECT` | 安全组或网络 ACL 是否允许该访问（允许/拒绝） |
| `bytes` / `packets` | `2048` / `10` | 该流的字节数与数据包个数 |
| `eni-id` / `vswitch-id` / `vpc-id` | `eni-bp1…` 等 | 弹性网卡、交换机、VPC 标识 |
| `log-status` | `OK` / `NODATA` / `SKIPDATA` | 日志记录状态：正常 / 无流量 / 高流量跳过 |

- 另有 `start`/`end`（采集窗口内首包时间/窗口结束或连接关闭时间，Unix 时间戳）、`tcp-flags`（TCP 标志位按位或）、`traffic_path`（流量场景 0~22，如 7=经 NAT 网关、15=经公网 IP 访问公网）。
- 每条条目对应采集窗口内的一个五元组网络流；采样间隔可选 1/5/10 分钟（默认 10 分钟），多实例同时采集同一网卡时取最小采样间隔。

**B. 审计管控事件（ActionTrail，VPC 事件结构）**

| 字段 | 含义 |
|---|---|
| `eventTime` | 事件发生时间（UTC 格式） |
| `eventName` | 事件名称，如 `CreateVpc`、`CreateVSwitch`、`AllocateEipAddress`、`CreateNatGateway`、`CreateHaVip` |
| `eventSource` | 事件来源（vpc.aliyuncs.com 等） |
| `eventType` | 事件类型：ApiCall / ConsoleOperation / ConsoleSignin 等 |
| `eventRW` | 事件读写类型：Read / Write |
| `sourceIpAddress` | 事件发起的源 IP 地址 |
| `userIdentity` | 请求者身份（root-account / RAM 用户 / 假定角色等） |
| `errorCode` | 云服务处理 API 请求发生错误时记录的错误码 |

- VPC 已接入操作审计的事件涵盖 CreateVpc/CreateVSwitch、AllocateEipAddress、CreateNatGateway、CreateVpnGateway、CreateHaVip、流日志与流量镜像等管控操作。

## 投递与加工

| 通道 | 去向与参数 | 关键限制 / 额度 | 计费要点 |
|---|---|---|---|
| 流日志 → 日志服务 SLS | 创建流日志时选择 Project 与 Logstore（建议新建隔离）；仅创建时可选，关闭后不支持重新开启 | 需先开通流日志与 SLS，并授权 RAM 角色 `AliyunVPCLogArchiveRole`（策略 `AliyunVPCLogArchiveRolePolicy`）；勾选「流日志分析报表」自动创建索引与仪表盘，Logstore 保存时长强制 7 天 | 流日志生成费 5 GB/账号/地域/月 免费，超出阶梯 2.5→0.25 元/GB；SLS 存储/索引按 SLS 计费 |
| 流日志 → NIS 流量分析器 | 选择流量分析器做流量分析；NIS 分析采样间隔须**大于**流日志采样间隔 | 与 SLS 二选一或并存；支持地域以官方列表为准 | NIS 流量分析处理费与存储费按 NIS 定价 |
| 采样与过滤（创建时参数） | 资源类型（弹性网卡/交换机/VPC）、流量类型（All/Allow/Drop）、IP 版本（IPv4/双栈）、采样间隔（1/5/10 分钟）、采样路径（NAT/VPN/TR/VBR/ECR/IPv4 网关/GWLB/公网等） | 同一资源已有「采集全部场景」实例时不能再建仅部分路径的实例；双栈流日志不支持自定义 trafficPath | 按采集到的日志量计费，路径过滤可降低日志量 |
| SLS 加工与二次投递 | SQL 查询分析、域间分析（自动生成网段字段的数据加工任务）、Flowlog 日志中心仪表盘；SLS 数据投递可将 Logstore 归档到 OSS、MaxCompute、AnalyticDB MySQL、TableStore | OSS 投递为同地域投递；数据投递实时性通常 5~30 分钟 | SLS 加工/投递按 SLS 定价；数据加工收费 |
| 操作审计跟踪投递 | 创建跟踪 → SLS LogStore（`actiontrail_<跟踪名称>`，默认建好索引与仪表盘）或 OSS Bucket | 单账号跟踪每地域 5 个、多账号跟踪全地域 1 个；1 个跟踪最多配 1 个 OSS Bucket；可创建数据回补任务追溯历史事件 | 操作审计免费；SLS/OSS 侧按各自定价计费 |
| 配置审计投递 | 将配置变更历史、不合规事件、定时快照投递到 SLS 指定日志库 | 单 Project 导入配置上限等按 SLS 规则 | 免费试用口径；投递按目标产品计费 |

- 跨账号：多账号跟踪可将资源目录成员账号的管控事件统一投递到管理账号的 SLS/OSS；OSS/RAM 用户投递需 `AliyunLogDefaultRole` 类角色授权。
- 停止/删除流日志后 VPC 不再收流日志生成费，但 SLS 中已保存日志持续计费，需到 SLS 控制台管理 Logstore 才能停掉全部费用。

## 审计与合规

| 项 | 官方口径 |
|---|---|
| 接入方式 | VPC 已接入操作审计（ActionTrail），记录用户通过控制台、OpenAPI、开发者工具操作 VPC 产生的管控事件 |
| 留痕范围 | CreateVpc/CreateVSwitch、AllocateEipAddress、CreateNatGateway、CreateVpnGateway、CreateHaVip、流日志与流量镜像管理等 VPC 管控操作 |
| 查询与保留 | 默认为每个阿里云账号记录最近 90 天事件；不创建跟踪无法追溯 90 天以前的事件 |
| 可查延迟 | 用户操作后 10 分钟内可通过控制台/OSS 查询到数据 |
| 长期保存 | 创建跟踪将事件投递到 SLS（LogStore 默认永久保存）或 OSS；等保 2.0 要求留存 180 天的场景需持续投递 |
| 配额 | 单账号跟踪每地域 5 个；多账号跟踪全地域 1 个；1 个跟踪最多 1 个 OSS Bucket；LookupEvents 每秒最多 2 次 |
| 配置审计 | VPC 已接入配置审计，默认每隔 10 分钟记录资源配置变更；提供等保 2.0 云上预检与配置合规审计（免费试用口径） |
| 网络日志合规 | VPC 默认不记录网络日志；开启 VPC 流日志可记录并分析出入弹性网卡流量，满足等保网络日志要求 |
| 事件告警 | 云监控订阅阈值事件可对报警通知做合并降噪，并推送至 MNS、SLS、函数计算、Webhook（见 [09-监控与告警](09-监控与告警.md)） |
