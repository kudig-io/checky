## 弹性公网 IP（EIP）

EIP 是可独立购买和持有的公网 IPv4 地址资源，可为专有网络类型 ECS、公网 NAT 网关、负载均衡等提供公网访问能力，支持动态绑定/解绑。

| 参数 | 数值 |
|---|---|
| 单个账号可申请的按量计费 EIP 数量 | 20 个（可提升） |
| 本地运营商线路 EIP 配额 | 每地域 5 个（占用上述整体配额） |
| 按使用流量计费 EIP 单个最大带宽峰值 | 200 Mbps（不作为业务承诺，争抢时受限） |
| 按固定带宽计费 EIP 单个最大带宽峰值 | 500 Mbps（按量付费模式，作为承诺指标） |
| 单地域单账号按流量 EIP 实际运行带宽峰值总和 | ≤5 Gbps |
| 单地域单账号按固定带宽 EIP 实际运行带宽峰值总和 | ≤50 Gbps（更大需申请） |
| 1 个 EIP 绑定云资源数 | 1 个（须同地域） |
| 1 个 ECS 实例绑定 EIP 数 | 1 个（可通过辅助弹性网卡扩展） |
| 1 个公网 NAT 网关绑定 EIP 数 | 20 个 |
| 1 个 CLB 实例绑定 EIP 数 | 1 个 |
| 1 个 HaVip 绑定 EIP 数 | 1 个 |
| 入方向带宽 | 峰值 ≥10 Mbps 时分配与峰值相等的入方向带宽；<10 Mbps 时分配 10 Mbps |
| 出方向带宽 | 与 EIP 带宽峰值相等 |

- 加入共享带宽的按流量 EIP：原计费方式和带宽峰值无效，由共享带宽计费，不受上述峰值限制。
- 2022-09-19 起，新创建的公网 NAT 网关绑定 1 个 EIP 会占用所在交换机的 1 个私网 IP。
- 本地运营商线路 EIP：仅支持美国（弗吉尼亚），创建后 30 天内不支持释放，服务可用性 99%。

## NAT 网关

NAT 网关分公网 NAT 网关（提供 SNAT/DNAT 出入公网）与 VPC NAT 网关（私网地址转换）。

| 配额/参数 | 默认值 |
|---|---|
| 单 VPC 内可创建的 NAT 网关数量（natgw_quota_nat_num_per_vpc） | 5 个 |
| 每个 NAT 网关可保有的 SNAT 条目数（natgw_quota_snat_entry_num） | 40 个（可提升至 2,500） |
| 每个 NAT 网关可保有的 DNAT 条目数（natgw_quota_dnat_entry_num） | 100 个 |
| 每个公网 NAT 网关绑定 EIP 数 | 20 个 |
| 每个 VPC NAT 网关可创建的 NAT IP 数 | 15 个 |
| 公网 NAT 最大并发连接数（SNAT） | N × 55,000（N = SNAT 条目配置的 EIP 数量） |
| SNAT 条目匹配规则 | 源网段掩码越长优先级越高（ECS 粒度 /32 最高） |
| 限速规则 | 单实例最多 100 条，每条最多 10 个源地址网段，单条 ≥10 Mbps（仅 SNAT 生效） |

- 公网 NAT 网关基础容量：5 Gbps、50 万并发、2 万 CPS；支持 5→20 Gbps 弹性扩容（官方功能页表述）。
- 单可用区容灾模式 NAT 网关仅支持按量计费，不支持包年包月，暂不支持资源包抵扣。

## VPC 对等连接

| 配额/参数 | 默认值 | 能否提升 |
|---|---|---|
| 单个 VPC 的同地域对等连接数（vpc_quota_intra_region_peer_num_per_vpc） | 10 个 | 可提升 |
| 单个 VPC 的跨地域对等连接数（vpc_quota_cross_region_peer_num_per_vpc） | 20 个 | 可提升 |
| 单账号单地域对等连接总数（vpc_quota_peer_num） | 20 个 | 可提升 |
| 跨地域带宽最大值（vpc_quota_peer_cross_region_bandwidth） | 1024 Mbps | 可提升 |
| 跨境带宽最大值（vpc_quota_peer_cross_border_bandwidth） | 1024 Mbps | 可提升 |
| 同地域对等连接带宽 | 不限制 | — |
| 路由传递 | 对等连接不具备路由传递能力（VPC 2/3 不能经 VPC 1 中转互通） | — |
| 跨境 | 支持非跨境与跨境；跨境需先完成跨境合规认证 | — |

## 云企业网（CEN）/ 转发路由器（TR）

| 参数 | 数值 |
|---|---|
| 单个 TR 默认可连接 VPC 数 | 1000 个 |
| 单个 VPC 支持指向转发路由器 TR 连接的最大路由条目数 | 600 条 |
| 组网方式 | Hub-Spoke，VPC 以网络连接方式加入 TR |
| 路由配置 | 支持路由学习、路由同步自动配置 |
| 同地域计费 | 收取连接费、流量处理费 |
| 跨地域计费 | 连接费 + 流量处理费 + 跨地域带宽费（带宽包实例费或流量传输费） |
| 同地域带宽（网络实例连接最大带宽） | 每可用区 100 Gbps（杭州/上海/北京/深圳/香港/新加坡）；50 Gbps（广州/河源/武汉-本地/雅加达/墨西哥）；其他地域 15 Gbps（无法调整） |
| 跨地域最大带宽（按流量付费） | 内地↔内地 1000 Mbps；内地↔境外 100 Mbps；境外↔境外 100 Mbps（均可提升） |
| 跨地域最大带宽（带宽包分配） | 带宽包带宽值；带宽包购买规格 2~10,000 Mbps |

- 选型口径（官方）：互连 2~3 个 VPC 推荐对等连接；超过 3 个推荐云企业网。
- 需要云上组播、服务链、跨地域 QoS 或不希望手动配路由时，官方推荐云企业网。

## 高速通道（Express Connect）

高速通道以物理专线连接本地 IDC 与阿里云，产品由物理专线连接、边界路由器 VBR、专线网关 ECR 组成。

| 参数 | 数值 |
|---|---|
| 独享专线传输速率 | 1 Gbps ~ 400 Gbps |
| 独享端口规格档位（资源占用费定价档） | 1 / 10 / 40 / 100 / 400 Gbps |
| 独享端口光口标准 | 1000Base-LX、10GBase-LR、40GBase-LR、100GBase-LR、400GBase-LR（LC 模式，传输距离 10 km 单模） |
| 共享端口规格档位 | 50 / 100 / 200 / 300 / 400 / 500 Mbps、1 Gbps；1 Gbps 以上默认不开放，需向商务经理申请 |
| 单链路最大带宽 | 400 Gbps |
| 多专线聚合 | 支持 ECMP 链路聚合，可达 Tbps 级 |
| 推荐带宽（接入方式） | 自主申请专线 1~400 Gbps（施工 1~3 个月）；共享合作伙伴预连接专线 <10 Gbps（1 个月内） |
| VBR 带宽档位（独享专线） | 50、100、200、300、400、500、1000、2048、5120、8192、10240、20480、40960、50120、61440、102400 Mbps（共 16 档） |
| VBR 带宽（共享专线） | 无需配置，等于创建共享物理专线时设置的带宽 |

- 端口资源占用费参考价（元/月，中国内地）：独享 1 Gbps 530、10 Gbps 4,400、40 Gbps 15,600、100 Gbps 33,900、400 Gbps 128,800；价格仅供参考，以购买页为准。
- 电口端口将于 2027 年 8 月 30 日后停止服务，存量电口专线需迁移至光口。
