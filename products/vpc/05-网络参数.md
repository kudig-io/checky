## VPC 内互通

| 场景 | 参数/结论 |
|---|---|
| 同一 VPC 内不同交换机 | 内网互通（含跨可用区），无额外费用 |
| 同地域对等连接带宽 | 不限制 |
| 同地域对等连接费用 | 免费（同账号或跨账号均不收费） |
| 跨 VPC 默认状态 | VPC 之间网络默认隔离，需显式打通 |
| IPv6 | 开启后默认仅私网互通；公网需单独开通 IPv6 公网带宽 |

- 内网流量受实例规格/网卡带宽约束（详见 ECS 网络参数篇）。
- 官方选型口径：同地域大带宽互联推荐对等连接；同地域不计费。

## 跨 VPC 连通方式

| 对比项 | VPC 对等连接 | 云企业网 CEN |
|---|---|---|
| 组网方式 | Full Mesh，VPC 两两互联 | Hub-Spoke，接入转发路由器 TR |
| 互连 VPC 数量 | 单 VPC 默认 10 个同地域 + 20 个跨地域 | 单 TR 默认 1000 个 VPC |
| 路由配置 | 必须手动为每个 VPC 配置路由 | 路由学习/路由同步自动配置 |
| 扩展性 | 弱 | 强 |
| 同地域带宽 | 不限制 | 网络实例连接最大带宽：每可用区 100 Gbps（杭州/上海/北京/深圳/香港/新加坡）；50 Gbps（广州/河源/武汉-本地/雅加达/墨西哥）；其他地域 15 Gbps（无法调整） |
| 跨地域带宽 | 默认限制 1024 Mbps | 按流量付费：内地↔内地 ≤1000 Mbps、内地↔境外 ≤100 Mbps、境外↔境外 ≤100 Mbps（均可提升）；从带宽包分配则为带宽包带宽值（购买规格 2~10,000 Mbps） |
| 同地域计费 | 免费 | 连接费 + 流量处理费 |
| 跨地域计费 | CDT 按出向流量收流量传输费（金/铂金两档链路） | 连接费 + 流量处理费 + 跨地域带宽费 |

- 选型：2~3 个 VPC → 对等连接；>3 个 → 云企业网；需组播/服务链/QoS → 云企业网。
- 对等连接不支持路由传递：三个 VPC 两两对等时，中间 VPC 不做中转，需逐对建连。
- 高速通道（Express Connect）用于连接本地数据中心：独享专线 1~400 Gbps（端口档 1/10/40/100/400 Gbps），共享端口 50 Mbps~1 Gbps（1 Gbps 以上需商务经理申请）；单链路最大 400 Gbps，多专线 ECMP 聚合可达 Tbps 级。

## 公网访问路径

| 路径 | 说明 | 关键带宽参数 |
|---|---|---|
| ECS 固定公网 IP | 创建实例时分配，不可解绑/换绑 | 见 ECS 网络参数篇（按流量峰值 100 Mbps / 固定带宽 200 Mbps） |
| EIP 直绑 ECS/CLB | 独立资源，动态绑定 | 按流量 ≤200 Mbps/个；按固定带宽 ≤500 Mbps/个；账号地域总和 5 / 50 Gbps |
| 公网 NAT 网关 SNAT | 多实例共享 EIP 出网，隐藏真实 IP | 基础容量 5 Gbps；最大并发 N×55,000（N=EIP 数） |
| IPv4 网关 + 网关路由表 | 控制公网入方向流量引流至安全设备 | 单 VPC 仅 1 个 IPv4 网关，配 1 张网关路由表 |
| IPv6 公网 | 开通 IPv6 网关公网带宽 | 默认仅私网，公网需单独开通 |
| 跨境访问 | 中国内地 ECS 经 EIP 访问境外延迟较高 | 官方建议同地域部署或用云企业网互联 |

- 公网入站方向控制链路：IPv4 网关 → 网关路由表 → （可选）安全设备（如云防火墙/自建防火墙）→ VPC 内实例。
- EIP 与 NAT 网关解绑不会停止任一方计费；停止 NAT 实例费需删除实例，停止 EIP 计费需释放 EIP。

## 附加网段与私网地址（配额口径）

| 参数 | 现行官方配额 |
|---|---|
| 单个 VPC 支持创建的附加 IPv4 网段数量（vpc_quota_secondary_cidr_num） | 5 个 |
| 单个 VPC 支持创建的附加 IPv6 网段数量 | 5 个（无法提升） |
| 单个 VPC 支持云资源使用的私网网络地址数量 | 300,000 个 |

- 口径冲突（v1 遗留）：旧版部分文档（2025 年前后镜像页）写附加 IPv4 网段为 1 个、私网地址为 60,000 个，与现行配额页冲突；以现行《限制与配额》页的 5 个 / 300,000 个为准，旧值不再引用。
- 私网地址计数口径：ECS 实例仅有一个私网 IP 时计 1 个；绑定多个网卡或网卡配置多个 IP 时，按所有网卡分配的 IP 地址数量之和计。
