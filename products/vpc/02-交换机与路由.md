## 交换机 CIDR 规则

| 规则项 | 数值/约束 |
|---|---|
| 交换机层级 | 可用区级资源，必须属于某个 VPC |
| 网段来源 | 必须是所属 VPC 主网段或附加网段的子网 |
| 同 VPC 互通 | 同一 VPC 内不同交换机之间内网互通 |
| 组播/广播 | 交换机不支持组播和广播 |
| 网段修改 | 交换机 IPv4/IPv6 网段均不支持修改 |
| 预留网段 | 单 VPC 的 IPv4、IPv6 预留网段各最多 100 个；IPv4 预留网段掩码 ≤28，IPv6 ≤80 |
| 数量配额 | 单个 VPC 支持创建的交换机数量 = 150 个 |

- 官方建议：使用一个 VPC 时也至少创建 2 个交换机并分布在不同可用区，实现跨可用区容灾。
- 删除交换机前提：未共享、未绑定自定义路由表和网络 ACL、交换机内云产品资源已释放。
- 交换机可用 IP 数公式（2026-11-18 复查已定）：IPv4 可用数 = 2^(32-掩码) − 4（每个交换机第 1 个和最后 3 个 IPv4 地址为系统保留地址，例：192.168.1.0/24 保留 .0/.253/.254/.255）；IPv6 每个交换机第 1 个和最后 9 个地址为系统保留地址。ECS 侧口径一致（192.168.0.0/16 可用私网 IP 65,532 = 65,536−4）。

## 路由表类型

| 对比项 | 系统路由表 | 自定义路由表（交换机型） | 网关路由表（边界网关型） |
|---|---|---|---|
| 绑定对象 | 交换机 | 交换机 | IPv4/IPv6 网关 |
| 创建方式 | 创建 VPC 时系统自动创建 | 手动创建（选择交换机类型） | 手动创建（选择边界网关类型） |
| 是否可删除 | 无法删除 | 可删除，需先与交换机解绑 | 可删除，需先与网关解绑 |
| 配额 | 一个 VPC 只有 1 个 | 一个 VPC 默认 9 个，可提升 | 一个 VPC 只能创建 1 个 |
| 使用场景 | 默认绑定所有新建交换机，统一控制流量 | 单独绑定目标交换机，控制其流量流向 | 绑定 IPv4/IPv6 网关，入方向公网流量安全引流 |

- 每个交换机必须绑定 1 张路由表；交换机绑定自定义路由表后自动解绑系统路由表，解绑后绑回系统路由表。
- 网关路由表仅允许修改系统路由，不支持创建自定义路由条目；编辑保存后转化为自定义路由条目。

## 路由条目类型

VPC 路由条目分 2 种：静态路由条目、动态路由条目。

| 类型 | 定义 | 可否自行创建/删除 |
|---|---|---|
| 系统路由条目 | 系统在创建 VPC 和交换机时自动添加、下一跳为 `Local` 的路由条目 | 不能自行创建，也不能删除 |
| 自定义路由条目 | 用户手动添加的路由条目 | 可自行创建和删除 |
| 动态路由条目 | TR、VPN 网关、专线网关 ECR 等网络实例传播至 VPC 的路由条目 | 系统接收/撤销 |

系统自动添加的 IPv4 系统路由：
- 交换机网段路由：以 VPC 内所有交换机网段为目标网段，用于交换机内实例相互通信。
- 云服务路由：目标网段 `100.64.0.0/10`，用于 VPC 内实例访问云服务；可配置更明细的自定义路由，但不允许与该网段相同。

自定义路由的下一跳可选：IPv4 网关、NAT 网关、VPC 对等连接、转发路由器、VPN 网关、ECS 实例、弹性网卡、高可用虚拟 IP、路由器接口（边界路由器/专有网络方向）、专线网关、网关型负载均衡终端节点等。

动态路由限制：
- 所有路由表默认开启动态路由接收，可按路由表粒度关闭。
- 单个路由表同一时刻仅接收单一路由动态源。
- 仅绑定交换机的路由表支持接收动态路由，绑定网关的路由表不支持。
- 来自 ECR 的动态传播路由默认最多 200 条生效，超限状态为「超限」暂不生效。

## 路由优先级

- 目标网段重叠时：IPv4 与 IPv6 流量路由彼此独立，按**最长前缀匹配**选择最明确路由。
- 新增路由与已有路由重叠的规则：

| 操作 | 已有系统路由 | 已有自定义路由 | 已有动态路由 |
|---|---|---|---|
| 创建交换机 | 交换机网段不支持与已有系统路由重叠 | 不支持相同网段，也不支持包含自定义路由网段 | 不支持相同网段，也不支持包含动态路由网段 |
| 新增自定义路由 | 不支持与系统路由网段相同，也不支持比系统路由更明细 | 不支持目标网段相同 | 不支持目标网段相同 |
| 接收动态路由 | 不支持与系统路由网段相同；更明细时不生效 | 网段相同时动态路由不生效，删除自定义路由后自动生效 | 不支持（单一路由传播源） |

- 特例：新增自定义路由下一跳为 VPN 网关或路由器接口时，与已有来自 CEN 的同网段动态路由冲突 → 动态路由撤销、自定义路由生效。
- 系统路由表中的系统路由条目不支持修改下一跳；自定义路由表中的系统路由条目支持改为 ECS 实例、弹性网卡、网关型负载均衡终端节点，修改后类型变为自定义路由条目。
