# VPC · 计费与生命周期

> 产品：VPC ｜ 口径：公共云 ｜ 复核：2026-11-16

## 免费项与付费项

VPC 本身是免费的；对等连接、流日志、流量镜像，以及在 VPC 中创建的其他产品资源会收取费用。

| 类别 | 功能 |
|---|---|
| 免费功能 | VPC 与交换机、附加网段、预留网段；DNS 主机名、DHCP 选项集；路由表、前缀列表；共享 VPC；ClassicLink、网关终端节点；IPv4 网关、网络 ACL |
| 公测期间免费 | IP 地址管理（IPAM）、高可用虚拟 IP（HaVip） |
| 收费功能 | VPC 对等连接、流日志、流量镜像 |

- 在 VPC 中创建云产品资源、或使用中产生存储/传输流量，按对应产品计费文档收费（EIP、NAT、SLB 等）。

- 产品计费：https://help.aliyun.com/zh/vpc/vpc-product-billing
- 复核：2026-11-16

## 付费项计费维度

### VPC 对等连接

| 项目 | 规则 |
|---|---|
| 同地域 | 免费（同账号/跨账号均不收费） |
| 跨地域 | 由云数据传输 CDT 按**出向**流量收流量传输费 |
| 链路类型 | 铂金（可用性承诺 99.995%）、金（99.95%） |
| 计费周期 | 每小时；周期内切换链路类型按较高档单价计费 |

金档示例单价（元/GB，A→B 与 B→A 同价）：

| 流出 \ 流入 | 中国内地 | 亚太 | 欧洲 | 北美 | 南美 | 中东 |
|---|---|---|---|---|---|---|
| 中国内地 | 0.48 | 5.6 | 5.6 | 5.6 | 5.6 | 5.6 |
| 亚太 | 5.6 | 0.525 | 0.525 | 0.525 | 2.5 | 2.5 |
| 欧洲 | 5.6 | 0.525 | 0.131 | 0.35 | 2.5 | 2.5 |
| 北美 | 5.6 | 0.525 | 0.35 | 0.131 | 2.5 | 2.5 |

铂金档：中国内地内 0.72 元/GB；跨境方向 8.4 / 3.75 元/GB（内地×境外），欧美之间 0.197~0.525 元/GB。

### 流日志

- 计费项 = 流日志生成费 + SLS 服务费 + 流量分析器处理/存储费（投递时产生）。
- 流日志生成费：按月每地域阶梯累积，每账号每地域每月 **5 GB 免费额度**；计费周期 1 小时。

| 每月生成量阶梯 | 单价（元/GB） |
|---|---|
| 0~10 TB（含） | 2.5 |
| 10~30 TB（含） | 1.25 |
| 30~50 TB（含） | 0.5 |
| >50 TB | 0.25 |

### 流量镜像

| 计费项 | 单价 |
|---|---|
| 实例费 | 0.1 元/个/小时（镜像源数 × 活跃时长，不足 1 小时按 1 小时） |
| 流量处理费 | 0.05 元/GB（**2027-03-31 前免收**） |

- 单个镜像源创建多个镜像会话，实例费仅收一次；活跃时长跨会话累计。

### 配套产品计费维度（强绑定）

| 产品 | 计费维度 |
|---|---|
| EIP | 按使用流量（出向流量费，入向免费）/ 按固定带宽；计费周期 1 小时（按流量）或 1 天（按带宽）；部分场景收 EIP 配置费（公网 IP 保有费） |
| NAT 网关 | 实例费 + 容量单位 CU 费；仅后付费按量计费，计费周期 1 小时；2025-09-26 起 CU 费仅按该小时处理流量 CU 个数（1 CU = 1 GB 处理流量） |
| NAT 实例单价 | 内地跨可用区 0.23 元/小时、单可用区 0.115 元/小时；海外 0.3 / 0.15；沙特 0.4 / 0.2 |
| NAT CU 单价 | 内地跨可用区 0.23 元/个/小时；单可用区 0~100 万 CU 0.184、100 万以上 0.11 |
| CEN | 同地域：连接费 + 流量处理费；跨地域：另加跨地域带宽费 |

- 创建按量 NAT 网关前，账号可用余额（含代金券/优惠券）需 ≥100.00 元。
- NAT 网关不支持新购包年包月；不支持包年包月和按固定规格的后付费模式已停止新购。

## 欠费规则

- 欠费后在**延期免停权益**额度内，服务不停止、实例继续运行，延停期间正常计费。
- 超出延停权益额度后服务自动停止，计费停止。
- 流日志：实例停止后 7 天内充值补足 → 自动恢复；7 天未补足 → 实例自动释放，配置和数据删除不可恢复。
- 流量镜像：功能停止后 15 天内充值补足 → 自动恢复，镜像会话自动恢复；15 天未补足 → 镜像会话实例删除，不可恢复。
- NAT 网关：实例锁定后 7 天内充值 → 自动开启；7 天未补足 → 实例删除（删除前一天提醒），配置和数据删除不可恢复。
- 余额预警：账号余额低于设定值时短信/邮件提醒；NAT 另按最近 24 小时账单均值预判后 3 个账单支付能力。

## 资源生命周期

| 资源 | 删除/停止计费条件 |
|---|---|
| VPC | 内部资源已释放完成，且已取消与云企业网等网络服务的关联 |
| 交换机 | 未共享、未绑定自定义路由表和网络 ACL、交换机内云资源已释放 |
| 路由表 | 仅自定义路由表可删除：先解绑交换机/网关，且已删除所有自定义路由条目；系统路由表不可删除 |
| NAT 网关 | 删除实例后停止计费；仅解绑 EIP 不停止任一方计费；需释放 EIP 才停 EIP 计费 |
| EIP | 仅按量计费 EIP 支持释放；包年包月 EIP 到期后自动停止服务；解绑后 EIP 仍继续收费 |
| 预留网段 | 删除前需确保无 IP 段占用 |
