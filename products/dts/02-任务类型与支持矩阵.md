# DTS · 任务类型与支持矩阵

> 产品：DTS ｜ 口径：公共云 ｜ 复核：2026-11-16

## 三类任务对比

| 维度 | 数据迁移 | 数据同步 | 数据订阅 |
|---|---|---|---|
| 目的 | 一次性将数据从源库迁移至目标库，完成后源库通常不再使用 | 两端长期、持续的动态一致复制 | 捕获源库增量，供下游按需消费 |
| 任务生命周期 | 流程结束即停止 | 长期运行 | 长期运行 |
| 阶段 | 结构迁移 + 全量 + 增量（可组合） | 同步初始化 + 实时同步 | 日志拉取 + SDK 消费 |
| 拓扑 | 一对一同构/异构链路 | 单向（一对一/一对多/多对一/级联）、双向 | 单源多消费组 |
| 双向同步 | 不支持 | 支持（限特定数据库组合） | 不适用 |
| 计费方式 | 仅按量付费 | 包年包月 / 按量付费 / Serverless | 包年包月 / 按量付费 |
| 典型选型 | 上云、更换数据库、机房搬迁 | 异地多活、灾备、读写分离、报表分流 | 缓存更新、异步解耦、实时数据流 |
| 与对方的差异 | 迁移在某些场景可实现部分同步功能，但适用场景、功能和收费有区别 | 同步价格高于迁移：功能更多（在线改同步对象、双向同步），且基于内网传输 | 输出为 JSON 数据流，按消费量计流量费（部分任务） |

## 通用支持口径

| 项目 | 官方口径 |
|---|---|
| 跨地域任务 | 仅当目标库为函数计算 FC 时不支持跨地域，其余链路均支持 |
| Serverless 实例 | 源或目标为 RDS MySQL 的链路支持 RDS MySQL Serverless；RDS PostgreSQL 链路仅目标库支持；暂不支持消息队列 Kafka 版 Serverless |
| 跨阿里云账号 | 是否支持取决于数据库类型和接入方式 |
| MyBase 专属集群 | 可通过「云实例」接入方式被 DTS 正常读取 |
| 同步方案缺口 | 源端类型不在同步方案中时，可尝试数据投递 |
| 数据源类别 | 关系型（MySQL、PostgreSQL、SQL Server、Oracle 等）、NoSQL（MongoDB、Redis 等）、大数据仓库（AnalyticDB、MaxCompute 等） |
