# DTS · 计费与生命周期

> 产品：DTS ｜ 口径：公共云 ｜ 复核：2026-11-16

## 计费方式总览

| 计费方式 | 支持的实例 | 规则（官方口径） |
|---|---|---|
| 包年包月（预付费） | 数据订阅实例、数据同步实例 | 新建实例时支付；适合长期，价格比按量优惠；支持非全额退订 |
| 按量付费（后付费） | 数据迁移、数据订阅、数据同步实例、数据校验任务 | 每小时生成一个收费订单，按天推送账单并按实例规格从账号扣费 |
| Serverless | Serverless 实例 | 分钟级动态匹配资源、实时计费（每小时生成订单、按天推送账单扣费），仅为实际用量付费 |

- 数据迁移实例仅支持按量付费，且不支持转换计费方式；数据同步/订阅支持按量与包年包月互转（新版控制台）。
- 实例开始计费后，只有运行失败、完成或释放后才停止计费。
- 按量计费维度是实例运行时长和链路规格（如 1 核 2 GB、2 核 4 GB），不是数据条数/表数/存储量；任务运行即按小时计费，与源端是否有变更无关。
- 源或目标库到期锁定时 DTS 仍可正常连接并继续计费，需及时释放 DTS 实例。

## 计费项与暂停期规则

| 任务类型 | 计费项 | 起止与暂停规则 |
|---|---|---|
| 数据迁移 | 增量迁移配置费（按量） | 仅在增量迁移正常运行期间计费；结构迁移和全量迁移期间不计费；暂停和失败期间不计费；不勾选增量迁移则不收费 |
| 数据迁移 | 公网流量 | 目标库接入方式为公网 IP 时产生：出云 0.8 元/GB（不足 1 GB 按 1 GB），入云免费 |
| 数据同步 | 增量同步配置费 | 预检查通过且购买成功、增量数据采集模块启动后计费（含暂停期间）；失败期间不计费；同步实例默认包含增量任务，必然产生费用 |
| 数据同步 Serverless | 资源（DU）使用量 | 增量数据采集模块启动后计费（含暂停期间），仅按量付费 |
| 数据订阅 | 订阅通道配置费 | 启动后开始计费；暂停期间仍收费 |
| 数据订阅 | 数据流量 | 包年包月 + 源库 MySQL：半价配置费 + 1 元/GB（自 2020-12-18 起，不足 1 GB 按 1 GB）；其他订阅任务暂不收流量费 |
| 数据校验 | 校验任务配置费 | 仅按量付费；按表行数校验不收费，按行抽样全字段校验按实际校验数据量收费；增量校验暂停期间也收费 |
| 专属集群 | 集群规格 + 公网流量 + 存储资源 | 见专属集群计费方式文档 |
| 欠费前 1 小时计费 | 各按量任务通用 | 使用 ≤ 0.5 小时按 0.5 小时计，> 0.5 小时按 1 小时计 |

## 出账、支付与价格入口

| 项目 | 官方口径 |
|---|---|
| 出账节奏 | 按量：每小时生成一个收费订单，按天推送账单并扣费 |
| 支付方式 | 阿里云账户余额、支付宝、企业网银、线下汇款 |
| 价格入口 | 按量付费价格（含 Serverless）与包年包月价格见官网价格页；价格取决于任务类型、计费方式、集群类型、地域、链路数量、订购时长等 |
| 分布式源库的价格变量 | 源库为 PolarDB-X 1.0、DMS LogicDB、分片集群 MongoDB、日志服务 SLS、Tair/Redis 时，同步与校验任务价格还与节点数量有关 |
| 转换计费方式 | 购买后可转换（迁移实例除外；旧版控制台仅支持按量转包年包月） |

## 到期与欠费停服

| 计费类型 | 到期/欠费影响 |
|---|---|
| 包年包月 | 实例到期后数据传输任务停止服务并冻结；自冻结之日起 7 天内未续费，系统释放并删除该实例，不可恢复 |
| 包年包月（专属集群） | 集群到期或欠费时，集群内 DTS 实例锁定，7 天后释放实例并释放专属集群资源 |
| 按量付费 | 欠费后账号下所有按量付费实例进入延停状态；延停权益额度内不停服且正常计费；超出延停额度后实例冻结、停止服务 |
| 按量付费（冻结后） | 自冻结之日起 7 天内未充值成功，系统释放并删除该实例，不可恢复 |
| 延停额度 | 按历史消费等因素每月自动计算，不是欠费总额上限 |

## 生命周期收尾动作

| 阶段 | 动作 / 规则 |
|---|---|
| 包年包月到期未续费 | 实例会自动释放，数据将会丢失 |
| 用完即释放 | 按量任务用完应尽快结束/释放实例以停止计费；释放当天使用过 DTS 仍会产生当天账单 |
| 自动续费 | 不再使用的包年包月任务须手动取消自动续费或释放实例，否则持续产生费用 |
| 退订 | 包年包月支持非全额退订；先了解退款规则 |
| 切换后收尾 | 业务切换完成并稳定后结束反向迁移任务；删除迁移账号或回收写权限；防止 7 天内失败实例被自动恢复覆盖目标库 |
| 账单查询 | 费用中心的 DTS 账单明细可查运行时间费用、增量数据校验费用等构成 |
