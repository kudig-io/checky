# 数据传输服务 DTS（dts）

> 产品：DTS ｜ 口径：公共云 ｜ 复核：2026-11-17

DTS（Data Transmission Service）是阿里的数据迁移、同步、订阅、加工、校验于一体的传输服务，支持 RDBMS、NoSQL、OLAP 等数据源。
