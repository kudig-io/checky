## 数据同步链路规格（同步数据流转上限）

RPS = 每秒增量同步至目标表的数据行数。规格以同步的记录数为衡量标准。

| 规格 | 性能上限（RPS）参考 |
|---|---|
| micro | 200 以内 |
| small | 2,000 |
| medium | 5,000 |
| large | 11,000 |
| xlarge | 17,000 |
| 2xlarge | 34,000 |
| 4xlarge | 68,000 |
| 6xlarge | 102,000 |
| 8xlarge | 136,000 |

达标前提（三条同时满足）：源实例压力 ≥ 规格对应上限；目标实例写入性能不是瓶颈；源/目标实例与 DTS 服务器的网络延迟 ≤ 2 ms。
- 该性能规格为测试数据，不作为产品 SLA 评判标准，不在 SLA 承诺范围内。
- 不建议将 micro 规格实例用于生产环境。

- 数据同步链路规格说明（仅供参考非 SLA 承诺）：https://help.aliyun.com/zh/dts/product-overview/specifications-of-data-synchronization-channels ｜ 复核：2026-11-18

## 数据迁移链路规格（增量迁移性能上限）

规格以增量迁移性能为衡量标准；全量迁移任务的性能不受链路规格的限制。

| 规格 | 性能上限（RPS）参考 |
|---|---|
| small | 2,000 |
| medium | 5,000 |
| large | 6,000 |
| xlarge | 7,000 |
| 2xlarge | 11,000 |

官方测试模型：源/目标均为 rds.mys2.8xlarge（内存 48,000 MB、最大连接数 2,000、最大 QPS 18,000、最大 IOPS 14,000）；20 张有主键的表、记录 1 KB、每事务平均 2 条 DML + 1 条 COMMIT（INSERT:UPDATE:DELETE = 3:1:2）。

| 场景（源→目标） | 网络延迟（毫秒） | 规格 | 实测 RPS |
|---|---|---|---|
| 杭州→杭州 | 0.26 | small / medium / large | 2,566 / 4,726 / 6,378 |
| 杭州→青岛 | 26 | small / medium / large | 2,469 / 4,856 / 5,439 |
| 杭州→北京 | 26 | small / medium / large | 2,533 / 5,038 / 6,829 |
| 杭州→硅谷 | 175 | small / medium / large | 1,753 / 2,837 / 3,884 |
| 新加坡→硅谷 | 198 | small / medium / large | 1,104 / 1,724 / 2,256 |

- 表无主键、网络延迟大、存在更新热点或源/目标有性能瓶颈时，达不到上表增量迁移性能。
- 达标前提与同步规格相同（含网络延迟 ≤ 2 ms）；性能上限仅供参考，不在 SLA 承诺范围内。

## Serverless 链路规格（DU 与上限）

DU（DTS Unit）是 Serverless 实例规格的计量单位，表示实例资源（CPU、内存、磁盘等）。

| DU 数 | 性能上限（RPS）参考 |
|---|---|
| 1 | 200 |
| 2 | 1,000 |
| 4 | 3,000 |
| 8 | 9,000 |
| 16 | 17,000 |
| 32 | 35,000 |

- 实际性能受网络环境、源/目标实例性能与延迟影响；性能上限仅供参考，不在 SLA 承诺范围内。

## 全量 / 增量阶段性能与时延口径

| 指标 | 官方数字 / 口径 |
|---|---|
| 全量数据迁移峰值性能 | 70 MB/s |
| 实时同步峰值性能 | 30,000 RPS（并发粒度缩小至事务级别） |
| 同步时延 | 可实现数据秒级同步，但受源库负载、网络带宽与延时、目标写入性能影响，无法绝对保证秒级延迟 |
| 切换判定阈值 | 迁移任务「增量迁移」显示无延迟或延迟低于 5 秒，方可进入业务切换 |
| 切换稳定阈值 | 停写后等待增量再次「无延迟」并保持 1 分钟以上，再手动暂停任务 |
| 性能规格与 SLA | 规格表为测试数据，不作为 SLA 评判标准 |

- 端到端时延的量化承诺值（如 P99 时延）：官方未发布——链路规格页明确「实际性能受源库负载、网络延迟、目标写入能力影响，仅供参考非 SLA 承诺」，SLA 只承诺服务可用性（2026-11-18 复核规格页与产品索引）。

## 流量类参数（公网 / 数据流量）

| 计费项 | 单价 | 规则 |
|---|---|---|
| 出云流量（目标库接入方式为公网 IP 且数据出云） | 0.8 元/GB | 按实际产生流量计费，不足 1 GB 按 1 GB 计费 |
| 入云流量（本地库经公网迁入云上） | 免费 | 不收费 |
| 阿里云间流量 | 仅当目标库接入方式为「公网 IP」时收取 | 源/目标均走阿里云内网互联（同 VPC、私网连接）时不产生该费用 |
| 订阅数据流量（包年包月 + 源库 MySQL） | 1 元/GB | 半价配置费 + 1 元/GB 数据流量费，自 2020 年 12 月 18 日起收取；不足 1 GB 按 1 GB 计算 |
| 其他类型订阅任务 | 暂不收取数据流量费 | — |
| 全量校验流量 | 按实际校验数据量收费（按行抽样全字段校验） | 按表行数校验模式不收费 |

- DTS 本身不设任务级「数据流转流量上限」数值；官方未发布账号级/任务级流量封顶配额（2026-11-18 复核产品索引）。任务侧可控的是速率：性能监控页可限速，`ModifyDynamicConfig` 的 `ConfigList` 可设 RPS/BPS 上限（`-1` 为不限速）；公网出云链路的流量上限取决于所购弹性公网 IP 的带宽峰值（见 05）。
