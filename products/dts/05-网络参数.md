# DTS · 网络参数

> 产品：DTS ｜ 口径：公共云 ｜ 复核：2026-11-16

## 接入方式总览

DTS 连接数据库时由「接入方式」决定行为，共 6 种（以控制台显示为准，接入方式因任务类型、数据库类型、源/目标组合而异）：

| 接入方式 | 适用场景 | 是否需手动加白名单 |
|---|---|---|
| 云实例 | 阿里云 RDS、PolarDB、MongoDB 等云数据库 | 否（特殊情况除外）：系统自动添加 DTS IP 到白名单；例外为 MaxCompute/OceanBase 及跨境或跨地域迁移任务 |
| ECS 自建数据库 | 部署在阿里云 ECS 上的数据库 | 否（集群除外）：自动加入安全组 `SG-DTS-GROUP-xxxx`；集群部署仅自动配置第一个节点，其余节点需手动加入 |
| 公网 IP | 本地 IDC 自建库、其他云厂商库、任何可暴露公网 IP 的库 | 是：手动添加对应地域 DTS 服务器 IP 段 |
| 专线 / VPN 网关 / 智能网关 | 经专线或 VPN 连接的本地 IDC 数据库 | 是：手动添加（含 CEN/本地白名单，见下） |
| 云企业网 CEN | 经云企业网连接的本地 IDC 数据库 | 是：手动添加 |
| 数据库网关 DG | 经数据库网关连接的数据库 | 是（配置网关 IP）：无需加 DTS 服务 IP，只需将 DG 所有网关节点 ID 的 IP 加入数据库安全设置 |

- DTS 支持的网络接入方式概述（官方产品优势口径）：公网、专线、VPN 网关、智能网关等多种网络接入方式。
- 「中转实例」未出现在 6 种官方接入方式清单中；官方「中转」方案为公网 NAT 网关中转（中转 VPC，见下）。若另有以中转实例接入 DTS 的官方形态：⚠️ 待核

## 白名单要求

| 任务类型 | 添加白名单的数据库 | DTS 服务器 IP 所属地域 |
|---|---|---|
| 数据同步 | 源库 | 源库和目标库所在地域 |
| 数据同步 | 目标库 | 目标库所在地域 |
| 数据迁移 | 源库 | 目标库所在地域（若任意一方为公网 IP 接入，公网接入方需同时加源+目标两个地域的 IP 段） |
| 数据迁移 | 目标库 | 目标库所在地域 |
| 数据订阅 | 源库 | 源库所在地域 |
| 数据校验（单独任务）/ 数据准备 | 源库与目标库 | 目标库所在地域 |

- IP 列表以该文档附录的 IP 地址段为准（控制台授权弹窗可能存在信息延迟）；收到 DTS 白名单扩容通知时须及时更新。
- CEN 接入：更新 CEN 的「访问云服务配置」；专线/VPN/智能网关：更新 IPsec 连接的「本端网段」；本地数据库：更新数据库安全设置。
- 必须完整添加所需地域 IP 段：DTS 服务节点可能因容灾切换，列表不完整会导致切换后任务中断。
- 集群部署（Kafka、Redis、Doris 等）的每一台服务器都要加白名单。
- DTS 自动创建的白名单名称含 `dts`/`DTS`（如 `rdsdts`、`dtspolardb`、`dts_group`），仅供 DTS 使用，勿挪作他用。
- 云实例需通过云数据库控制台的白名单功能放行，ECS 安全组不会自动作用于挂载在 ECS 上的云数据库。
- 路由风险：100.104 网段是阿里云服务网段、也是 DTS 与数据库默认交互网段，勿将该网段从 VPC 路由到 VPN/高速通道/VPCPeer/CEN 等其他位置，否则连接中断。
- 任务结束或释放后建议移除 DTS IP 段。

## 公网 NAT 网关中转方案（替代逐条加白名单）

| 项目 | 内容 |
|---|---|
| 适用 | 数据库具备公网地址，且不便逐条添加大量 DTS 服务 IP 段 |
| 前提 | 数据库需具备公网地址 |
| 配置流程 | 创建中转 VPC 及交换机 → 购买公网 NAT 网关 → 购买弹性公网 IP（EIP）→ 绑定 EIP → 配置 SNAT 条目 → 配置 EIP 报警 → 将 EIP 加入数据库白名单 → 创建 DTS 实例 |
| 费用 | 需购买公网 NAT 网关和弹性公网 IP，产生相关费用 |
| SLA | 受公网质量限制导致的实例不稳定不在 DTS SLA 保障范围内 |
| 关键注意 | 运行期间勿修改/删除中转 VPC、NAT 网关、EIP；EIP 亲和性开关须保持关闭；每个 EIP 的出/入方向限速丢包速率应保持 0，否则延迟或中断；SSL 加密连接的数据库可能无法经此方式接入 |
| 流量上限 | DTS 每线程一个连接、每连接经一个 EIP 访问数据库；EIP 带宽峰值（流量上限）需满足 DTS 实例需求，瓶颈时扩容带宽或增加 EIP 数量 |

## 地址族与其他网络限制

| 项目 | 官方口径 |
|---|---|
| IPv6 | DTS 不支持 IPv6 地址配置，源/目标库地址仅接受 IPv4；IPv6 环境需经公网 NAT 网关转换为 IPv4 后接入 |
| 跨地域/跨境迁移的地址要求 | 源库接入方式为云实例时源库需开通外网地址；否则目标库需开通外网地址 |
