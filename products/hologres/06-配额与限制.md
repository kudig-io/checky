# Hologres · 配额与限制

> 产品：Hologres ｜ 口径：公共云 ｜ 复核：2026-11-18

## 购买与付费约束（硬限制）

| 限制项 | 规则 |
|---|---|
| 每日购买实例数 | 一个阿里云主账号每天最多购买 3 个实例 |
| 计费方式 | 包年包月、按量付费两种；Hologres 支持两种计费方式之间互相转换 |
| 按量付费停机 | 控制台手动停机后计算资源停止收费，存储资源继续收费，直到实例删除才停止收费 |
| 包年包月存储超卖 | 存储超出购买额度的部分按量付费计费 |
| MaxCompute 内建函数 | Hologres 中不支持使用 MaxCompute 的内建函数 |
| UDF | 不支持 MaxCompute 创建的 UDF；不支持创建和使用 UDF（支持 PostgreSQL 内建函数） |
| 数据类型 | 仅支持 PostgreSQL 数据类型子集 |

**来源**：
- 约束和限制：https://help.aliyun.com/zh/hologres/support/limits ｜ 复核：2026-11-18

## 建议最大值配额（官方「使用建议」口径）

超过下列值可能导致性能降低、系统不稳定甚至服务中断；超出场景需联系官方支持。

| 配额项 | 默认/建议值 | 备注 |
|---|---|---|
| 单实例数据库个数 | 10 | — |
| 每天新购、变配实例总次数 | 10 | 升配或降配合计 |
| 单实例账号数（阿里云账号+RAM+自定义） | 256 | — |
| 单实例连接数 | 与规格相关 | 见 03-实例参数 |
| 单 Table Group 表数（含分区子表，不含外表） | 10,000 | 可用 `hologres.hg_table_properties` 查询 |
| 单表列数 | 列存/行列共存 ≤300；行存 ≤3000 | — |
| 单 Table Group 列数总和 | 1,000,000 | — |
| 表/列注释长度 | 1024 字符 | — |
| 单值最大数据量（TEXT 等） | 4 MB | — |

## 结构与操作限制

| 限制项 | 规则 |
|---|---|
| 最大连接数 | 不可修改，随规格扩缩容自动调整 |
| 默认 Shard 数 | 扩缩容不改已有 DB 默认 Shard，需手动改；新建 DB 取对应规格默认值 |
| 冷热转换批量 | 一次性建议 ≤200 张表 |
| 行存冷存 | 不推荐行存表设为冷存储 |
| 冷存点查 | 冷存表每秒读取行数比热存低 2 个数量级，不推荐 Serving/维度表场景 |
| 跨库查询版本 | 仅相同大版本实例互通；仅内部表、仅分区父表；不支持外表 UPDATE/DELETE/TRUNCATE |
| HoloStudio | 逐步下线迭代为 DataWorks DataStudio；调度默认公共资源组，独享资源组需申请 |
