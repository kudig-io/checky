# Hologres · 网络参数

> 产品：Hologres ｜ 口径：公共云 ｜ 复核：2026-11-16

## 四种网络类型与域名格式

端口统一为 **80**（PostgreSQL Wire 协议端口，VPC 与公网均使用此端口）。

| 网络类型 | 域名格式 | 说明/带宽 | 默认状态 |
|---|---|---|---|
| 公网 | `<instanceID>-cn-<region>.hologres.aliyuncs.com:80` | 有流量开销，但目前 Hologres 暂不针对流量收费；支持带宽 200 Mbps | 默认关闭，可手动开启/关闭 |
| 经典 | `<instanceID>-cn-<region>-internal.hologres.aliyuncs.com:80` | 阿里云公共基础网络；支持带宽 20 Gbps | 系统默认只能开启该网络类型 |
| 指定 VPC | `<instanceID>-cn-<region>-vpc-st.hologres.aliyuncs.com:80` | 仅与绑定的 VPC 联通；支持带宽 20 Gbps；VPC 连接场景推荐 | 默认绑定创建实例时选择的 VPC，可改绑/解绑 |
| VPC | `<instanceID>-cn-<region>-vpc.hologres.aliyuncs.com:80` | 支持带宽 20 Gbps；不支持跨 Region 连接；该类型逐步下线 | 可开启/关闭；关闭后无法再开启 |

- 获取实例 IP：复制 Endpoint 去掉末尾 `:80` 后 `ping`，DNS 解析地址即该网络类型下的实例 IP。

## 公网访问

| 项目 | 规则 |
|---|---|
| 适用场景 | 阿里云以外设备访问实例；访问位于不同地域/网络类型的实例 |
| 带宽 | 200 Mbps |
| 流量计费 | 公网有流量开销，但目前 Hologres 暂不针对流量收费（⚠️ 属「目前」口径，可能变化） |
| 关闭风险 | 关闭公网会导致所有使用公网连接的应用断链，关闭前须确认无应用使用 |
| 特殊限制 | 聚石塔和物流云受安全监管要求，不透出公网 Endpoint |

**来源**：
- 实例配置（网络配置）：https://help.aliyun.com/zh/hologres/user-guide/instance-configurations ｜ 复核：2026-11-16

## VPC 连通规则

| 项目 | 规则 |
|---|---|
| 指定 VPC 隔离 | 仅与绑定的 VPC 联通；与其他 VPC 打通需走 VPC 互连（VPN 网关/高速通道/云企业网/智能接入网关等） |
| 同 VPC 访问 | 只要 VPC 相同，VPC 内任意可用区的 Flink、ECS 等均可通过指定 VPC Endpoint 访问 |
| DNS 生效 | 绑定 VPC 后通常需等 30 秒待 DNS 更新才能获取 IP |
| IP 占用 | 绑定指定 VPC 占用 2~3 个 VPC IP（Hologres V1.3 占 3 个，V2.0 占 2 个），须确保交换机有足够可用 IP |
| VPC Endpoint 变更 | 2022 年 12 月 26 日起新购实例（含备份恢复的新实例）不再提供 VPC Endpoint，改用指定 VPC Endpoint；已有实例不受影响，官方建议关闭原 VPC Endpoint |
| 关闭 VPC 影响 | 关闭后如需用 HoloWeb 须绑定指定 VPC；用 DataWorks 对接须改用独享资源组 |

**来源**：
- 实例配置（绑定指定 VPC 网络、注意事项）：https://help.aliyun.com/zh/hologres/user-guide/instance-configurations ｜ 复核：2026-11-16

## 连接参数速查

| 参数 | 取值 |
|---|---|
| 端口 | 80（默认，PG 协议） |
| 默认数据库 | 开通实例后系统自动创建 `postgres` 数据库（分配资源较少，正式业务建议新建库） |
| 认证 | 数据库账号（阿里云账号 AccessKey / 自定义账号 BASIC$xxx）或 RAM 用户 AccessKey |
| 连接串示例 | `psql -h <instanceID>-cn-<region>-vpc-st.hologres.aliyuncs.com -p 80 -d <db>`；计算组型可追加 `@warehouse_name` |
| 白名单 | Hologres 支持 IP 白名单访问控制；但跨库查询场景因实例 IP 不固定，暂不建议配置 IP 白名单 |
