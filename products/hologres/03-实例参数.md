## 单实例最大连接数与默认 Shard 数

- 最大连接数由规格决定，**不可修改**；系统扩缩容时同步调整。
- 总连接数 = 单 Frontend 接入节点最大连接数 × Frontend 节点数；`show max_connections;` 返回单节点值。
- Shard 数可通过创建新的 Table Group 调整；扩缩容不改变已有 DB 默认 Shard，新建 DB 用对应规格默认值。

## QPS 与并发查询口径

| 口径 | 数值/规则 |
|---|---|
| 在线点查 QPS | 官方宣称行存主键索引 + 短路径优化支持「每秒数十万 QPS」高性能点查、前缀扫描 |
| 高并发场景选型门槛 | 官方将「1000 QPS 以上」毫秒级响应列为计算组型实例适用场景 |

## Serverless Computing 资源 Quota（实例级）

| 实例计算资源（CU） | Serverless Computing Quota |
|---|---|
| <32 | 不支持使用 Serverless Computing |
| 32 ≤ 实例计算资源 < 688 | 实例计算资源的 3 倍（例：32 CU → 96 CU）；V3.0.33 起调为 5 倍、上限 2048 CU（V3.1.9 起上限 4096 CU）；V4.0.13 起调为 10 倍、上限 4096 CU |
| ≥688 | 最高 2048 CU；V3.1.9 起最高 4096 CU |

- Quota = 每实例处于 EXECUTE 状态的所有 SQL 占用的 Serverless 资源上限。
- 超过 Quota 或可用区资源池已满时，SQL 进入 QUEUE 排队；默认超限后 SQL 自动回落到实例预留资源执行。
- Serverless Computing 属后付费按量计费，不承诺可分配到计算资源。

## Shard 调整规则

| 规则 | 说明 |
|---|---|
| 何时扩大 Shard | 需要更大写入吞吐时；点查可命中 Shard 剪枝时 Shard 越多并发越强 |
| 何时不建议调 | OLAP 查询增大 Shard 无明显收益、甚至降低并发；规格扩容小于 5 倍时不建议调整 |
| Local Join | 同一 Table Group 内同 Shard 关联效率最高；跨 Shard 需 Redistribution（Shuffle）开销 |
| 行存特性 | 行存表 Shard 越多读取性能越高 |
