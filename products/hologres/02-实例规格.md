> 产品：Hologres ｜ 口径：公共云 ｜ 复核：2026-11-16

## 实例类型对比

| 实例类型 | 资源类型 | 核心诉求 | 适用业务场景 |
|---|---|---|---|
| 计算组型实例（官方推荐） | 独享计算资源和存储资源 | 高性能、高并发与大规模数据处理；单独实例可实现读写分离架构 | TB 级以上或 PB 级数据、复杂查询频繁；高并发在线服务毫秒级响应（1000 QPS 以上）；混合负载隔离；流量波动显著需快速扩缩容 |
| Serverless 型实例 | 共享计算资源，独享存储资源 | 高性能、大规模、低频次的数据加工与查询 | 开发/测试环境；低频次高性能查询；负载波动明显难预测波峰 |
| 通用型实例 | 独享计算资源和存储资源 | 成本控制与轻量级分析；可升级为计算组型实例 | TB 级以下数据量；低频次临时查询、中小规模 BI 报表；成本敏感/非核心业务试水；低并发服务、定时任务 |
| 只读从实例（即将下线） | 独享计算资源和存储资源 | 多实例读写分离，须绑定通用型实例 | 主实例写入加工 + 只读从实例分析；官方建议改用计算组型 |
| 共享集群（即将下线） | 共享计算资源，无存储资源 | 低成本加速湖仓查询与 BI 集成，无内表读写需求 | 数据在 OSS/MaxCompute 的加速查询；突发大查询；对接 Tableau/Quick BI/帆软 |

## 计算规格档位（CU）

| 实例类型 | 可购计算资源 | 步长/门槛 |
|---|---|---|
| 通用型 | 支持 512 CU 至 1024 CU 之间的计算资源规格（2022-04-25 起）；更高规格需提交工单，且升级前实例须为 V1.1.58 及以上版本 | — |
| 计算组型 | 无需提交工单，可购 32 CU 至 8192 CU 任意规格；单个计算组预留计算资源 32~8192 CU，步长 16 CU | 单计算组最少 32 CU |
| 计算组型 Gateway | Gateway 节点最少 2 个（默认 2，保障高可用），后续可调整 | Gateway 按个计费 |
| Serverless 型 | 按 Serverless 资源实际用量付费，无需预购计算资源 | — |

- 1 CU = 1 core 4 GB（计算节点与 Frontend 节点都计入规格，每 16 CU 对应一个计算节点）。

## 选型速查：数据量 → 规格 → Shard 数

| 数据总规模 | 推荐规格 | 推荐 Shard 数 | 使用说明 |
|---|---|---|---|
| 4000 万行以下 | 32 Core 以上 | 10～20 | 不适合压力测试，建议用于开发环境 |
| 4000 万行～4 亿行 | 64 Core 以上 | 20～40 | 适合业务场景较为单一、无混合负载 |
| 4 亿行～40 亿行 | 128 Core 以上 | 40～80 | 写入查询均衡，建议生产系统默认起步配置 |
| 40 亿行～400 亿行 | 256 Core 以上 | 80～240 | 建议按业务属性/数据量划分多个 Table Group |
| 400 亿行～4000 亿行 | 512 Core 以上 | 160～400 | 多 Table Group；仅对超大表划多 Shard，普通表不建议 Shard 过多 |

- 官方说明：该推荐不是唯一标准；扩容小于 5 倍时，不建议调整 Shard。

## 通用型转计算组型

| 限制项 | 规则 |
|---|---|
| 版本要求 | 仅 Hologres V2.0.40 及以上版本的通用型实例支持转换 |
| 规格要求 | 8 Core 的通用型实例不支持转换（需先变更实例规格） |
| 方向限制 | 不支持将计算组型实例转换回通用型；不支持只读从实例单独转换 |
| 从实例 | 支持主从实例一起转换 |
