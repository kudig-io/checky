# 实时数仓 Hologres（hologres）

一站式实时数仓引擎：MPP + 行列混存 + 存算分离，兼容 PostgreSQL 协议，一份数据同时支撑 OLAP 分析、Ad Hoc 与高并发点查（Serving）。公共云口径。
