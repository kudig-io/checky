## 存储计费单位与类型

| 项目 | 规则 |
|---|---|
| 存储量定义 | 用户在 Hologres 中存储的数据量（不考虑数据副本），含业务数据、元数据等，以账单为准 |
| 计费单位 | GB；包年包月按 GB·月，按量付费按 GB·小时，每小时结算一次 |
| 存储类型 | 标准存储（热存，全 SSD，默认）/ 低频访问存储（冷存，全 HDD） |
| 冗余类型 | 本地冗余存储（单可用区）/ 同城冗余存储（3AZ 多可用区，仅北京/深圳/上海/杭州支持） |
| 与规格关系 | 计算和存储分离，存储资源与实例规格不相关，可独立升降 |

## 冷热分层（数据分层存储）

| 项目 | 规则 |
|---|---|
| 支持版本 | Hologres V1.3.37 及以上；主从实例建议升到 V1.3.55 及以上开启冷存 |
| 热存 | 标准存储 = 全 SSD，默认存储 |
| 冷存 | 低频访问存储 = 全 HDD；不推荐支撑点查（Flink 维度表、Serving），每秒读取行数比热存低 2 个数量级 |
| SSD 缓存加速 | V2.1 起支持，默认开启，预计访问性能提高一倍以上（仅默认分配缓存空间） |
| 表级设置 | `SET_TABLE_PROPERTY` 的 `storage_mode` = hot/cold；分区子表默认继承父表，可单独设置 |
| 搬迁时机 | 后台异步搬迁，默认当天 0 点执行；V2.2 起支持自定义搬迁时间 |
| Meta 位置 | 表的 Meta 只能存热存储，冷表也会产生少量热存储费用 |
| 新写入数据 | 先写热存，后台异步搬冷，产生一定热存储费用 |
| 批量转换限制 | 建议一次性转换表数 ≤200 张（会打开所有表 tablet，内存占用增加） |
| 不推荐 | 行存表不建议设为冷存储 |
| 低版本配额 | 低版本包年包月实例升到 V1.3.37 后，低频访问存储配额默认 0 GB |
| 状态查询 | `hg_table_storage_status(schema, table)` 返回 hot/cold/transferring 与 Byte 级大小 |

## 跨库查询（Beta）

| 项目 | 规则 |
|---|---|
| 起始版本 | Hologres V1.1 及以上；原理同 PostgreSQL FDW（`CREATE EXTENSION hologres_fdw`） |
| 跨越范围 | 不同地域、不同实例、不同数据库之间通过外部表查询 |
| 版本约束 | 仅支持相同大版本的实例互相跨库查询（如不支持 V1.3 查 V1.1） |
| 数据范围 | 仅内部表；不支持外部表和 View；仅分区父表，不支持分区子表 |
| 类型限制 | 仅 INT、BIGINT、DATE 等基本类型，JSON 等复杂类型不支持 |
| 写限制 | 不支持对外表执行 UPDATE、DELETE、TRUNCATE |
| 白名单 | Hologres 实例 IP 不固定，使用跨库查询时暂不建议配置 IP 白名单 |

**来源**：
- 跨库查询（Beta）：https://help.aliyun.com/zh/hologres/user-guide/query-data-across-databases/ ｜ 复核：2026-11-16

## 与 MaxCompute 外表直读

| 项目 | 规则 |
|---|---|
| 地域要求 | Hologres 与 MaxCompute 必须同一地域（跨地域查询稳定性无法保障） |
| 加速方式 | CREATE EXTERNAL DATABASE（整库映射）/ IMPORT FOREIGN SCHEMA（批量）/ CREATE FOREIGN TABLE（单表） |
| 直读 2.0 | V3.1 起直读升级为 2.0（MaxCompute C++ Native SDK），直读盘古存储：MaxCompute 侧无额外计算开销、无限流，读取性能 2 倍以上优势 |
| 限制取消 | V3.0 起取消「单次查询扫描 ≤200 GB、分区数 ≤512」限制（约束和限制页口径为 V3.0.20 及以上取消，⚠️ 两页版本号口径存在差异） |
| 查询上限（旧版本） | 单次查询最大底层数据扫描 200 GB；分区表单次最多扫描 512 个分区 |
| 存储类型限制 | 仅支持读取 MaxCompute 标准存储，不支持低频/长期存储数据 |
| 表范围限制 | 只能加速 MaxCompute 内部表，不能查外部表和 VIEW；不支持 Map、Struct 类型 |
| 性能口径 | 相比原生 MaxCompute 访问加速 5-10 倍；两系统间百万行每秒同步 |
| 写回 | 支持 INSERT INTO / INSERT OVERWRITE 导出至 MaxCompute（归档、冷热分层、离线回补） |
