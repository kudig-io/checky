# Hologres · 计费与生命周期

> 产品：Hologres ｜ 口径：公共云 ｜ 复核：2026-11-16

## 计费方式与计费项

| 项目 | 规则 |
|---|---|
| 付费模式 | 包年包月（预付费）、按量付费（后付费） |
| 计费单位 | 计算：CU（1CU=1 core 4GB），Serverless/弹性资源按 CU·小时；存储：GB；网络：跨地域快照复制流量 GB |
| 按量结算周期 | 每 1 小时结算一次；实例即使没有任务运行，计算资源也每小时计费一次 |
| 高级功能计费 | Serverless Computing、备份恢复、跨区域复制快照等产生的资源用量均为按量付费 |
| 备份/跨区复制 | 计费规则表标注「无」（无包年包月预付费定价）；价格表给出按量单价：备份快照 0.00030 元 GB·小时、跨区域复制快照网络传输 0.5 元/GB（内地部分地域） |

### 包年包月 vs 按量付费计费项

| 计费项 | 包年包月 | 按量付费 |
|---|---|---|
| 计算资源 / Gateway / 计算组预留 | 预付费（购买时收规格+时长费用） | 购买后立即计费，每小时结算；停机可停止计费 |
| 计算组弹性资源 | 后付费，按资源量和时长 | 同左 |
| Serverless Computing | 后付费（无单独包年包月价格） | 后付费，按 CU·小时 |
| 标准存储 / 低频访问存储 | 预付费；超出购买规格部分按量计费 | 有数据即开始计费，每小时结算；删数据后停费 |
| 备份快照 / 跨区域复制 | 停止周期性备份并删除备份即停费 | 同左 |

## 到期/欠费停服与释放规则

### 包年包月

| 阶段 | 规则 |
|---|---|
| 到期预警 | 停机前 7 天、3 天、1 天短信/邮件提醒 |
| 到期后 | 立刻停止服务，不能访问；重新购买包年包月立即恢复 |
| 到期第 1~15 天 | 实例锁定状态，无法被访问，期间不推送账单 |
| 释放预警 | 释放前 7 天、3 天、1 天提醒 |
| 到期第 16 天 | 实例释放，管控台删除，数据不保留、不可恢复 |
| 账号欠费 | 欠费时实例正常运行；停服前 18 小时、12 小时、6 小时提醒；未启用延期免停则欠费后停机 |

### 按量付费

| 阶段 | 规则 |
|---|---|
| 欠费 24 小时内 | 实例正常运行 |
| 停服后第 1~15 天 | 锁定状态，无法访问，不推送账单 |
| 停服后第 16 天 | 实例释放，数据不保留、不可恢复 |
| 延期免停 | 阿里云提供延停权益，额度/时长按历史消费按月自动计算；延停期间正常计费 |

### 通用规则

- Hologres 服务暂停后，当前账号所有 Hologres 实例保留 15 天后释放；15 天内充值补足欠费服务自动开启，超 15 天视为放弃数据、实例自动释放。
- 手动停机（按量付费）：计算资源停止收费，存储资源继续收费，直到实例删除。

## Serverless Computing 计费要点

| 项目 | 规则 |
|---|---|
| 计费方式 | 后付费，按使用资源量和时长（CU·小时）计费；无单独包年包月价格 |
| 用量统计 | 按当前 DB 默认时区的自然日统计已用资源量（CU*H） |
| 超限回落 | 达到实例/用户/DB 的 Serverless 日累计用量限制后，SQL 默认自动转由实例预留资源执行；可设 `hg_serverless_computing_enable_fallback_when_exceed_cuh_threshold=false` 改为直接报错 |
| 不承诺 | Serverless Computing 属后付费资源，不承诺可分配到计算资源；超 Quota 或资源池满时 SQL 排队（QUEUE） |
