## ALB 通用配额（默认→最大支持提升至）

| 配额名称 | 描述 | 默认 | 最大 | 可申请 |
|---|---|---|---|---|
| alb_quota_loadbalancers_num | 每地域 ALB 实例数 | 60 | 150 | 是 |
| alb_quota_loadbalancer_certificates_num_basic_edition | 基础版实例扩展证书数（不计默认证书） | 10 | 150 | 是 |
| alb_quota_loadbalancer_rules_num_basic_edition | 基础版实例转发规则数（不计默认规则） | 40 | 100 | 是 |
| alb_quota_loadbalancer_servers_num_basic_edition | 基础版实例后端服务器数 | 200 | 400 | 是 |
| alb_quota_loadbalancer_listeners_num_basic_edition | 基础版实例监听数 | 50 | 80 | 是 |
| alb_quota_loadbalancer_certificates_num_standard_edition | 标准版实例扩展证书数 | 25 | 300 | 是 |
| alb_quota_loadbalancer_rules_num_standard_edition | 标准版实例转发规则数 | 100 | 200 | 是 |
| alb_quota_loadbalancer_servers_num_standard_edition | 标准版实例后端服务器数 | 1000 | 1500 | 是 |
| alb_quota_loadbalancer_listeners_num_standard_edition | 标准版实例监听数 | 50 | 100 | 是 |
| alb_quota_loadbalancer_*_standardwithwaf_edition | WAF 增强版：证书 25→300、规则 100→200、后端 1000→1500、监听 50→100 | 同标准版 | 同标准版 | 是 |
| alb_quota_max_request_timeout | 创建监听时连接请求最大超时时间 | 600 秒 | 3600 秒 | 是 |
| alb_quota_max_idle_timeout | 创建监听时连接空闲最大超时时间 | 600 秒 | 3600 秒 | 是 |

- 配额叠加规则：同一资源被多次关联时计算会叠加（如同一后端挂到同实例多个监听/规则，按多次计）。
- ALB 健康检查模板、自定义安全策略等地域级配额见「硬限制」表。

## NLB 默认配额

| 配额名称 | 描述 | 默认值 | 可申请提升 |
|---|---|---|---|
| nlb_quota_loadbalancers_num | 每地域 NLB 实例数 | 60 个 | 是 |
| nlb_quota_loadbalancer_eci_servers_num | 每实例后端可挂载服务器数（ECI 类型） | 1600 个 | 否 |
| nlb_quota_loadbalancer_noeci_servers_num | 每实例后端可挂载服务器数（ECS/ENI/IP 类型） | 400 个 | 是 |
| nlb_quota_loadbalancer_listeners_num | 每实例监听数 | 50 个 | 是 |
| nlb_quota_loadbalancer_certificates_num | 每实例扩展证书数（不计默认证书） | 25 个 | 是 |
| nlb_quota_servergroups_num | 每地域服务器组数 | 3000 个 | 否 |
| nlb_quota_servergroup_eci_servers_num | 每服务器组服务器数（ECI 类型） | 1600 个 | 否 |
| nlb_quota_servergroup_noeci_servers_num | 每服务器组服务器数（ECS/ENI/IP 类型） | 400 个 | 是 |
| nlb_quota_server_added_num | 同一后端（含 IP 类型）可被添加到服务器组的次数 | 200 次 | 是 |
| nlb_quota_servergroup_attached_num | 每服务器组可关联监听的次数 | 50 个 | 是 |
| nlb_quota_securitypolicies_num | 每地域自定义安全策略数 | 50 个 | 否 |

- 权益配额（默认 0，需授权）：`nlb.white_list/ip_target_cidr_not_limited`（IP 类型服务器组不限制网段）、`nlb.white_list/single_zone_for_uid`（支持单可用区）。
- 安全组：一个 NLB 实例最多可加入的安全组数 = ECS 安全组配额 − 1；最多可关联安全组规则数 = ECS 安全组规则配额 − NLB 托管安全组规则数。
- 其他限制：NLB VIP 可用性探测走 ICMP，云墙/网络 ACL 需放行；禁用客户端地址保持时每可用区与单一后端组合最多 60,000 条并发（扩到 8 个 Local IP 后 250,000 条）。
