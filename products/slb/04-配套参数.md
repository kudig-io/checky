## 健康检查参数（ALB）

| 参数 | 取值范围 | 默认值 |
|---|---|---|
| 健康检查协议 | HTTP、HTTPS、TCP、gRPC（扩展版仅 HTTP、TCP；HTTPS 协议标准版/WAF 增强版支持，基础版不支持） | — |
| 健康检查方法 | HEAD（HTTP/HTTPS 默认）、POST（gRPC 默认）、GET | HEAD / POST |
| 探测端口 | 1~65535，仅一个端口号 | 空 = 使用后端服务器端口 |
| 探测路径 | 如 `/health` | `/`（根路径） |
| 健康状态返回码（HTTP/HTTPS） | http_2xx、http_3xx、http_4xx、http_5xx | http_2xx + http_3xx |
| 健康状态返回码（gRPC） | 0~99，最多 20 个范围值，逗号分隔 | — |
| 响应超时时间 | 1~300 秒 | 5 秒 |
| 检查间隔时间 | 1~50 秒 | 2 秒 |
| 健康阈值（连续成功） | 2~10 次 | 3 次 |
| 不健康阈值（连续失败） | 2~10 次 | 3 次 |

- 服务器组默认开启健康检查；健康检查为短连接，不产生额外费用。
- 权重为 0 的后端不参与健康检查；组内全部不健康时仍按调度算法尝试转发。
- ALB 升级实例用交换机网段 Local IP 与后端通信；升级前实例用 100.64.0.0/10，后端安全组/ACL 需放行。
- GET 响应报文超过 8 KB 会被截断，不影响判定。
- 一个地域最多 50 个健康检查模板，不可提升。

## 健康检查参数（CLB、NLB）

| 参数 | CLB | NLB |
|---|---|---|
| 健康检查协议 | TCP 监听：TCP/HTTP；UDP 监听：TCP/UDP/HTTP；HTTP/HTTPS 监听：仅 HTTP | TCP/HTTP（默认 TCP）；后端协议为 UDP 时可选 UDP |
| 健康检查方法（仅 HTTP） | HEAD、GET（默认 HEAD） | GET（默认）、HEAD |
| 健康检查协议版本 | — | HTTP1.0（默认）、HTTP1.1（仅 HTTP 检查生效） |
| 探测端口 | 1~65535；不设置则用后端服务器端口 | 0~65535，默认 0（使用后端服务器端口） |
| 探测路径/域名（仅 HTTP） | 路径默认根路径；可配域名写入 Host 头（不配则不带 Host） | 路径可配（1~80 字符，以 / 开头）；域名默认后端内网 IP，可指定 1~80 字符域名 |
| 健康状态返回码（仅 HTTP） | http_2xx、http_3xx、http_4xx、http_5xx（控制台默认 http_2xx+http_3xx） | http_2xx（默认）、http_3xx、http_4xx、http_5xx |
| 响应超时时间 | 1~300 秒（TCP 监听 API 显式默认 5 秒） | 1~300 秒，默认 5 秒 |
| 检查间隔时间 | 1~50 秒 | TCP/HTTP：1~50 秒（默认 5 秒）；UDP：1~300 秒（默认 5 秒，须 ≥ 响应超时） |
| 健康阈值（连续成功） | 2~10 次 | 2~10 次，默认 2 次 |
| 不健康阈值（连续失败） | 2~10 次 | 2~10 次，默认 2 次 |

- 探测源地址：CLB 用 100.64.0.0/10 段，NLB 用其 Local IP，后端 iptables/安全策略需放行。
- UDP 检查支持自定义请求/返回结果（NLB 请求串最大 512 字符），按预期响应判定成败。
- CLB 健康检查默认开启、可关闭；NLB 默认开启（HealthCheckEnabled 默认 true），全部后端异常时尽力转发。

|---|---|---|---|

| 每实例扩展证书（不计默认证书） | 基础版 10→150；标准版/WAF 25→300 | 25 个→可提升 | 每监听扩展域名默认 3 个→最大 10 个 |

| 每地域可上传客户端 CA 证书 | — | — | 100 个（slb_quota_ca_certs_num） |

## 会话保持

| 项目 | ALB | CLB | NLB |
|---|---|---|---|
| 配置位置 | 服务器组维度 | 监听维度 | 服务器组维度（客户端地址保持） |
| 方式 | 植入 Cookie（插入 SERVERID、SERVERCORSID，自带 SameSite=None）；重写 Cookie（自定义 Cookie 名） | 七层 HTTP/HTTPS：Cookie 植入（insert）/重写（server）；四层 TCP/UDP：按源 IP 会话保持 | 客户端地址保持（源 IP），服务器组开关 PreserveClientIpEnabled，默认开启；关闭时靠源 IP/四元组/QUIC ID 哈希调度保持同流同后端 |
| 超时时间 | 植入 Cookie 时输入会话保持超时时间：1~86400 秒，默认 1000 秒；官方建议短连接场景 60~300 秒 | 四层 PersistenceTimeout 0~3600 秒，默认 0（即关闭）；七层 CookieTimeout 1~86400 秒（API 示例 500 秒） | 无超时参数（开关式，无 Cookie/超时配置） |
| 限制 | ALB 扩展版不支持会话保持；函数计算类型服务器组无需配置；关闭跨 AZ 负载均衡的服务器组不支持开启会话保持 | — | 开启客户端地址保持的 TCP 服务器组不支持关联 TCPSSL 监听；关闭后可让后端作为客户端访问 NLB（配 Proxy Protocol 取源地址）；禁用客户端地址保持时，每可用区 NLB 与单一后端（IP）组合最多 60,000 条并发，扩至 8 个 Local IP 后最多 250,000 条 |
