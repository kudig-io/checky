## 公网实例与私网实例

| 项目 | ALB | NLB | CLB |
|---|---|---|---|
| 网络类型 | 公网 / 私网 | 公网 / 私网 | 公网 / 私网 |
| 公网能力提供 | EIP（一个公网 ALB 可有多个 EIP，至少 2 个分布不同可用区） | EIP（一个公网 NLB 可有多个 EIP，至少 2 个分布不同可用区） | 固定公网 IP / 可绑定 EIP |
| 私网是否收公网费 | 不收（仅公网实例收公网网络费） | 不收 | 不收公网 IP 保有费、流量费、带宽费 |
| VIP | VPC 内私网 IP | VPC 内私网 IP | 私网 IP |
| 域名 | 平台域名 + CNAME（2024-11-15 起新建实例不允许直接用平台默认域名访问） | 同左 | 实例服务地址 |

## 带宽上限

| 项目 | 数值/规则 |
|---|---|
| ALB 双可用区实例默认公网带宽 | 400 Mbps，实际以单实例下 EIP 带宽总和为准 |
| ALB 单账号单地域按使用流量 EIP 业务带宽峰值总和 | ≤ 5 Gbps；更大需购买共享带宽 |
| ALB 单 VIP 最大私网带宽（升级后） | 25 Gbps；多可用区 = 可用区数 × 单 VIP |
| NLB 单 VIP 内网吞吐量（入向+出向） | 50 Gbps；多可用区 = 可用区数 × 单 VIP |
| CLB 按流量公网实例：单账号单地域峰值总和 | ≤ 5 Gbps（带宽峰值非承诺指标，争抢时受限） |
| CLB 按固定带宽公网实例：单账号单地域峰值总和 | ≤ 50 Gbps（带宽峰值为承诺指标） |
| CLB 出/入带宽 | 固定带宽下出、入独立计算，各不超过设定值 |
| CLB 满速压测 | 分布式架构，客户端数量至少 5 台以上 |
| CLB 单连接下载峰值 | 设置的总带宽 ÷ (N−1)，N 为集群子节点数（四层 4、七层 8） |
| NLB 公网性能 | 公网部分性能参考 EIP 的性能限制 |

- CLB 按流量计费实例的带宽峰值各地域不同，以控制台实例详情页为准；按固定带宽实例可购最大带宽各地域不同，以购买页为准。
- ALB/NLB 采用分布式集群架构，单条连接吞吐受单台数据面节点限制，大流量长连接业务应拆分为多条并发连接。

## 共享带宽

- NLB：仅公网 NLB 需要共享带宽；共享带宽提供地域级带宽共享复用，以及按带宽计费和按增强型 95 计费等模式，公网 NLB 用共享带宽提供增强型 95 与按带宽计费能力。
- ALB：官方建议公网带宽超出 EIP 按流量 5 Gbps 账号限额时购买共享带宽。
- CLB：本次复核的计费页中公网计费项为流量费/带宽费，未见共享带宽计费项；私网 CLB 绑定独立购买的 EIP 时，EIP 公网费用在 EIP 侧计费。
- 共享带宽的带宽档位、单价与增强型 95 规则 ⚠️ 待核（属共享带宽产品文档，本次未复核）。
