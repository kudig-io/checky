|---|---|---|
| 存储 | 存储费用（按存储时长 × 容量） | 是 |

## 存储计费

- 按实际使用量付费；存储费用按小时计量、按小时单价结算。
- 小时账单在计费周期结束后约 3~4 小时生成。
- 单个计费周期内某计费项金额不足 0.01 元时不单独出账，持续累加至 0.01 元后统一出账。
- 单价换算示例：标准型（本地冗余）0.12 元/GB/月 ≈ 0.000167 元/GB/小时（0.12÷30÷24）。
- 最短存储时间不足时收「不足规定时长容量费用」：低频 30 天、归档 60 天、冷归档/深度冷归档 180 天。
- 最小计量：低频/归档/冷归档/深度冷归档按 64 KB 起计；标准存储按对象实际大小。
- 除手动删除、生命周期删除、欠费停服 15 天未补款外，数据默认永久保存。

## 请求计费

| 计费项 | Code | 规则 |
|---|---|---|
| Put 类请求 | PutRequest | 按 Put 类 API 成功请求次数；2xx/3xx 计费，4xx/5xx 不计费 |
| Get 类请求 | GetRequest | 按 Get 类 API 成功请求次数；同上状态码规则 |
| 冷归档取回请求 | CAStdRetrievalRequest / CAHighPriorRetrievalRequest / CABulkRetrievalRequest | 按解冻优先级三档，1 次解冻 = 1 次请求（与大小无关） |
| 深度冷归档取回请求 | DeepCAStdRetrievalRequest / DeepCAHighPriorRetrievalRequest | 两档，同上 |

- 分片上传：InitiateMultipartUpload、UploadPart（分片数 = PUT 请求数）、CompleteMultipartUpload、AbortMultipartUpload 均按成功次数计 Put 类请求费。
- ListObjects/ListObjectsV2、DeleteMultipleObjects 单次调用 = 1 次 Put 类请求（按 max-keys/Key 数量决定调用次数）。
- 生命周期 CommitTransition/ExpireObject 按命中对象个数计 Put 类请求费。
- CopyObject 按源存储类型计费；UploadPartCopy 按目标存储类型计费。

## 流量计费（内网 / 公网 / 上行下行）

| 计费项 | Code | 是否计费 |
|---|---|---|
| 外网流入流量（上传） | 不涉及 | 否 |
| 内网流入流量（上传） | 不涉及 | 否 |
| 内网流出流量（下载） | 不涉及 | 否 |
| 外网流出流量（下载/预览/图片处理） | NetworkOut | 是 = 流量（GB）× 每 GB 单价 |
| CDN 回源流出流量 | CdnOut | 是 = 回源流量（GB）× 每 GB 单价 |
| 跨区域复制流量 | ReplicationDatasize | 是 = 流量（GB）× 每 GB 单价；无资源包，仅按量 |

- 返回码 4xx、5xx 的请求不产生流量费用。
- 同地域 ECS 走内网 Endpoint：不产生外网流出流量费，仅请求费。
- 请求者付费模式开启后，外网流出/CDN 回源费由请求者承担；下行流量包、回源流量包不再生效。

## 资源包与预付费

| 方式 | 抵扣范围 | 关键规则 |
|---|---|---|
| 下行流量包 | 仅外网流出流量 | 12 种规格：100 GB~500 TB；可叠加、可续费、不可升级 |
| 回源流量包 | OSS 流出到 CDN 边缘节点流量 | 可叠加、不可升级和续费 |
| 存储包 | 对应存储类型 + 冗余类型（LRS/ZRS）的存储费 | 类型/冗余任一不匹配不抵扣；不可叠加，可升级 |
| SCU | OSS 等多云存储产品容量费 | 跨产品抵扣 |
| 预留空间 | 有地域属性 Bucket 标准 LRS 容量费 + ECS 快照费 | 先购后抵扣 |
| 传输加速包 | 传输加速费 | 可叠加、不可升级和续费 |

- 资源包抵扣为精准匹配机制：计费项类型、存储类型、冗余类型须与实际一致，否则按按量付费结算。
- Bucket 冗余类型转换（如 LRS→ZRS）后，原冗余类型资源包停止抵扣，需按新类型重购。
- 新用户首次开通可享免费试用额度（标准存储 LRS 容量、外网流出流量、请求次数）。

## 欠费停服规则

| 阶段 | 规则 |
|---|---|
| 欠费但在延停权益额度内 | 服务不停，延停期间正常计费；额度按历史消费等每月自动计算，不是欠费总额上限 |
| 超出延停额度 / 账号欠费 | 服务自动停止；控制台 Bucket 列表不可见；占用的 Bucket 资源停止继续扣费 |
| 停服后 15 天内补足欠款 | OSS 服务自动启用（欠费状态同步需时间） |
| 停服后 15 天内未补足欠款 | 视为主动放弃服务，全部数据被清理删除且不可恢复；与是否购买资源包、资源包是否在有效期无关；数据清理前不再继续计费 |
