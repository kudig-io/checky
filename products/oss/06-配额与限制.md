> 产品：对象存储 OSS ｜ 口径：公共云 ｜ 复核：2026-11-16

## Bucket（存储空间）配额

| 项 | 限制 | 备注 |
|---|---|---|
| 单账号单地域 Bucket 数 | ≤100 个 | 超出走配额中心申请 |
| 单 Bucket 容量 | 不限 | — |
| Bucket 名称 | 创建后不可修改；OSS 范围内全局唯一 | 3~63 字符，小写字母/数字/短划线，首尾为字母或数字 |
| Bucket 地域、存储类型 | 创建后不可修改 | 对象可由生命周期转存储类型 |
| 单 Bucket 对象数量 | ⚠️ 待核（官方使用限制页未给出数值） | — |

| 项 | 限制 |
|---|---|
| 简单/表单/追加上传单文件 | ≤5 GB |
| 分片上传单文件 | ≤48.8 TB |
| 控制台重命名 | ≤1 GB（更大用 SDK/ossutil） |
| 控制台一次删除 | ≤100 个 |
| SDK 一次删除 | ≤1,000 个 |
| ossutil/ossbrowser 一次删除 | 无限制 |
| 同名覆盖 | 默认覆盖；`x-oss-forbid-overwrite: true` 可禁止（版本控制开启/暂停时不生效） |

## 请求类默认配额与硬限制

| 项 | 数值 |
|---|---|
| 单账号总 QPS | 10,000（顺序读写 2,000；非顺序 10,000） |
| 单文件上传+下载总 QPS | 最高 2,000，峰值带宽 ≤10 Gbps |
| 账号带宽 | 见 05-网络参数（按地域 2~100 Gbps） |
| 流控标识 | Header `x-oss-qos-delay-time: <ms>` |
| 后台任务 | 生命周期/跨区域复制等不计入账户 QPS 与带宽流控；跨区域复制独立 QPS 限额 |

## 功能类配额

| 功能 | 配额/限制 |
|---|---|
| 生命周期规则 | 单 Bucket ≤1,000 条；重点地域 ≤10 亿对象操作通常 24 小时内完成，其他地域 ≤1 亿 |
| 回源规则 | 单 Bucket ≤20 条；镜像回源默认 QPS 2,000/2 Gbps（内地+香港）、1,000/1 Gbps（海外） |
| 域名绑定 | 单 Bucket ≤100 个域名；单域名仅绑 1 个 Bucket；账号总数无限制；内地域名需 ICP 备案 |
| 跨区域复制规则 | 单 Bucket 关联 ≤100 条 |
| 图片样式 | 单 Bucket ≤50 个 |
| 图片处理能力 | 杭州/上海/北京/张家口/深圳：20 MB/s、QPS 50；其他地域：2 MB/s、QPS 5 |
| 图片限制 | 原图 ≤20 MB；原图宽或高 ≤30,000 px（旋转 4,096 px）、总像素 ≤2.5 亿；缩放后宽高 ≤16,384 px、总像素 ≤16,777,216 |
| 分片上传 | 分片 1~10,000 个；单片 100 KB~5 GB；ListParts 单次 ≤1,000；ListMultipartUploads 单次 ≤1,000 |
| 列举/批量删除单次 | ListObjects max-keys 最大 1,000（默认 100）；DeleteMultipleObjects 单次 Key 最大 1,000 |
| 解冻配额 | 冷归档：500 个/秒、合计 100~120 TB/天；深度冷归档：100 个/秒、合计 10~15 TB/天 |
| Bucket Policy 条数上限 | ⚠️ 待核（本次未抓取 Bucket Policy 文档） |

## 资源包相关限制

- 地域资源包仅归属地域可用；中国内地通用资源包不含中国香港和海外地域。
- 已购资源包不支持更换地域。
- 存储包不支持叠加购买（支持升级）；传输加速包/回源流量包可叠加、不支持升级和续费；下行流量包/高防基础包可叠加和续费、不支持升级。
- 请求费用、数据处理费用、跨区域复制流量费用无资源包，仅按量计费。
- 资源包不抵扣无地域属性 Bucket 的下行流量。
