# OSS · 配套参数（数据保护与生命周期）

> 产品：对象存储 OSS ｜ 口径：公共云 ｜ 复核：2026-11-16

## 跨区域复制（CRR）

| 参数/限制 | 数值或规则 |
|---|---|
| 复制语义 | 自动、异步（近实时）复制创建/更新/删除；目标为精确副本 |
| 单 Bucket 关联复制规则上限 | 100 条（可同时作源和目标；更多需工单申请） |
| 版本控制前置 | 源/目标版本控制状态必须一致且不为暂停；复制期间不允许变更 |
| 内地 ↔ 非内地 | 必须开启传输加速 |
| 无地域属性 Bucket | 仅支持与中国内地各地域 Bucket 配置 CRR；无地域属性 Bucket 之间只能用 CRR |
| 不可复制对象 | 源端冷归档/深度冷归档对象（无论是否已解冻）；Appendable 对象复制到冷归档/深度冷归档目标 |
| RTC（数据复制时间控制） | 开启后几秒内复制大多数对象，10 分钟内复制 99.99% 的对象；RTC 单独计费 |
| 复制耗时 | 异步（近实时），通常几分钟到几小时，取决于数据量 |
| 一致性 | 默认保证两端最终一致性；复制期间向目标写同名文件则不保证 |
| 关闭风险 | 状态为「关闭中」时对源 Bucket 的操作（含删除）是否同步具有不确定性，须确认状态变为「未开启」后再删数据 |

费用：跨区域复制流量费（ReplicationDatasize，按量、无资源包）+ 每成功复制 1 个对象的请求费 + 可选 RTC 费 + 可选传输加速费（由目标 Bucket 账号承担）；低频/归档复制不收解冻取回费。

## 版本控制

| 状态 | 覆盖 Object | 删除 Object |
|---|---|---|
| 未开启（默认） | 直接覆盖且无法恢复 | 直接删除，无法再获取 |
| 开启 | 生成新版本，历史版本不受影响 | 生成删除标记，历史版本不受影响，可恢复 |
| 暂停 | 生成新版本（相同暂停期版本则覆盖），其他历史版本保留 | 生成删除标记（相同暂停期标记则覆盖），其他历史版本保留 |

- 开启后**无法返回「未开启」**，只能暂停；暂停后新对象 versionId 为 null，历史版本继续保留。
- 已开启保留策略（WORM）的 Bucket 禁止从「开启」转「暂停」；「暂停」转「开启」允许。
- 版本控制功能本身不收费，但当前版本 + 所有历史版本都收存储费用；下载/恢复历史版本另产生请求费、流量费。
- 版本控制开启或暂停时：禁止覆盖规则不生效，`x-oss-forbid-overwrite` 请求头不生效。
- 同一 Bucket 禁止同时开通 OSS-HDFS 服务和版本控制。
- OSS 当前不提供回收站；删除找回依赖版本控制。
- 开启版本控制的 Bucket 中，生命周期按 Object 的每个版本各记一次操作。

**来源**：
- 版本控制：https://help.aliyun.com/zh/oss/user-guide/overview-78/ ｜ 复核：2026-11-16

## 生命周期

| 参数/限制 | 数值或规则 |
|---|---|
| 单 Bucket 生命周期规则数 | 最多 1,000 条 |
| 执行完成时间（重点地域） | 杭州、上海、北京、张家口、乌兰察布、深圳、新加坡：Object 数 ≤10 亿的删除/转类型/碎片过期操作通常 24 小时内完成 |
| 执行完成时间（其他地域） | Object 数 ≤1 亿的操作通常 24 小时内完成 |
| 可能超时的情形 | 扫描对象过多、待执行对象过多、标签多、历史版本多、执行期间新上传对象多等，可能数天到数周 |
| 触发方式 | 基于最后一次修改时间 / 最后一次访问时间 |
| 典型动作 | 转换存储类型（CommitTransition）、删除对象（ExpireObject）、碎片过期 |

- 生命周期转类型/删除按命中对象个数产生 Put 类请求费；低频/归档/冷归档相关操作在中国大陆地域费用更高，深度冷归档删除不收费。
- 官方建议用生命周期清理过期碎片、历史版本、删除标记，控制存储费。

## 数据恢复（解冻/取回）

| 项 | 规则 |
|---|---|
| 需解冻类型 | 归档（未开归档直读）、冷归档、深度冷归档 |
| 归档解冻 | 通常 1 分钟；归档直读可免解冻实时访问（另收直读取回费） |
| 冷归档解冻 | Expedited 1 小时内 / Standard 2~5 小时 / Bulk 5~12 小时 |
| 深度冷归档解冻 | Expedited 12 小时内 / Standard 48 小时内 |
| 冷归档解冻配额 | 平均每秒 500 个对象；三档合计每天 100 TB~120 TB |
| 深度冷归档解冻配额 | 平均每秒 100 个对象；两档合计每天 10 TB~15 TB |
| 解冻计费 | 数据取回容量费 + 取回请求费（按次，与文件大小无关）+ 临时存储容量费 |
| 提前结束解冻 | CleanRestoredObject 结束冷归档/深度冷归档解冻状态，副本不再产生临时存储费用 |
| 低频/归档跨区域复制 | 不涉及解冻，不收数据取回容量费 |

## 其他强绑定配套

| 配套 | 关键参数 |
|---|---|
| 镜像回源 | 单 Bucket 最多 20 条回源规则；中国内地及中国香港默认 QPS 2,000、流量 2 Gbps；海外地域默认 QPS 1,000、流量 1 Gbps |
| 图片处理 | 单 Bucket 最多 50 个样式；原图 ≤20 MB；处理能力（杭州/上海/北京/张家口/深圳）20 MB/s、QPS 50，其他地域 2 MB/s、QPS 5 |
| 请求者付费 | 开启后外网流出/CDN 回源费由请求者承担，需 Header `x-oss-request-payer: requester`；禁用匿名访问；仅地域属性 Bucket 支持；开启后下行流量包、回源流量包不再生效 |
