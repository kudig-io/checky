## 域名类型与费用特点

| 域名类型 | 适用场景 | 费用特点 | 是否需要开通 |
|---|---|---|---|
| 外网访问域名 | Web 应用、移动客户端等公网访问 | 按外网流出流量计费 | 默认可用 |
| 内网访问域名 | 阿里云内网访问（如 ECS 访问 OSS） | 内网流量免费 | 默认可用 |
| 传输加速域名 | 跨地域、跨国际高速上传/下载 | 外网流出流量费 + 传输加速费 | 需开启传输加速功能 |
| 双栈域名 | IPv6 网络环境访问 | 按外网流出流量计费 | 部分地域支持 |
| CNAME 域名 | 自定义域名绑定时的 DNS 解析 | 按外网流出流量计费 | 需绑定自定义域名并配置 CNAME |

Endpoint 格式：

- 外网：`oss-cn-<region>.aliyuncs.com`（杭州示例 `oss-cn-hangzhou.aliyuncs.com`）。
- 内网：`oss-cn-<region>-internal.aliyuncs.com`（杭州示例 `oss-cn-hangzhou-internal.aliyuncs.com`）。
- 传输加速：`oss-accelerate.aliyuncs.com`。
- Endpoint 缺少 `oss-` 前缀会导致 DNS 解析失败。
- 访问端口（HTTP 80 / HTTPS 443）：Endpoint 按 `http://`、`https://` 协议头访问；官方排障文档明确要求用 `telnet` 检测 Endpoint 80/443 端口连通性（Java SDK Connection refused 报错排查，2026-11-18 复核）。

## 内网 / 公网访问规则

- 同地域 ECS 通过内网域名直连 OSS，走阿里云内部网络，不需配置 VPC 对等连接或路由；经典网络和 VPC 实例共用同一内网 Endpoint。
- 内网访问不经过公网，不产生外网流出流量费用；同地域 ECS + 内网 Endpoint 免流量费（仅产生请求费用）。
- 跨地域访问 OSS 需通过公网或云企业网 CEN 互通。
- 流量计费方向（详见 07）：外网流入、内网流入、内网流出均不计费；外网流出（NetworkOut）、CDN 回源流出（CdnOut）、跨区域复制流量（ReplicationDatasize）计费。
- PrivateLink：VPC 内专属私有终端节点，支持绑安全组、VPC 流日志审计；默认内网域名占用 100.64.0.0/10 网段、无法用安全组控制。

## 请求速率（QPS）

| 读写方式 | QPS（单账号总 QPS 10,000） |
|---|---|
| 顺序读写 | 2,000 |
| 非顺序读写 | 10,000 |
| 单文件上传和下载的总 QPS | 最高 2,000，峰值带宽不超过 10 Gbps（同时受账号地域带宽和 Bucket 上限限制） |

- 顺序前缀命名会导致索引集中于特定分区，请求速率过大时下降；建议随机性前缀。

## CDN 加速与传输加速对比

| 维度 | CDN 加速 | 传输加速 |
|---|---|---|
| 加速原理 | 静态资源缓存到全球边缘节点就近响应 | 阿里云骨干网智能路由优化传输路径 |
| 适用场景 | 静态资源高频读取（图片、音视频、文档下载） | 跨地域、跨国际远距离上传和下载 |
| 对上传的支持 | 不建议通过 CDN 上传 | 支持加速上传 |
| 费用 | CDN 费用 + OSS CDN 回源流出流量费（CdnOut） | 外网流出流量费 + 传输加速费 |
| 组合 | 可将 CDN 回源配置到传输加速域名，构成「边缘缓存 + 骨干网加速」 | 同左 |

- CDN 回源流出流量按 GB 单价计费，可购回源流量包抵扣；回源流量包支持叠加，不支持升级和续费。
- 镜像回源（非 CDN）默认配额：中国内地及中国香港 QPS 2,000 / 2 Gbps；海外 QPS 1,000 / 1 Gbps；单 Bucket 最多 20 条回源规则。
- 传输加速费用：按中国内地/非中国内地方向分 M2M/M2O/O2M/O2O 四类计费，与外网流出流量同时计算，支持传输加速包抵扣；官方《OSS 计费案例》列示非中国内地→中国内地（AccO2MOut）示例单价 1.25 元/GB（2024-11-20 官网价格），完整四类单价以产品定价页为准（2026-11-18 复核）。

## 域名绑定与访问控制

- 一个域名只能绑定在一个 Bucket 上；一个 Bucket 最多绑定 100 个域名；一个账号可绑定域名数无限制。
- 中国内地各地域绑定的域名必须工信部备案（ICP）；其他地域不需要。
- Bucket 域名默认支持 HTTPS 访问，无需额外配置；自定义域名需配置 SSL 证书。
- 使用 Bucket 域名访问 HTML/图片时浏览器强制下载，需绑定自定义域名才能在线预览。
- 防盗链按「空 Referer 检查 → 黑名单 → 白名单」优先级执行，仅对匿名访问和签名 URL 生效；配了 CDN 需在 CDN 层同步配置。
- OSS 解析出的 IP 动态变化，固定 IP 白名单场景需 ECS 反向代理。
