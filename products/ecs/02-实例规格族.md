> 产品：云服务器 ECS ｜ 口径：公共云 ｜ 复核：2026-11-16

## 命名规则

```
ecs.<规格族主体><代际><后缀>.<规格大小>
```

- **规格大小** → vCPU：`small`=1，`large`=2，`xlarge`=4，`<n>xlarge`=n×4
- **主体字母**（性能领域）：

| 主体 | 含义 | CPU:内存 / 场景 |
|---|---|---|
| g | 通用型 | 1:4；通用 Web、Java 应用 |
| c | 计算型 | 1:2；数据库、游戏服、视频编码、批量计算 |
| r | 内存型 | 1:8；Redis、Kafka/ES、大内存 Java |
| u | 通用算力型 | 1:1/1:2/1:4/1:8；性价比企业级 |
| e | 经济型（共享） | 无性能 SLA |
| s/t | 共享/突发 | CPU 积分模式见 07 |
| hf(c/g/r) | 高主频 | 大型游戏、HPC、中大型数据库 |
| i | 本地 SSD | 1:4/1:8；OLTP、NoSQL、ES |
| d | 大数据 | 1:4；Hadoop 生态 |
| re(p) | 持久内存 | re6p/re7p/re8 |

- **代际数字**：越大越新、性价比越高（g8i 发布 2023-03-21；g9 系 2025-2026 年发布）
- **后缀**：`i`=Intel，`a`=AMD，`ae`=AMD 增强，`y`=倚天 710 ARM，`h`=海光，`se`=存储增强，`ne/nex`=网络增强，`t`=安全增强，`p`=持久内存
- **异构/裸金属**：`gn/vgn/sgn`=GPU 计算/vGPU 独享/vGPU 共享，`gi`=Intel GPU，`f`=FPGA，`ebm`=弹性裸金属，`scc`=超级计算集群（+RDMA），`hpc`=物理核
- **GPU 后缀**：`6v`=V100 16G，`6e`=V100 32G，`6i`=T4，`7i`=A10 24G，`7s`=A30，`7e`=A100 大显存，`8is`=L20 48G；`gn7i-c8g1.2xlarge` 中 `c8g1`= vCPU:GPU=8:1

## 选型速查

| 场景 | 推荐 |
|---|---|
| Web 前端 / 通用企业应用 | g 系；预算敏感 u1/u2i 或共享 e/s6 |
| 高并发计算 / 游戏服 / 编码 | c 系；极大包收发选 g8ine/c8ine |
| Redis / ES / 缓存 | r 系；OLTP/NoSQL 选本地 SSD i 系 |
| 持久内存 | re6p/re7p/re8 |
| 大数据存算 | d 系 |
| ARM 降本（容器/微服务/Web） | 倚天 8y 系 |
| AI 训练（NVLink 必须） | gn7e（A100 大显存）；推理 gn8is（L20）/gn7i（A10） |
| 物理机性能 / BYOL | ebm 裸金属；HPC 用 hpc 系；超算互联 scc |
| 机密计算 | SGX/TDX/Enclave/CSV（g6t/g7t/g8i 等） |
