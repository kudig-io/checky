## 云盘性能对比（Block Size=4K）

| 云盘 | 单盘容量 GiB | 最大 IOPS | 最大吞吐 MB/s | IOPS 公式 | 吞吐公式 MB/s | 时延（单路随机写） |
|---|---|---|---|---|---|---|
| ESSD PL0 | 1~65,536 | 10,000 | 180 | min{1800+12×容量, 10,000} | min{100+0.25×容量, 180} | 0.3~0.5 ms |
| ESSD PL1 | 20~65,536 | 50,000 | 350 | min{1800+50×容量, 50,000} | min{120+0.5×容量, 350} | 0.2 ms |
| ESSD PL2 | 461~65,536 | 100,000 | 750 | min{1800+50×容量, 100,000} | min{120+0.5×容量, 750} | 0.2 ms |
| ESSD PL3 | 1,261~65,536 | 1,000,000 | 4,000 | min{1800+50×容量, 1,000,000} | min{120+0.5×容量, 4,000} | 0.2 ms |
| ESSD PL-X（邀测） | 40~32,768 | 3,000,000 | 12,288 | 预配置 IOPS | min{4KB×预配置额外IOPS/1024, 12,288} | 0.03 ms |
| ESSD AutoPL | 1~65,536 | 100 万 | 4,096 | 基准 max{min{1800+50×容量, 50,000}, 3000}+预配置+突发 | 基准 max{min{120+0.5×容量, 350}, 125}+预配置 | 0.2 ms |
| ESSD 同城冗余 | 10~65,536 | 50,000 | 350 | 同 PL1 | 同 PL1 | ms 级（跨 AZ 复制 RPO=0） |
| ESSD Entry | 10~32,768 | 6,000 | 150 | min{1800+8×容量, 6,000} | min{100+0.15×容量, 150} | 1~3 ms |
| SSD 云盘（上一代） | 20~32,768 | 25,000 | 300 | min{1800+30×容量, 25,000} | min{120+0.5×容量, 300} | 0.5~2 ms |
| 高效云盘（上一代） | 20~32,768 | 5,000 | 140 | min{1800+8×容量, 5,000} | min{100+0.15×容量, 140} | 1~3 ms |
| 普通云盘（上一代） | 5~2,000 | 数百 | 30~40 | 无 | 无 | 5~10 ms |

全部 ESSD 系数据可靠性 99.9999999%（11 个 9）；同城冗余 12 个 9。

要点：

- 上一代云盘（SSD/高效/普通）逐步停售：官方替换建议——高效/普通 → PL0 或 Entry；SSD → AutoPL
- AutoPL = 基准性能 + 预配置性能 + 突发性能，计费也分对应三段；容量 ≤3 GiB 不支持预配置
- ESSD 支持 NVMe 协议挂载与多重挂载
- 实例侧上限：各云盘性能之和超过实例规格存储 I/O 能力时，以实例能力为准
- SSD 云盘性能随块大小变化：4KiB≈25,000 IOPS/100MB/s，64KiB≈4,800 IOPS/300MB/s

## 挂载与系统盘限制

| 项 | 数值 |
|---|---|
| 系统盘数量 | 1 块 |
| 数据盘数量 | 由实例规格决定；创建实例时最多 1 系统盘 + 64 数据盘 |
| 挂载点 | 系统盘 /dev/vda；数据盘 /dev/vd[b-z]，>25 块 /dev/vd[aa-zz] |
| 系统盘容量 | Linux 20~2,048 GiB；FreeBSD 30~2,048 GiB；Windows Server 40~2,048 GiB；普通云盘作系统盘上限 500 GiB |
| ≥4 GiB 内存规格 | 不能用 32 位镜像 |

⚠️ 待核：数据盘 64 块为 2026 版限制页表述（旧版 16 块），以 DescribeInstanceTypes 实时值为准。
