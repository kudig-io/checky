## 关键日志详表

### 系统事件（ECS 系统事件汇总）

| 字段 | 类型 | 含义 |
|---|---|---|
| 事件 Code | 字符串 | 格式 `<事件起因>.<对资源的影响>`，如 SystemMaintenance.Reboot |
| 事件名称 | 字符串 | 中文事件名，如「因系统维护实例重启」 |
| 事件等级 | 枚举 | 严重 / 警告 |
| 云监控事件名称 | 字符串 | 格式 `<资源类型>:<事件起因>.<对资源的影响>:<事件状态>`，如 Instance:SystemMaintenance.Reboot:Inquiring |
| 事件状态 | 枚举 | Inquiring（问询中）/ Scheduled（计划中）/ Executing（执行中）/ Executed（已完成）/ Avoided（已规避）/ Failed（失败）/ Canceled（已取消） |
| 事件说明和影响 | 文本 | 触发原因与对实例的影响；计划内维护事件在执行前 24~48 小时发送 |
| 用户侧处理建议 | 文本 | 官方响应动作（修改预约重启时间、自行重启、等待自动执行等） |

### 实例操作记录（管控事件）

| 字段 | 类型 | 含义 |
|---|---|---|
| 事件发生时间 | 时间 | 该操作发生的时间 |
| 操作者名称 | 字符串 | 阿里云账号、RAM 用户或云服务 |
| 云服务名称 | 字符串 | 如「云服务器 ECS」 |
| 事件名称 | 字符串 | 对应 API 名称，如 ModifyInstanceSpec、StopInstances |
| 关联资源 | 字符串 | 实例 ID 与实例名称 |
| 变更范围 | 枚举 | 实例配置/状态/属性/计费变更、创建或释放、关联资源变更 |
| 变更影响等级 | 枚举 | 高 / 中 / 低 |
| 事件记录 | JSON | 事件上下文（requestParameters 等），详情为 ActionTrail JSON 格式 |

### 云助手任务执行记录

| 字段 | 类型 | 含义 |
|---|---|---|
| InvokeId | 字符串 | 命令执行 ID |
| CommandId | 字符串 | 命令 ID |
| CommandContent | 字符串 | 命令内容（周期执行时为 Base64 编码） |
| CommandType | 字符串 | 脚本类型，如 RunShellScript |
| InvocationStatus | 枚举 | 执行状态，如 Success |
| ExitCode | 数字 | 命令退出码，如 0 |
| RepeatMode / Repeats | 枚举/数字 | 执行模式（Once/Period）与已执行次数 |
| Output | 文本 | 命令执行输出结果 |

## 投递与加工

| 日志 | 投递目标 | 配置入口 | 关键参数/说明 |
|---|---|---|---|
| 操作审计管控/数据事件 | 日志服务 SLS、对象存储 OSS、MaxCompute | 操作审计控制台 → 跟踪（每地域最多创建 5 个跟踪） | SLS 专属 LogStore 默认永久保存，可修改存储时长；投递后按对应服务计费；数据事件默认不采集，需创建跟踪并开启 |
| 云助手命令执行记录 | SLS 日志库、OSS 存储空间 | ECS 控制台 → 云助手 → 设置 → 命令执行设置 → 投递到日志服务 SLS | 投递后自动写入指定日志库/存储空间，按 SLS/OSS 计费 |
| 会话管理操作记录 | SLS 日志库、OSS 存储空间 | ECS 控制台 → 云助手（需指定 Project/LogStore 或 Bucket） | 使用会话管理连接实例后自动投递 |
| ECS 系统事件 | 云监控事件中心 → 事件订阅 | 云监控控制台 → 事件 → 事件订阅策略 | 事件同步至云监控后按订阅策略推送至报警联系组（含钉钉机器人 Webhook） |

- 等保 2.0 要求事件保存 180 天及以上时，需创建跟踪持续投递到 OSS/SLS/MaxCompute；默认投递的事件永久保存，可改为仅保留 180 天。
- 查询 90 天以前的事件必须提前创建跟踪；可用数据回补任务把最近 90 天事件回补到 SLS。

## 审计与合规

| 项目 | 事实 |
|---|---|
| 留痕范围 | 阿里云控制台、OpenAPI、开发者工具对云上产品与服务的访问和使用行为；管控事件含资源创建/修改/删除（如创建 ECS 实例、删除安全组规则）与控制台登录（ConsoleSignin） |
| ECS 落地入口 | ECS 控制台 → 实例详情 → 操作记录 页签（数据由操作审计提供）；操作审计控制台 → 事件 → 事件查询 |
| 默认保留期 | 操作审计默认为每个账号保存最近 90 天管控事件，支持在线查询和下载 |
| 数据事件 | 默认不开启采集和存储，需创建跟踪并开启数据事件记录 |
| 记录时延 | 事件通常在 10 分钟内被操作审计追踪并记录 |
| 长期保存 | 创建跟踪投递到 SLS/OSS/MaxCompute 后长久保存；等保 2.0 要求至少保存 180 天 |
| 查询维度 | 操作时段、用户名、资源类型、资源名称、操作名称 |
