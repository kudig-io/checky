## 抢占式实例

| 项 | 规则 |
|---|---|
| 价格 | 相对按量最低 1 折，随供需波动；按秒计费 |
| 保护期 | 默认 1 小时（可设 0 = 无保护期更便宜），期内不释放 |
| 回收 | 过保护期后每 5 分钟检测市价与库存；市价>出价或库存不足 → 释放 |
| 释放预警 | 释放前约 3 分钟产生「准备释放」系统事件；释放后状态 = Expired，不再计费 |
| 限制 | 不可转按量/包年包月；不可变更规格；不可备案 |
| 辅助 API | DescribeSpotPriceHistory（历史价）、DescribeSpotAdvice（近 30 天释放率/折扣率） |

## 节省停机模式（停机不收费）

同时满足四条件才生效：VPC 网络 + 按量付费（含抢占式）+ 规格族无本地存储 + 无持久内存。

- 停机回收并停收：vCPU、内存、GPU/FPGA、固定公网 IP（固定带宽模式）、镜像 License
- 继续计费：系统盘/数据盘、EIP、快照
- 注意：OS 内直接关机不触发；回收后再启动受库存影响（可能 NoStock）；短期停机建议 KeepCharging

**来源**
- 停止实例（节省停机模式）：https://help.aliyun.com/document_detail/132239.html ｜ 复核：2026-11-16

## 宕机迁移

- 共享宿主机实例：宿主机有故障风险时提前 **24~48 小时**发 SystemMaintenance.Redeploy 事件；可自行重新部署或等自动处理（迁移时长分钟级，官方未给统一数字 ⚠️）
- 专有宿主机 DDH：默认开启自动宕机迁移；ActionOnMaintenance = Migrate（云盘型默认）/ Stop（本地盘型默认）
- 迁移后实例 ID、私网 IP、公网 IP 不变；物理机更换后**机器码改变**
- 本地 SSD 型 DDH/实例不支持自动迁移（工单人工迁移，本地盘数据丢失）

- DDH 宕机自动迁移：https://help.aliyun.com/zh/dedicated-host/user-guide/configure-auto-failover ｜ 复核：2026-11-16

## CPU 积分（突发型 t5/t6）

- 概念：基准性能（持续 CPU %）、初始积分（创建时每 vCPU 30）、获得速度（积分/小时，规格决定）、余额上限（=24 小时可获得量）
- 示例（官方）：t6-c2m1.large = 2 vCPU、基准 10%、12 积分/小时、上限 288、初始 60；t5-lc1m2.large = 2 vCPU、基准 20%、24/小时、上限 576
- 模式：性能约束模式（默认，无积分不超基准）/ 无性能约束模式（可超基准，可能产生费用）
- t6 处理器 2.5 GHz Cascade Lake；仅 VPC

**来源**
- 突发性能实例概述：https://help.aliyun.com/zh/ecs/user-guide/burst-performance-instance-overview ｜ 复核：2026-11-16

## 镜像族系（ImageFamily）

- 以 ImageFamily 创建实例自动选族系内最新可用镜像；与 ImageId 互斥
- 族系内镜像可弃用/恢复：弃用最新后自动回退次新可用镜像，实现平滑更新与回滚
