# 专有云 ECS · 架构与差异

> 产品：ECS ｜ 口径：专有云企业版 v3.18.6 ｜ 复核：2026-11-16

## 产品组成

ECS 实例 = 虚拟计算环境（vCPU/内存/OS/网络配置/云盘）。围绕实例的配套资源：

| 组件 | 作用 | 关键参数/常识 |
|---|---|---|
| 块存储 | 云盘（三副本分布式）+ 本地盘（宿主机本地盘，临时性） | 系统盘/数据盘支持在线与离线扩容，离线扩容需重启 |
| 云盘加密 | 盘内数据、盘-实例间传输数据、衍生快照 | 用 KMS，不改应用、不影响业务 |
| 镜像 | 实例运行环境模板 | 导入导出支持 RAW/VHD/QCOW2；VMDK 可导入并转 RAW；导出不可改格式 |
| 快照 | 云盘时点拷贝；一致性组可跨 VM 多盘时序一致 | IA 快照（秒级可用/极速回滚）仅支持高性能云盘 |
| 部署集 | 感知宿主机/机架/交换机物理拓扑的分布约束 | 两种取向：打散（可靠）或聚拢（低时延、保带宽） |
| 安全组 | 虚拟防火墙，状态检测+包过滤 | 规则匹配协议/端口/优先级；多安全组规则全部生效 |
| 专有宿主机 DDH | 单租户独享物理资源 | 可见 Socket/物理核/内存等物理属性；支持跨一级账号共享 |
| 云助手 | 免登录批量执行 Shell/PowerShell/Bat、发文件 | 插件机制扩展 |
| 密钥对 | SSH 登录认证 | RSA 2048，仅 Linux 实例 |

## 虚拟化底座：KVM 与神龙并存

- KVM 机型需在宿主机预留 CPU/内存给网络/存储虚拟化与管控（如 8 vCPU 32 GiB、10 vCPU 40 GiB、10 vCPU 48 GiB 三档预留）
- 神龙机型软硬一体：网络/存储虚拟化与系统管控全部卸载到专用芯片，**资源零开销**，无底层争抢抖动
- CPU 超分：仅共享型、突发型允许超分宿主机 CPU，建议超分比 ≤4；其余类型不可超分
- 宿主机内存、本地盘一律不可超分

## 可靠性指标（SLA 类常识）

| 机制 | 指标 |
|---|---|
| 热迁移 | 特定配置下业务中断 < 100 ms；SLB 后端实例热迁移长连接不中断 |
| 宕机迁移 | 检测到迁移完成 < 90 s |
| HA 重启 | HostOS/GuestOS 内存泄漏、内核崩溃、夯死、网卡反复 UP/DOWN 场景，重启 < 60 s |
| 热升配 | 热加 CPU 不限次数；连续热加内存上限 4 次，第 5 次需重启重置 |
| 回收站 | 删除实例进冷冻期，期内可恢复 |
| 反亲和纠偏 | 约束失效后资源恢复时支持手动热迁移还原 |

## 运维侧特有能力

- 云盘 IO 规格热变配（仅盘古 2.0 底座）：SSD↔高效↔高性能↔普通性能，变配方向有矩阵约束
- 批量热升配、在线/离线克隆（1 台克隆 N 台）
- 整机疏散：宿主机维护（锁定）模式下一键排空，可设迁移速率与并发
- AI 实例诊断、实例规格推荐、资源智能查询
