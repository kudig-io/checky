# 云服务器 ECS · 专有云 v3.18.6 分支

> 产品：ECS ｜ 口径：阿里云专有云企业版 v3.18.6（构建 `v_3_18_6_20261030`，2026-10-30）｜ 复核：2026-11-16

本分支沉淀**专有云形态**的 ECS 常识。与公共云主线（`products/ecs/`）的关键差异：

| 维度 | 公共云 | 专有云 v3.18.6 |
|---|---|---|
| 虚拟化 | 全线神龙化，KVM 基本退场 | KVM 与三代神龙并存，规格名带 `-k`/`-k10`/`-k25` 标记 |
| 规格命名 | 面向公网的世代数字（g8i/c8a/g8y…） | 本地命名体系：密度标记（m/x/v/h）+ 网络标记（k10/k25） |
| 配套底座 | 公共云全托管 | 依赖盘古 2.0 底座、飞天基础运维平台（天基） |
| 可用区/部署 | 公共云地域+可用区体系 | 部署集 + 反亲和纠偏 + 整机疏散的运维侧能力 |
| 运维 | 用户自助 | 云平台运维 + 租户自助分层（ASCM/运维控制台） |
