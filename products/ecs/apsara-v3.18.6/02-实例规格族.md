# 专有云 ECS · 实例规格族

> 产品：ECS ｜ 口径：专有云企业版 v3.18.6 ｜ 复核：2026-11-16

## 命名规则

```
ecs.<规格族><密度?>-<网络标记?>.<资源配比><规格大小>
```

| 段 | 含义 | 例 |
|---|---|---|
| `ecs.` | 产品名 | — |
| 规格族首字母 | s=共享型，g=独享型，c/g/r 按计算内存比取向，d=大数据（本地 HDD），i=本地 SSD，ebm=弹性裸金属 | `ecs.g9mk10` |
| 数字 | 阿里云机型代际（5/6/7/8/9） | `g9` |
| 密度标记（独享型） | m/x/v/h = 宿主机不同整机密度 | `g9m`、`g9x`、`g9v`、`g9h` |
| `-k` / `-k10` / `-k25` | 虚拟化/网络条件：k=KVM，k10=2×10 Gbps 网络，k25=2×25 Gbps 网络 | `s6-k`、`g9xk25` |
| 资源配比 | `c1m2` = 计算内存比 1:2 | — |
| 规格大小 | large=2 vCPU，xlarge=4，2xlarge=8，3xlarge=12 | — |

高密标记的宿主机规模（Intel V9 独享型，来自官方规格表）：

| 家族 | 宿主机规格 | 规格大小范围（vCPU） |
|---|---|---|
| ecs.g9mk10 / g9mk25 | 96 vCPU | 2 ~ 86 |
| ecs.g9xk10 / g9xk25 | 128 vCPU | 2 ~ 118 |
| ecs.g9vk10 / g9vk25 | 192 vCPU | 2 ~ 178 |
| ecs.g9hk10 | 256 vCPU | 2 ~ 242 |

全部支持计算内存比 1:1 / 1:2 / 1:3 / 1:4 / 1:6 / 1:8。

## 家族类型总览（12 类）

| 类型 | 适用场景 | 特征 |
|---|---|---|
| 共享型 | 中小型网站、开发测试、轻量库 | 宿主机 CPU 可超分（≤4），内存比 1:1~1:8 |
| 独享型 | 高网络包收发、Web 前端、批量计算、视频编码 | CPU 不超分，规格越高网络性能越强 |
| 弹性裸金属（ebm） | 容器、数据库、核心业务、大数据 | 物理机性能无损 + 虚拟机弹性；支持 NUMA ON/OFF、共享块存储 |
| 本地 HDD 盘（d 系列） | Hadoop/HDFS/Hive/HBase、ES、Kafka | 计算内存比 1:4（个别例外） |
| 本地 SSD 盘（i 系列） | OLTP、NoSQL、MPP 数仓、ES | 内存比 1:4、1:8 |
| 异构计算型 | AI 推理/训练、视觉、语音、渲染 | GPU 直通：V100/A10/T4/A2/A16/MLU370/DCU Z100L/K100/燧原 I20/Atlas300I Pro/Atlas300T |
| 超级计算集群 SCC | HPC、AI/ML、工程计算 | 裸金属 + InfiniBand 高速互联 |
| 突发型 | 轻载网站 | vCPU 基准性能 + CPU 积分提速 |
| 网络增强型 | NFV/SD-WAN、视频弹幕、电信转发 | 超高 PPS |
| 存储增强型 | 存储密集 | 云盘带宽/IOPS 优化 |
| 可信计算型 | 金融、政务、敏感数据 | UEFI 安全固件 + vTPM/vTCM + 远程证明，启动链度量 |

## 自定义规格

- 格式：`实例规格族.c（CPU 核数）m（内存大小）.customize.XXX`，网络带宽/收发包/多队列自动生成
- 不支持自定义的类型：突发型（CPU Credit）、NUMA ON、裸金属、vGPU、SCC
