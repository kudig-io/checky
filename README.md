# snap-check · 云速查

按**产品维度**速查云基础常识的开放手册：每个产品充分展开两类内容——**参数**（规格、性能、配额、限制）与**架构**（底层组成、工作原理、可靠性设计）。所有数据取自官方文档，逐条标注来源。

> 名字读作 "snap check"：snap = 快照/速览，check = 核对。查一个参数，像抓快照一样快。

## 口径

- **主线**：公共云官方文档（以阿里云为主，逐步扩展多云）
- **分支**：同一产品的专有云/其他形态作为独立分支维度并存，如 `products/ecs/apsara-v3.18.6/`
- **事实优先**：只收录可核对的参数与架构事实；观点、营销话术不收
- **来源强制**：每个小节末尾列官方来源 URL 与复核日期；拿不准的数字标 `⚠️ 待核`
