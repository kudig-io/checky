# 云速查（checky）快速上手指南

> 3 分钟上手：怎么查、怎么读、怎么信。

## 1. 这是什么

**云速查（checky）**是按产品维度的云产品速查手册：快速查看每个产品的**基础信息、组件、日志、告警、架构图**。

- 当前覆盖 **20 个阿里云产品**（计算存储网络 / 数据库 / 云原生 / 大数据），清单见 [products/INDEX.md](../products/INDEX.md)
- 每条事实带**官方来源 URL + 复核日期**；查不实的显式标记，不猜数字

## 2. 30 秒找到你要的内容

```
products/INDEX.md          ← 第 1 步：按产品名找目录
products/<产品>/README.md  ← 第 2 步：看导览，9 篇各讲什么
products/<产品>/NN-主题.md  ← 第 3 步：直达对应篇目
```

## 3. 读懂三个惯例

**① 文件头 = 快照信息**

```markdown
> 产品：OSS ｜ 口径：公共云 ｜ 复核：2026-11-17
```

复核日期超过 12 个月的内容在 INDEX 标 🕐，用前建议自行再核。

**② 每节末尾的「来源」块**

小节里的每个数字都能沿来源 URL 回到官方页核对。多来源冲突时按「官方最新 > 官方旧版 > 其他」取值并写明冲突。

**③ 两个标记**

| 标记 | 含义 | 怎么用 |
|---|---|---|
| `⚠️ 待核` | 官方口径冲突或本次未核实 | 数字仅作参考，引用前回官方页确认 |
| `📋 待补` | 结构已建、官方未发布该数据（如多数产品无官方告警阈值） | 说明此处官方就没有，不是遗漏 |

**架构图**：Mermaid 文本图，GitHub 直接渲染；图中组件名与「组件清单」表同名，可交叉对照。

## 4. 三个实战例子

**查参数**：ECS 云盘单盘 IOPS 上限 → `products/ebs/03-性能参数.md`（公式表 + 各 PL 档位）

**配告警**：RDS MySQL CPU 告警阈值 → `products/rds-mysql/09-监控与告警.md` §官方默认与推荐告警（有官方出处才收录，缺位处标 📋）

**排日志**：OSS 访问日志字段含义 → `products/oss/08-日志与审计.md` §关键日志详表（字段/类型/含义 + 投递方式）

| 角色 | 动作 |

| **纯查** | 上面三步就够了 |

| **加新产品** | 读 [CONTRIBUTING.md](../CONTRIBUTING.md) → 复制 [docs/template-product.md](template-product.md) → 建 9 篇骨架 → 内容 ≥60% 后在 INDEX 登记 🚧 |

设计与规划见 [docs/design.md](design.md)（v2 九篇规格）与 [docs/development-plan.md](development-plan.md)（已完成的 DP-01~12）。

## 6. 常见问题

**Q：数字过时了怎么办？** 以文件头复核日期为准；来源 URL 指向官方页，官方永远是最新口径，欢迎 PR 更新并刷新复核日期。

**Q：为什么没有某产品的官方阈值/配额？** 官方未发布——我们在 09/06 篇显式写「官方未发布」+ `📋 待补`，绝不编造。

**Q：能离线看吗？** 全部是纯 Markdown + Mermaid，克隆仓库即可离线阅读；架构图用任意 Mermaid 渲染器打开。
