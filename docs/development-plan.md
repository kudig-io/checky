## 三、执行策略

1. **代理并行**：沿用 v1 模式——每产品一个调研生产代理，返回文件清单 + 覆盖率 + 待核数；主流程跑 gate 校验后登记 INDEX
2. **gate 前置**：每批完成立即跑局部四项 gate，问题批内修复，不带病进下一批
3. **来源纪律**：代理提示词固定三句——逐节来源 1:1、查不实标 ⚠️/📋 不猜、只引阿里云官方域
4. **变更控制**：设计稿评审后冻结信息架构；铺开期若需改小节结构，先回写 design.md 再进批次
