# 云速查（checky）设计补齐稿

> 状态： draft，待评审 ｜ 拟定：2026-11-17 ｜ 基线：v1（20 产品 × 7 篇，164 文件）

## 一、定位

**云速查（checky）**：按产品维度快速查看云产品**基础信息、组件、日志、告警、架构图**的速查手册。

- 查一个参数，像抓快照一样快；每条事实带官方来源与复核日期
- v1 已解决「参数 + 架构事实」；本稿补齐「组件、日志、告警、架构图」四个维度

## 二、目标与非目标

**目标**

1. 每个产品形成九维速查：架构（含架构图）/ 组件 / 资源类型 / 参数 / 网络 / 配额 / 计费 / 日志 / 监控告警
2. 架构图文本化、可 diff、可离线渲染
3. 日志与告警内容延续「事实 + 来源」强制规则，不滑向经验帖
4. 20 个存量产品可分批回填，状态在 INDEX 可见

**非目标（本期不做）**

- 不做交互式网站 / CLI / API（架构预留，见 §八）
- 不收厂商对比、选型观点、无出处的阈值经验
- 不替代官方文档，只做「带索引的快照」

## 四、四个新维度的规格

### 4.1 架构图（并入 01）

- **格式**：Mermaid `flowchart TB`，纯文本、可 diff、GitHub/GitLab 原生渲染
- **数量**：每产品 01 篇 ≥1 张总架构图；组件关系复杂者（ACK/DTS/DataWorks）可加 1 张分解图，上限 2 张
- **画法**：按官方架构页重绘；组件名与正文术语一致（与组件清单同名）
- **风格约束（DP-08 三试点定稿）**：subgraph 按功能分层，2~5 个；单 subgraph ≤6 节点；全图 ≤20 节点；锚点节点（地域/业务应用）可置于 subgraph 外；边标签仅用于语义非自明的路径（读写路径、复制方式）
- **来源**：图后紧跟来源块，指向该图依据的官方架构页（复核日期随图）
- **不收**：官方 PNG 截图（版权 + 过时 + 不可 diff）

```markdown
## 架构图

​```mermaid
flowchart TB
  ...
​```

**来源**
- <官方架构页 URL> ｜ 复核：2026-11-17
```

### 4.2 组件清单（并入 01）

一张表回答「这个产品由什么组成、什么必须、什么另计费」：

| 组件 | 作用 | 必选/可选 | 是否独立计费 | 备注 |
|---|---|---|---|---|

- 组件范围：核心构件（如 ACK 的 CNI/CSI/Ingress）+ 强绑定关联产品（如 ECS↔云盘/快照）
- 每行事实需可在来源页核对；关联产品给出仓库内交叉链接（如 `[云盘](../ebs/)`）

### 4.3 08-日志与审计

固定小节骨架：

1. **日志类型总表**：类型（操作/访问/审计/引擎/审计日志）｜ 产生方 ｜ 查看入口（控制台路径/产品名）｜ 默认保留期 ｜ 是否计费
2. **关键日志详表**：该产品最重要的 2~4 类日志，字段级列 3~8 个关键字段（名称、类型、含义）
3. **投递与加工**：投递目标（SLS/OSS/CMS）、采样与过滤参数、跨账号投递
4. **审计与合规**：操作审计（ActionTrail）覆盖范围、留痕保留期

来源体系：help.aliyun.com 日志文档 + SLS/操作审计官方页。

### 4.4 09-监控与告警

固定小节骨架：

1. **核心监控指标表**：指标名（官方英文名）｜ 含义 ｜ 单位 ｜ 统计周期 ｜ 维度
2. **官方默认/推荐告警**：官方文档明示的默认告警规则或推荐阈值（指标 + 阈值 + 等级）
3. **通知与渠道**：支持的通道（短信/邮件/函数计算/webhook）、告警升级与静默
4. **告警配额**：单账号告警规则数、通知人配额等（CloudMonitor 侧）

**阈值红线（本稿最重要的一条规则）**：

- 只收**有官方出处**的阈值（官方推荐值、官方默认规则、官方文档示例），逐条带来源
- 无官方出处的「经验阈值」**不收**——若某产品官方无推荐阈值，第 2 节写「官方未发布推荐阈值」并标 `📋 待补`，不破坏「事实 + 来源」的仓库契约

## 五、来源与标记规则（增量）

沿用 CONTRIBUTING 全部规则，增补三条：

1. **图即事实**：Mermaid 图与其来源块绑定；图中每个组件名可在来源页找到
2. **双来源域**：日志/告警篇除 help.aliyun.com 外，允许 `help.aliyun.com/zh/sls/`、CloudMonitor 指标文档、terms.aliyun.com；域名审计规则不变（仅阿里云官方域）
3. **标记扩展**：`⚠️ 待核` 沿用；新增 `📋 待补`（结构已建、内容空位）与 `🕐`（超 12 个月未复核）并存于 INDEX 图例

## 八、预留（不在本期）

- **多云分支**：篇目结构与云厂商无关，非阿里云分支（如 `products/ecs/aws/`）复用同一 9 篇骨架，来源域审计按分支白名单放行
